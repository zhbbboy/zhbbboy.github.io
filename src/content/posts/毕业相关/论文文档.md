# 杭州电子科技大学计算机学院 2025 级学硕｜GME / B-Rep 缝合研究与投稿期刊规划

> **版本**：2026-11-15（V1.0，可持续更新）  
> **对象**：杭州电子科技大学计算机学院 2025 级学术型硕士  
> **研究范围**：GME 几何内核（参照 ACIS）的 B-Rep Stitching / Sewing；重点考虑候选 Coedge 搜索、几何匹配、容差鲁棒性、部分重合边、拓扑正确性。  
> **写作目的**：为后续筛选期刊、论文创新点与毕业节点做决策，**不是录用率预测或学校最终认定证明**。

## 0. 一页结论

1. **你不是非发 SCI 不可。** 2025 级学硕按学院办〔2025〕13 号，可采用 **1 篇学校认可的中文核心/一级期刊、SCI/EI 期刊、CCF C 及以上会议/期刊等论文**作为成果路径，其他成果路径也存在。文中同时有“首次盲审 AA”的替代路径，但不能预先依赖。
2. **投稿前审批备案是硬要求**：先经导师同意并完成《杭州电子科技大学研究生学术成果审核备案表》，否则成果可能不予认定。
3. **中文核心论文要求本人第一完成人**；所有成果**杭州电子科技大学为第一署名单位**；其余成果通常允许本人一作或导师一作本人二作（以具体规定为准）。
4. 建议先瞄准校内目录中的**核心级、主题相符的刊物**，而不是仅选 SCI 或 CCF C：特别是《计算机应用研究》《计算机工程》《计算机工程与应用》《工程设计学报》《机械科学与技术》《现代制造工程》。
5. **只做“GME 性能快一些”并不自动构成论文。** 要先识别可复现的缺陷，再做一般性的算法改进，验证缝合正确性、边界不漏匹配和稳定性。
6. **文内所有“投稿—录用估计”都是单次顺利审稿/常规返修的规划区间**；拒稿重投可能额外增加数月乃至一年。仅《计算机应用研究》《计算机工程》等少数期刊查得官方周期佐证。

其他路径还包括授权国际/国家发明专利、专著、符合条件的竞赛获奖等，具体见原文；本文件以“学术论文”路径规划。**注意：这不是“随便发知网收录刊物即可”，刊物必须符合具体认定等级。**

## 2. 评分和周期解释（避免被数字误导）

- **契合度 /100（越高越合适）**：主题是否直接涵盖 CAD/B-Rep、几何建模、曲面/拓扑处理；**不是接受概率**。
- **投稿难度 /100（越高越难）**：根据刊物学术定位、潜在方法创新要求、选题适配作出的**主观排序**；无官方“难度分数”。
- **投稿→录用时间**：自**首次正式提交**至**编辑部给出正式录用**，包括常规返修，不包括“录用后排版、网络首发、见刊、数据库检索”；不包括拒稿后换刊。绝大多数为**规划估计 E**，不能作为期刊承诺。
- **时间证据级别 O1/O2**：O1 = 官方给出正常审稿1–2个月，我保守估投稿→录用2–4个月；O2 = 官方提到“平均录用80天”，我按返修及波动估2–4个月。**不得将官方首轮审稿时间和最终录用周期混为一谈**。
- 等级“核心/一级/TOP”全部**严格按 2023 版校内名录分组**，并不推断当下所有目录、检索库状态始终不变。

### 3.1 如何利用这张表

**第一梯队（先看已发表论文）**：工程设计学报、计算机应用研究、机械科学与技术、现代制造工程、计算机工程、计算机工程与应用、计算机应用。它们不是“很容易”，而是你现有 GME 核心算法工作可能有合适的论文叙事。

**第二梯队（要把题目扩展为 CAD 系统/工程修复）**：机械设计与研究、机械设计、系统仿真学报、工程科学与技术、航空航天领域学报。应把案例切换到机械、航空 CAD 数据及应用问题，不能只拿纯代码性能表投稿。

**第三梯队（创新够强时再冲）**：计算机辅助设计与图形学学报、计算机集成制造系统、中国机械工程等。它们在题目上匹配得很高，但往往需要更明显的方法创新、完整对比或工程验证，**匹配度高≠毕业最稳**。

### 3.2 不纳入主推荐的刊物与原因

- 《图学学报》：虽然主题很相关，但**未在这次提供的《杭电国内期刊名录（2023版）》检索到该刊**；不能把其他学会的分级/T1 自动当成杭电认可“核心/一级”的依据。如想投，必须先向学院核实当前认定路径（也可能以其他可认定的收录条件进入）。
- 《计算机学报》《软件学报》《机械工程学报》：虽在校内名录中（TOP），**远高于毕业所需强度**；除非做出有竞争力的系统级/理论创新，否则不作为合理主目标。
- 视觉识别、医学影像、深度学习优先的刊物：若论文只做传统 B-Rep 缝合，不应为投刊强行加 AI；若以后做 Learning-based B-Rep Repair，可另开清单。
- 一般“知网收录”“科技论文展示”但未达到文件A列明的成果类别：**不能自动视为符合学位条件**。

## 6. GME 与 ACIS：设计能支撑小论文的实验

### 6.1 目标问题

> 在有限容差下，如何降低 B-Rep 缝合中的无效候选边对及昂贵几何匹配开销，同时不破坏原有缝合结果与拓扑正确性？

### 6.2 推荐方法（尚未证明有新颖性）

1. **检测 GME 原实现**：确认候选边生成的数据结构、已有过滤、是否有 AABB/BVH/Hash、可能的两两枚举；先找真实短板。切勿假设 GME 仍是 O(n²) 暴力匹配。
2. **性能建模**：记录候选 Coedge 对数、精确几何匹配调用数/耗时、内存、总耗时，判断瓶颈占比。
3. **单点改进优先**：如容差安全的候选边索引、多粒度几何快速拒绝测试；必须避免排除真正应配对的边。
4. **难点用例**：逆向 Coedge、NURBS/圆弧/直线混合、近似但不重合、长边对多短边、退化边、小特征、不同容差、非流形选项（如接口支持）。
5. **严格对照**：原版 GME vs 改进 GME 为主要算法消融；ACIS 是商业工业参照，不保证语义/实现一致；可根据能力增加 OCCT Sewing。控制输入、单位、容差、功能选项、硬件、线程设置。
6. **论文实验**：总时间和各模块时间、加速比、候选减少率、匹配查全率、误缝率、合法 Shell/Body 数量、失败案例；不要只报告“候选数下降”或“比 ACIS 快”。

### 6.3 最少实验矩阵

| 测试维度 | 建议分组 | 指标 |
|---|---|---|
| 规模 | 100、1000、10000、更多 Edge（以真实支持能力为准） | 总耗时/峰值内存/加速比 |
| 几何 | 直线、圆弧、样条、混合 | 匹配正确率/精确比较耗时 |
| 容差 | 小/中/大，按模型单位和局部尺度设置 | 误缝率、漏缝率、结果有效性 |
| 拓扑 | 断边、部分重合、逆向、退化等 | 缝合成功率、非法拓扑数 |
| 消融 | 原版、仅空间搜索、仅快速过滤、联合优化 | 贡献分解 |

**学术新颖性自检**：如果方法仅等于常规 BVH/AABB 和 Hash 的直接应用，即使提速很大，也可能被认为是工程优化。选题初期必须阅读 OCCT Sewing / 几何匹配 / CAD Healing 相关文献并确认新增的机制或可证明性质。

## 7. 可执行的投稿优先级（只为毕业，不故意选最弱刊）

### 中文主路径

1. **《计算机应用研究》** — 若创新主要是候选匹配与通用算法性能。官网正常审稿 1–2 个月，规划“投稿→录用”约 **2–4 个月**。
2. **《计算机工程》** — 若设计了可复用的几何算法并完成正确性/复杂度实验。官网披露平均“录用约 80 天”，规划约 **2–4 个月**。
3. **《工程设计学报》** — 若含工业 CAD 复杂曲面或模型修复实例。规划约 **3–7 个月**，**非官网统计**。
4. **《计算机工程与应用》** — 几何匹配/鲁棒算法，规划约 **3–7 个月**，非官网统计。
5. **《机械科学与技术》** — 若更偏 CAD/机械建模与应用。规划约 **3–7 个月**，非官网统计。
6. **《现代制造工程》** — 若能把方法放进真实 CAD/CAE 工作流。规划约 **3–7 个月**，非官网统计。

注：**不要同时一稿多投**。每次投稿前，重新确认新规、期刊网站与预警/收录情况，且已经完成学院备案。

### 根据研究成熟度做决策

- **只有单点代码提速**：继续研究，先别投；哪怕期刊等级符合，内容也可能不达发表要求。
- **一个清楚的新筛选/匹配方法 + 充分对照**：优先考虑上述“中文主路径”。
- **新颖的容差/几何一致性机制 + 边界失败案例明显改善**：可以考虑《计算机应用》或《工程设计学报》，再评估《计算机集成制造系统》。
- **严谨几何算法框架，有通用性与较强方法创新**：评估《计算机辅助设计与图形学学报》或 Graphical Models / Computers & Graphics，但要接受更大的时间风险。
