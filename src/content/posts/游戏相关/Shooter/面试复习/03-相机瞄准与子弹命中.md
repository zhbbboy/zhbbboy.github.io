## 1. 功能

从相机选择目标点，从枪口发射实体子弹，并在服务器碰撞时结算伤害。

## 2. 相关类和源码位置

`AMyWeapon`、`AMyProjectile`、`AMyEnemyCharacter`。

- `Source/MyArenaShooter/Private/MyWeapon.cpp:300`（`::CalculateAimPoint(`）
- `Source/MyArenaShooter/Private/MyProjectile.cpp:52`（`::BeginPlay(`）
- `Source/MyArenaShooter/Private/MyProjectile.cpp:197`（`::OnProjectileHit(`）

## 3. 入口

`AMyWeapon::Fire → CalculateAimPoint`；子弹由 `OnComponentHit` 回调进入命中处理。

## 4. 调用链

```text
Camera位置 + ControlRotation.Vector × 10000
→ LineTraceSingleByObjectType（Pawn + WorldStatic，忽略玩家和武器）
→ 命中取 ImpactPoint，否则取线段终点
→ ShootDirection = (AimPoint − MuzzlePosition).GetSafeNormal()
→ 服务器从枪口按方向生成 Projectile
→ 服务器 ProjectileMovement / 碰撞 → OnProjectileHit
→ Enemy.TakeProjectileDamage → 玩家命中通知 → 命中特效 → Destroy
```

## 5. 核心机制

相机射线负责选点，真实伤害由服务器子弹碰撞结算；两次Hit是不同事件，接触点可能不同。Projectile服务器启用碰撞与移动复制；普通客户端副本关闭实体碰撞和ProjectileMovement，接收服务器位置。本地表现弹另有独立分支，只显示、不扣血。

## 6. 关键设计问题

**为什么不直接从相机生成子弹？**

相机位置便于确定准星方向，枪口位置让弹道从武器发出；分别使用二者可以减小近距离视差。近墙时仍要考虑枪口前方被遮挡。

**为什么Weapon和Projectile分开？**

Weapon决定什么时候、从哪里发射；Projectile负责飞行、碰撞和生命周期，便于独立调整子弹行为。

**这是不是客户端射线命中就扣血？**

不是。客户端选点可用于表现；服务器自己的真实Projectile碰撞后才请求伤害。当前相机查询类型未包含WorldDynamic。
