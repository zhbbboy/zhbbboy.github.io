## 1. 功能

用枪口火光、声音、网格后坐力、相机惯性摆动和换弹姿态表现武器操作。

## 3. 入口

服务器成功Fire后调用 `MulticastPlayFireEffects`；Weapon Tick每帧合成网格相对变换。

## 4. 调用链

```text
BeginPlay缓存WeaponMesh初始相对位置和旋转
→ 服务器真实开火成功 → MulticastPlayFireEffects
→ 本地射手增加CurrentRecoilBack/Pitch；各端按资源配置播放枪焰/声音
→ Tick按相机角速度计算Sway目标，并FInterpTo平滑当前值
→ 后坐力FInterpTo向0恢复
→ 按同步ReloadState计算Sin换弹权重
→ Default + Recoil + Sway + Reload → SetRelativeLocation/Rotation
```

## 5. 核心机制

WeaponMesh变化是相对父组件的表现；MuzzleLocation是其子组件，后续发射会重新读取枪口世界位置。武器网格后坐力不等同于控制器视角后坐力或散射。重新计算固定基准加偏移，避免每帧把偏移反复累积到上一帧最终变换。

## 6. 关键设计问题

**为什么要缓存默认相对变换？**

每帧从固定基准叠加当前状态，既能保留蓝图初始摆放，也能避免位置持续漂移。

**为什么使用FInterpTo？**

让当前状态随DeltaTime向目标逐步靠近，形成平滑回弹与摆动；实际速度和效果取决于参数与帧调度。

**为什么枪口可能影响实际发射起点？**

MuzzleLocation挂在WeaponMesh下，网格姿态改变会改变枪口世界位置；服务器Fire仍以相机选点再从枪口计算方向。
