## 1.完整玩家初始化流程
```
游戏启动
   ↓
GameMode 创建
   ↓
DefaultPawnClass
   ↓
BP_FirstPersonCharacter
   ↓
创建 Character
   ↓
ABoomerShooterCharacter 构造函数
   │
   ├─ ACharacter 自带 Capsule
   ├─ 自带 Mesh
   ├─ 自带 CharacterMovement
   │
   └─ CreateDefaultSubobject
        ↓
      CameraComponent
   ↓
PlayerController Possess Character
   ↓
PostInitializeComponents
   ↓
BeginPlay
   │
   ├─ Health = MaxHealth
   ├─ 初始化 Weapon
   └─ AddMappingContext
   ↓
SetupPlayerInputComponent
   │
   ├─ MoveAction → Move()
   ├─ LookAction → Look()
   ├─ JumpAction → JumpInput()
   ├─ DashAction → Dash()
   └─ ShootAction → FireInputStart()
   ↓
玩家开始操作
```


可以，而且我非常建议你用一种方法：**“影子项目重写法”**。

不是“把这个仓库读完”，而是最终自己新建一个：
```
MyArenaShooter
```
然后在**尽量不看原代码的情况下，从 0 把它重新做出来**。
只有做到这一点，你从这个仓库获得的知识才会接近“自己从零写了一遍”。
你可以按下面这个顺序来。
## 第一阶段：先把原项目跑通，不改代码

目标不是学细节，而是知道：
```
这个游戏到底有哪些系统？
```

你先实际玩一遍，然后记：
```
玩家可以：
- 移动
- 看向
- 跳跃
- Dash
- 射击
- 换武器
- 交互

游戏还有：
- Weapon
- Projectile
- Enemy
- Enemy AI
- Enemy Spawner
- JumpPad
- DamageZone
- UI
- GameMode
```

然后画一个非常粗的结构：

```
GameMode
   ↓
Player Character
   ├─ Input
   ├─ Camera
   ├─ Movement
   └─ Weapon
        ↓
     Projectile
        ↓
      Enemy
        ↑
   AIController

GameMode / Manager
       ↓
  EnemySpawner
```

第一遍不要管实现。

---

# 第二阶段：按照“游戏执行流程”读，不按照文件夹乱读

你现在应该按照这个顺序：

```
1 GameMode
↓
2 Character
↓
3 Input
↓
4 Movement
↓
5 Weapon
↓
6 Projectile
↓
7 EnemyCharacter
↓
8 EnemyAIController
↓
9 EnemySpawner
↓
10 UI
↓
11 其他辅助 Actor
```

这比：

```
随便点开一个 .cpp
→ 看不懂
→ 再点另一个
```

效率高非常多。

我们现在其实就在：

```
1 GameMode
```

阶段。

# 第三阶段：每个模块都按照固定的 7 步学习

以后我们读每一个模块，都固定这样。

例如学 Character。

### 第一步：它是什么？

先回答：

```
ABoomerShooterCharacter
是什么？
```

答案：

```
玩家角色
继承 ACharacter
```

### 第二步：它有什么东西？

比如：

```
Camera
Health
Weapon
InputAction
Movement 数据
```

也就是先看 `.h`。

---

### 第三步：它什么时候初始化？

再找：

```
Constructor
BeginPlay()
PostInitializeComponents()
```

搞懂：

```
谁创建？
什么时候创建？
创建时初始化什么？
开始游戏后初始化什么？
```

---

### 第四步：它接收什么输入？

例如：

```
WASD
鼠标
Space
左键
数字键
```

找到：

```
SetupPlayerInputComponent()
```

---

### 第五步：输入最终调用什么？

例如：

```
W
↓
MoveAction
↓
Move()
↓
AddMovementInput()
```

---

### 第六步：它和谁交互？

例如 Character：

```
Character
├─ Controller
├─ Weapon
├─ EnemySpawnerManager
└─ UI
```

这个步骤非常重要。

你以后真正写项目，难的不是：

```
for
if
vector
```

而是：

> **哪个类应该负责什么？谁调用谁？**

---

### 第七步：关闭源码，自己写

这是最重要的一步。

例如学完移动以后，关掉 GitHub。

自己写：

```
void AMyCharacter::Move(...)
{
    ...
}
```

如果你完全不会写：

先想。

实在不会再打开参考。

不要：

```
左边原项目
右边自己的项目
一行一行抄
```

那样学习效果很差。

---

# 第四阶段：建立一个全新的 UE 项目

当我们把：

```
GameMode
Character
Input
Movement
```

读懂以后，你就应该新建：

```
MyArenaShooter
```

不要复制原项目。

从：

```
Blank C++ Project
```

开始。

然后自己创建：

```
MyArenaShooterGameMode

MyCharacter

MyWeapon

MyProjectile

MyEnemyCharacter

MyEnemyAIController
```

名字都改掉。

这样非常重要，因为你会被迫重新思考：

```
这个类继承谁？
头文件 include 什么？
GameMode 怎么设置 Character？
Character 怎么加 Camera？
输入怎么绑定？
```

这些才是真正的学习。

---

# 第五阶段：重写顺序一定要控制

你不要一次重写整个项目。

应该这样。

### Milestone 1：角色出现在地图里

只实现：

```
GameMode
    ↓
MyCharacter
```

要求：

```
运行游戏
↓
GameMode 自动生成你的 Character
```

完成以后才能进入下一步。

---

### Milestone 2：第一人称相机

自己实现：

```
CreateDefaultSubobject<UCameraComponent>()
```

然后：

```
Character
└─ Camera
```

做到：

```
进入游戏
↓
可以看到第一人称画面
```

---

### Milestone 3：WASD + 鼠标

自己创建：

```
IA_Move
IA_Look
IMC_Player
```

然后：

```
WASD → Move()
鼠标 → Look()
```

做到：

```
可以正常移动
可以转动视角
```

---

### Milestone 4：Jump + Dash

做到：

```
Space → Jump
Shift → Dash
```

这时候你已经真正掌握：

```
Character
Input
CharacterMovement
Controller
```

---

### Milestone 5：Weapon

自己创建：

```
class AMyWeapon : public AActor
```

然后：

```
Character
   ↓
SpawnActor
   ↓
Weapon
```

先做到：

```
角色手里出现一把枪
```

不要急着射击。

---

### Milestone 6：Projectile

建立：

```
class AMyProjectile : public AActor
```

做到：

```
左键
↓
Weapon::Fire()
↓
SpawnActor<AMyProjectile>
↓
子弹生成
↓
向前移动
```

这一步会真正让你理解：

```
Actor
SpawnActor
Transform
生命周期
```

---

### Milestone 7：Enemy

建立：

```
MyEnemyCharacter
```

先不要 AI。

只做到：

```
敌人能生成
有 Health
子弹打中
Health 减少
Health <= 0
Destroy()
```

---

### Milestone 8：AIController

然后再加入：

```
AIController
    ↓
Possess
    ↓
EnemyCharacter
```

做到：

```
发现玩家
↓
追玩家
↓
攻击
```

---

### Milestone 9：Spawner

自己实现：

```
EnemySpawner
```

做到：

```
每隔 N 秒生成敌人
```

然后逐渐变成：

```
Wave 1
Wave 2
Wave 3
```

---

### Milestone 10：UI

最后做：

```
Health
Ammo
Score
Crosshair
```

因为 UI 本质上是在**显示前面系统的数据**。

# 第六阶段：每做完一个模块，必须回答 5 个问题

比如 Weapon。

你必须能不用看代码回答：

```
1. Weapon 为什么继承 Actor？

2. Weapon 是谁创建的？

3. Weapon 保存在哪？

4. 玩家按左键后，是谁通知 Weapon 开火？

5. Weapon 又是怎样创建 Projectile 的？
```

如果你答不上来：

> 说明这个模块还没有真正掌握。

---

# 第七阶段：做到“不看源码可以画出调用链”

例如射击，你最后应该能直接画：

```
鼠标左键
   ↓
Enhanced Input
   ↓
ShootAction
   ↓
Character::FireInputStart()
   ↓
Weapon::SetFirePressed()
   ↓
Weapon::Fire()
   ↓
SpawnActor<Projectile>()
   ↓
Projectile
   ↓
Hit Enemy
   ↓
Enemy 扣血
```

这个能力非常重要。

因为面试官问：

> “你项目里的射击系统怎么实现的？”

你真正回答的就是这张图。

---

# 第八阶段：第二遍自己改设计

第一次重写：

> 尽量模仿原项目。

第二遍开始思考：

```
原作者为什么这么写？

有没有更合理的写法？
```

例如原项目：

```
Character
持有 Weapon
```

你可能后来改成：

```
Character
   ↓
WeaponComponent
   ↓
Weapon
```

或者：

```
WeaponData
使用 DataAsset
```

这时候项目才开始真正变成：

> **你的项目，而不是复刻项目。**

---

# 你最终应该达到三个等级

### Level 1：看得懂

别人写：

```
SpawnActor
BindAction
CreateDefaultSubobject
```

你知道什么意思。

这只是最低级。

---

### Level 2：写得出来

我说：

> “做一个玩家 Character，带 Camera，WASD 移动。”

你可以自己打开空项目写出来。

这才算真正掌握。

---

### Level 3：设计得出来

我说：

> “现在加武器切换。”

你会自己思考：

```
Weapon 放哪里？

Character 管还是 Component 管？

Weapon 数据放哪里？

怎么切换？

输入放哪里？
```

然后自己设计。

**达到 Level 3，这个项目才真正属于你。**

## 所以我们接下来不要单纯“读仓库”

我们之后的学习方式应该变成：

```
原项目学习
    ↓
我解释
    ↓
你理解调用关系
    ↓
关闭源码
    ↓
你自己在 MyArenaShooter 重写
    ↓
遇到问题再参考原项目
    ↓
完成一个模块
    ↓
自己复述
    ↓
进入下一个模块
```

按照这个方法把

```
GameMode
→ Character
→ Input
→ Movement
→ Weapon
→ Projectile
→ Enemy
→ AI
→ Spawner
→ UI
```

走一遍以后，你获得的知识已经会**非常接近自己从零写过一个 FPS Demo**，而不是简单“看过一个 GitHub 项目”。

我们现在就继续从 **GameMode** 开始，但后面我会按照这种“读懂 → 重写 → 验证”的方式带你，而不是只给你解释源码。
