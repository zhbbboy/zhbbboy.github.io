这题是非常经典的 **二维动态规划 DP**，而且是字符串 DP 里必须掌握的一道。

核心是：

> `dp[i][j]` 表示：`text1` 前 `i` 个字符和 `text2` 前 `j` 个字符的最长公共子序列长度。

---

## ① 破题：题目真正要求什么

例如：

```
text1 = "abcde"
text2 = "ace"
```

公共子序列可以是：

```
"a"
"c"
"e"
"ac"
"ae"
"ce"
"ace"
```

最长：

```
"ace"
```

长度：

```
3
```

所以答案是：

```
3
```

注意这里是：

> **子序列（subsequence，子序列）**

不是：

> 子串（substring，连续子串）

子序列可以不连续，只要求：

> **相对顺序不能改变。**

例如：

```
abcde
↑ ↑ ↑
a c e
```

`ace` 虽然不连续，但是顺序没变，所以是子序列。

---

# ② 核心技巧：二维 DP

定义：

```
dp[i][j]
```

表示：

> `text1` 的前 `i` 个字符，与 `text2` 的前 `j` 个字符，最长公共子序列长度是多少。

这里特别注意：

```
i 不是下标
j 也不是下标
```

而是：

```
前 i 个字符
前 j 个字符
```

所以：

```
dp[0][j]
```

表示：

> 空字符串和 `text2` 前 j 个字符的 LCS。

显然是：

```
0
```

同理：

```
dp[i][0] = 0;
```

---

# ③ 为什么 DP 数组要开 `m+1 × n+1`

假设：

```
text1 = "abc"
text2 = "ace"
```

长度：

```
m = 3
n = 3
```

我们创建：

```
vector<vector<int>> dp(
    m + 1,
    vector<int>(n + 1, 0)
);
```

也就是：

```
4 × 4
```

因为还需要一行一列表示：

```
空字符串
```

大概是：

```
        ""  a  c  e
     ----------------
""   |  0  0  0  0
a    |  0
b    |  0
c    |  0
```

第一行和第一列天然初始化成：

```
0
```

---

# ④ 最关键：状态转移怎么推？

对于：

```
dp[i][j]
```

我们比较：

```
text1[i - 1]
text2[j - 1]
```

为什么是：

```
i - 1
j - 1
```

因为 `dp[i][j]` 表示的是：

```
前 i 个字符
前 j 个字符
```

那么它们最后一个字符的真实下标就是：

```
i - 1
j - 1
```

---

## 情况一：两个字符相同

如果：

```
text1[i - 1] == text2[j - 1]
```

例如：

```
text1 = "abc"
             ↑
             c

text2 = "adc"
             ↑
             c
```

两个最后字符都是：

```
c
```

那么这个 `c` 一定可以加入公共子序列。

所以：

```
dp[i][j] = dp[i - 1][j - 1] + 1;
```

意思：

> 去掉当前相同的两个字符，先看前面的最长公共子序列，再把这个相同字符加进来。

---

比如：

```
"ab"
"ad"
```

最长公共子序列：

```
"a"
```

长度：

```
1
```

现在双方最后都加一个：

```
c
```

变成：

```
"abc"
"adc"
```

那么：

```
"a" + "c"
= "ac"
```

所以：

```
1 + 1 = 2
```

---

# ⑤ 情况二：两个字符不相同

如果：

```
text1[i - 1] != text2[j - 1]
```

例如：

```
text1 = "abc"
             ↑
             c

text2 = "abe"
             ↑
             e
```

现在：

```
c != e
```

这两个字符不可能同时作为公共子序列的最后一个字符。

所以怎么办？

有两种选择：

### 不考虑 text1 当前最后一个字符

也就是：

```
dp[i - 1][j]
```

---

### 不考虑 text2 当前最后一个字符

也就是：

```
dp[i][j - 1]
```

我们当然取更大的：

```
dp[i][j] = max(
    dp[i - 1][j],
    dp[i][j - 1]
);
```

---

# ⑥ 为什么不是 `dp[i-1][j-1]`？

这个问题特别重要。

假设：

```
text1 = "abc"
text2 = "ac"
```

考虑：

```
c 和 c
```

相等：

```
dp[3][2] = dp[2][1] + 1;
```

没问题。

但如果最后字符不同，例如：

```
text1 = "abc"
text2 = "ab"
```

最后：

```
c != b
```

你不能直接：

```
dp[i][j] = dp[i - 1][j - 1];
```

因为这样相当于：

> 两边最后一个字符同时丢掉。

但实际最优答案可能只需要丢掉其中一边。

例如：

```
"abc"
"ab"
```

LCS 明明是：

```
"ab"
```

长度 2。

如果你同时丢掉：

```
c 和 b
```

就变成：

```
"ab"
"a"
```

只能得到：

```
1
```

错了。

所以不相等时必须考虑：

```
max(
    dp[i - 1][j],
    dp[i][j - 1]
);
```

---

# ⑦ 用 `"abcde"` 和 `"ace"` 完整推一次

```
text1 = "abcde"
text2 = "ace"
```

构造：

```
        ""  a  c  e
     ----------------
""   |  0   0  0  0
a    |  0
b    |  0
c    |  0
d    |  0
e    |  0
```

---

### `a` 和 `a`

相同：

```
dp[1][1] = dp[0][0] + 1;
```

所以：

```
1
```

---

### `a` 和 `c`

不同：

```
dp[1][2] =
max(dp[0][2], dp[1][1]);
```

即：

```
max(0,1) = 1
```

---

### `a` 和 `e`

还是：

```
1
```

第一行：

```
0 1 1 1
```

---

### 到 `c`

比如：

```
text1 前3个 = "abc"
text2 前2个 = "ac"
```

最后字符：

```
c == c
```

所以：

```
dp[3][2] = dp[2][1] + 1;
```

`dp[2][1] = 1`，所以：

```
2
```

对应：

```
"ac"
```

---

### 最后 `e` 和 `e`

```
text1 = "abcde"
text2 = "ace"
```

最后：

```
e == e
```

所以：

```
dp[5][3] = dp[4][2] + 1;
```

而：

```
dp[4][2] = 2
```

所以：

```
3
```

最终答案：

```
dp[5][3] = 3;
```

# ⑧ 完整代码

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int m = text1.size();
        int n = text2.size();

        vector<vector<int>> dp(
            m + 1,
            vector<int>(n + 1, 0)
        );

        for (int i = 1; i <= m; ++i) {
            for (int j = 1; j <= n; ++j) {

                if (text1[i - 1] == text2[j - 1]) {
                    dp[i][j] =
                        dp[i - 1][j - 1] + 1;
                }
                else {
                    dp[i][j] =
                        max(
                            dp[i - 1][j],
                            dp[i][j - 1]
                        );
                }
            }
        }

        return dp[m][n];
    }
};
```

# ⑨ 为什么遍历可以从左上到右下？

看依赖：

```
dp[i][j]
```

只依赖：

```
左上：
dp[i-1][j-1]

上：
dp[i-1][j]

左：
dp[i][j-1]
```

也就是：

```
       上
       ↓

左 → 当前
  ↘
  左上
```

因此计算当前之前：

```
左边
上面
左上
```

都必须已经算好。

所以：

```
for (int i = 1; i <= m; ++i)
{
    for (int j = 1; j <= n; ++j)
```

完全符合依赖顺序。

---

# ⑩ 为什么 `dp[0][j]` 和 `dp[i][0]` 都是 0？

比如：

```
text1 = ""
text2 = "abc"
```

空字符串和 `"abc"` 有公共子序列吗？

没有。

所以：

```
LCS("", "abc") = 0
```

因此：

```
dp[0][j] = 0;
```

同理：

```
dp[i][0] = 0;
```

所以我们初始化：

```
vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
```

就已经把边界处理好了。

# ⑪ 最容易混淆：子序列和子串

这题一定要分清。

## 子串

必须连续：

```
abcde

"bcd" ✅
"ace" ❌
```

---

## 子序列

可以不连续，但顺序不能变：

```
abcde

"ace" ✅
"abd" ✅
"bde" ✅
```

但是：

```
"ca"
```

不是，因为顺序变了。

所以：

> LCS 是“最长公共子序列”，不要求连续。

---

# ⑫ 为什么这题是 DP？

因为我们在解决：

```
text1前i个字符
和
text2前j个字符
```

的问题时，只需要利用更小的：

```
前i-1
前j-1
```

的问题结果。

而且大量子问题会重复出现。

所以非常适合二维 DP。

---

# ⑬ 能优化成一维 DP 吗？

可以，但这题第一次学习我不建议马上压缩。

二维：

```
O(mn)
```

空间。

因为：

```
dp[i][j]
```

只依赖上一行和当前行左边，所以可以压成：

```
vector<int> dp(n + 1);
```

但这时还需要额外保存：

```
左上角旧值
```

容易把状态覆盖问题搞混。

所以面试第一次手写：

> **先写二维版本最稳。**

---

# ⑭ 递归适不适合？

从逻辑上很适合。

如果：

```
text1[i] == text2[j]
```

可以：

```
1 + solve(i-1,j-1)
```

否则：

```
max(
    solve(i-1,j),
    solve(i,j-1)
)
```

但裸递归会重复计算很多状态。

所以：

```
递归 + memo
```

可以做。

不过标准写法还是：

> **二维 DP。**

---

# ⑮ 面试追问

最常问三个问题。

**1. `dp[i][j]` 表示什么？**

> `text1` 前 `i` 个字符和 `text2` 前 `j` 个字符的最长公共子序列长度。

**2. 相等时为什么 `+1`？**

> 因为两个当前最后字符相同，可以把这个字符加入前面已经得到的 LCS。

**3. 不相等为什么取 `max(dp[i-1][j], dp[i][j-1])`？**

> 因为这两个不同字符不能同时作为公共子序列的末尾，所以分别尝试舍弃其中一个，取更优结果。

---

# ⑯ 复杂度

DP 表：

```
(m + 1) × (n + 1)
```

所以：

```
时间复杂度：O(mn)

空间复杂度：O(mn)
```
