这道题我建议你**主学栈方法**。

原因是它最直观：

> 遇到 `(` 就记录位置；遇到 `)` 就尝试匹配。  
> 同时用一个“最后一个无法匹配的位置”作为边界，就能计算当前合法括号串长度。

DP 也能做，而且是很经典的进阶写法，但第一次做这题，**栈更容易真正理解**。

---

# ① 破题：题目真正要求什么

例如：

```
s = ")()())"
```

题目不是问有多少对括号，而是：

> 找一个**连续子串**，这个子串必须是合法括号串，并且长度最长。

例如：

```
) ( ) ( ) )
  └─────┘
   ()()
```

最长合法部分：

```
()()
```

长度：

```
4
```

所以答案：

```
4
```

这里一定注意：

> **必须连续。**

---

# ② 核心技巧

栈里不要存 `'('`，而是存：

> **左括号的下标。**

例如：

```
s = "(()"

下标：
0 1 2
( ( )
```

遇到：

```
0 '('
1 '('
```

栈：

```
[0, 1]
```

遇到下标 `2` 的 `)`：

把最近的 `(` 下标 `1` 弹掉：

```
[0]
```

此时当前合法部分：

```
()
```

长度怎么算？

```
当前下标 - 栈顶下标
= 2 - 0
= 2
```

所以：

> 栈顶不仅帮我们匹配括号，还帮我们确定合法子串左边界。

---

# ③ 为什么一开始要放 `-1`

这是本题最关键、也最容易疑惑的地方。

我们会先写：

```
stack<int> st;
st.push(-1);
```

这个 `-1` 不是字符串里的真实位置。

它代表：

> **当前合法括号串左边界前一个位置。**

例如：

```
s = "()"

下标：
0 1
( )
```

开始：

```
stack = [-1]
```

遇到 `(`：

```
stack = [-1, 0]
```

遇到 `)`：

弹出 `0`：

```
stack = [-1]
```

长度：

```
i - st.top()
= 1 - (-1)
= 2
```

正好是：

```
"()"
```

的长度。

如果没有 `-1`，匹配完以后栈空了，就没办法算：

```
从字符串开头开始的合法括号长度
```

所以：

> `-1` 是一个虚拟边界。

# ⑤ 完整代码

推荐你先掌握这个版本：

```
class Solution {
public:
    int longestValidParentheses(string s) {
        stack<int> st;

        // 虚拟边界
        st.push(-1);

        int ans = 0;

        for (int i = 0; i < s.size(); ++i) {

            if (s[i] == '(') {
                st.push(i);
            }
            else {
                // 当前 ')' 尝试匹配一个 '('
                st.pop();

                if (st.empty()) {
                    // 没有左括号可以匹配
                    // 当前 i 成为新的非法边界
                    st.push(i);
                }
                else {
                    // 当前合法括号串长度
                    ans = max(ans, i - st.top());
                }
            }
        }

        return ans;
    }
};
```

# ⑥ 关键设计解释

### 1. 为什么栈存下标，而不是存括号？

因为最后需要计算：

```
i - st.top()
```

得到连续合法子串长度。

如果栈里只存：

```
'('
```

你只能知道括号能不能匹配，却不知道它在字符串里的位置。

---

### 2. 为什么遇到 `)` 要先 `pop()`？

因为当前的 `)` 要和最近一个尚未匹配的 `(` 配对。

栈顶就是最近的左括号。

所以：

```
st.pop();
```

相当于：

```
当前 ')' 抵消一个 '('
```

---

### 3. 为什么 `pop()` 以后栈空，要 `push(i)`？

这表示当前：

```
)
```

没有对应的左括号。

例如：

```
)()()
↑
```

第一个 `)` 是非法的。

所以后面的合法括号串：

```
()()
```

必须从它后面开始。

因此：

```
st.push(i);
```

就是把当前非法位置记录为新的：

> **左边界。**

---

### 4. 为什么栈不为空时长度是：

```
i - st.top()
```

因为 `st.top()` 表示：

> 当前合法括号串左侧最近的“未匹配左括号 / 非法边界”。

所以真正合法区间是：

```
st.top() + 1 ... i
```

长度：

```
i - (st.top() + 1) + 1

= i - st.top()
```

这就是公式来源。

# ⑧ 面试追问

### Q1：为什么不能只统计左右括号数量？

因为题目要求：

> 括号不仅数量相同，还必须匹配顺序正确，并且子串连续。

例如：

```
")("
```

左右各一个，但不是合法括号串。

---

### Q2：时间复杂度？

每个字符：

```
最多入栈一次
最多出栈一次
```

所以：

```
时间 O(n)
空间 O(n)
```

---

### Q3：有没有 O(1) 空间方法？

有。

可以使用：

> 左右各扫描一次 + `left/right` 计数。

但是逻辑比栈版本更绕。

这道题第一次学习，我建议先把：

```
栈 + 下标 + 非法边界
```

彻底掌握。

---

### Q4：DP 能不能做？

可以。

经典定义：

```
dp[i] =
以 s[i] 结尾的最长有效括号长度
```

而且只有：

```
s[i] == ')'
```

时，`dp[i]` 才可能非零。

不过它的状态转移涉及：

```
"...()"
"...))"
```

两类情况，第一次看比栈方法更难理解。

所以这题我推荐：

> **主学栈，DP 作为进阶。**

# ⑨ 复习总结

```
32. 最长有效括号

题型：
栈 + 下标 + 边界

栈存：
左括号下标 / 非法边界

初始化：
stack.push(-1)

遇到 '('：
push(i)

遇到 ')'：
先 pop()

如果 pop 后为空：
说明当前 ')' 无法匹配
push(i)
把它作为新的非法边界

如果不为空：
当前合法长度：
i - stack.top()

不断更新：
ans = max(ans, i - stack.top())
```

最值得你记住的是：

> **栈顶始终代表当前合法括号串左边界的前一个位置。因此匹配成功后，长度就是 `i - st.top()`；如果遇到无法匹配的 `)`，它自己就变成新的边界。**

这题和普通“括号匹配”最大的区别就在这里：普通括号匹配只关心栈空不空，而这题为了求**最长连续长度**，所以必须存**下标**。


对于 **32. 最长有效括号**，动态规划其实很经典，而且它能很好训练你对：

> **“以当前位置结尾的最优状态”**

这种 DP 定义的理解。

这题 DP 比栈稍微绕一点，但只要抓住两个情况就够了。

# 动态规划 ① 破题：DP 要解决什么

例如：

```
s = ")()())"
```

我们希望得到：

```
最长有效括号 = "()()"
长度 = 4
```

DP 的关键不是直接问：

> 前 `i` 个字符最长是多少？

而是定义：

> **`dp[i]` = 必须以 `s[i]` 结尾的最长有效括号子串长度。**

这个“**以 i 结尾**”非常关键。

例如：

```
s = ")()())"

下标： 0 1 2 3 4 5
字符： ) ( ) ( ) )
dp：   0 0 2 0 4 0
```

最终答案就是：

```
所有 dp[i] 中的最大值 = 4
```

---

# ② 核心技巧

首先：

> 有效括号串一定以 `)` 结尾。

所以如果：

```
s[i] == '('
```

那么：

```
dp[i] = 0;
```

我们只需要研究：

```
s[i] == ')'
```

的情况。

而 `)` 又分成两种情况：

```
情况1：

...()

情况2：

...))
```

这就是整道题。

# ③ 情况一：`s[i-1] == '('`

比如：

```
... ( )
    ↑ ↑
   i-1 i
```

当前直接出现了一对：

```

```

所以至少贡献：

```

```

但是前面可能还有合法括号。

例如：

```

  ^^
```

计算最后这个 `)` 时：

```

```

那么：

```

```

准确来说：

```

```

如果：

```

```

就只有：

```

```

因此代码：


# ④ 情况二：`s[i-1] == ')'`

这是难点。

```
      i
```

要去找：

> **前面那段已经匹配好的合法括号之前的那个字符。**

```
下标：
```


也就是：

现在来到：

中间已经有：


# ⑤ 最关键的匹配位置公式

我们把：

```
int j = i - dp[i - 1] - 1;
```

记下来。

它表示：

> 当前 `)` 跳过前面已经匹配成功的那一段之后，理论上应该匹配的左括号位置。

如果：

```
j >= 0 && s[j] == '('
```

说明真的能匹配。

这时候：

```
dp[i] = dp[i - 1] + 2;
```

但还没完。

---

# ⑥ 为什么还要加 `dp[j-1]`？

看这个例子：

```
()(())
```

下标：

```
0 1 2 3 4 5
( ) ( ( ) )
```

计算最后：

```
i = 5
```

前面：

```
s[4] = ')'
```

所以进入第二种情况。

这时候：

```
dp[4] = 2
```

代表：

```
下标 3~4 = ()
```

所以：

```
j = 5 - 2 - 1
  = 2;
```

找到：

```
s[2] = '('
```

它和 `s[5]` 匹配。

于是：

```
( ( ) )
```

这一段长度：

```
dp[4] + 2
= 4
```

但别忘了左边还有：

```
()
```

也就是：

```
下标 0~1
```

它和当前 `(())` 是连续的：

```
() (())
```

所以还要加：

```
dp[j - 1]
```

这里：

```
j = 2

j - 1 = 1

dp[1] = 2
```

最终：

```
dp[5]
= dp[4] + 2 + dp[1]

= 2 + 2 + 2

= 6
```

得到：

```
()(())
```

长度 `6`。

因此第二种情况完整公式：

```
dp[i] =
    dp[i - 1]
    + 2
    + (j >= 1 ? dp[j - 1] : 0);
```

# ⑦ 完整代码

推荐你写这个版本：

```cpp
class Solution {
public:
    int longestValidParentheses(string s) {
        int n = s.size();

        if (n < 2) {
            return 0;
        }

        // dp[i]：
        // 以 s[i] 结尾的最长有效括号长度
        vector<int> dp(n, 0);

        int ans = 0;

        for (int i = 1; i < n; ++i) {

            // 有效括号必须以 ')' 结尾
            if (s[i] == ')') {

                // 情况1：...()
                if (s[i - 1] == '(') {

                    dp[i] =
                        (i >= 2 ? dp[i - 2] : 0) + 2;
                }

                // 情况2：...))
                else {
                    int j = i - dp[i - 1] - 1;

                    // 找到了可以和当前 ')' 匹配的 '('
                    if (j >= 0 && s[j] == '(') {

                        dp[i] =
                            dp[i - 1]
                            + 2
                            + (j >= 1 ? dp[j - 1] : 0);
                    }
                }

                ans = max(ans, dp[i]);
            }
        }

        return ans;
    }
};
```

这题真正需要记的其实只有两种情况。

如果：

```
s[i] = '('
```

```
dp[i] = 0
```

如果：

```
s[i] = ')'
```

### 前一个是 `(`

```
...()
```

直接形成一对：

```
dp[i] = dp[i - 2] + 2;
```

### 前一个是 `)`

```
...))
```

先跳过：

```
dp[i - 1]
```

这一整段合法括号：

```
j = i - dp[i - 1] - 1;
```

如果：

```
s[j] == '('
```

说明能包起来：

```
dp[i] =
    dp[i - 1] + 2 + dp[j - 1];
```

# ⑩ 这题为什么不需要递归

不推荐递归。

因为：

```
dp[i]
```

只依赖前面已经计算好的状态：

```
dp[i-1]
dp[i-2]
dp[j-1]
```

明显是：

> **从左往右递推。**

所以迭代 DP 最自然。

复杂度：

```
时间 O(n)
空间 O(n)
```

```
+ 2
+ dp[j-1]


最后：

ans = max(ans, dp[i])
```

最重要的一句话：

> **如果当前是 `)`：前一个是 `(` 就直接凑成 `()`；前一个也是 `)`，就跳过前面已经匹配好的 `dp[i-1]` 个字符，看看再前面的字符能不能和当前 `)` 配对。**
