## 解题思路

# 118. 杨辉三角

这道题非常适合继续练习你刚开始接触的 **动态规划思想**。

推荐方法：
> **二维 DP / 直接递推构造。**

这题不推荐递归。虽然每个元素都可以递归地去求“左上 + 右上”，但题目本身要求把前 `numRows` 行全部生成出来，直接从上一行推下一行最自然，也不会产生重复计算。

---

# ① 破题：题目真正要求什么

例如：

```cpp
numRows = 5
```

需要生成：

```text
[
    [1],
    [1,1],
    [1,2,1],
    [1,3,3,1],
    [1,4,6,4,1]
]
```

观察每一行：

```text
第 0 行：        1

第 1 行：       1 1

第 2 行：      1 2 1

第 3 行：     1 3 3 1

第 4 行：    1 4 6 4 1
```

有两个非常明显的规律：

```text
1. 每一行最左边和最右边永远是 1。
2. 中间元素 = 上一行左上角 + 右上角。
```

比如：

```text
上一行：  1   3   3   1
                  ↘ ↙

下一行：    1   4   6   4   1
```

其中：

```text
4 = 1 + 3
6 = 3 + 3
4 = 3 + 1
```

所以本题本质就是：

> **已经知道上一行，如何推出下一行。**

---

# ② 核心技巧：当前元素由上一行两个元素得到

我们把：

```cpp
result[i][j]
```

理解成：

> 第 `i` 行第 `j` 个数字。

对于中间位置：

也就是：

```text
当前数字
=
上一行左上角
+
上一行右上角
```

但是这个公式只适用于：

```text
中间位置
```

两边没有两个“上方邻居”，所以边界直接规定：

```cpp
result[i][0] = 1;
result[i][i] = 1;
```

# ③ 图解执行过程

假设：

```cpp
numRows = 5;
```

我们一行一行构造。

### 第 0 行

这一行只有一个元素：

```text
[1]
```

---

### 第 1 行

长度为 `2`：

```text
[1,1]
```

左右边界都是 `1`。

---

### 第 2 行

先初始化：

```text

```

```text
上一行：

 \ /
  2
```

所以：

```cpp

=

=

=
2
```

得到：

```text
[1,2,1]
```

---

### 第 3 行

先：

```text
[1, ?, ?, 1]
```

计算第一个中间元素：

```text
1  2
 \/
 3
```

```cpp
1 + 2 = 3
```

第二个：

```text
2  1
 \/
 3
```

所以：

```text
[1,3,3,1]
```

---

### 第 4 行

先：

```text
[1, ?, ?, ?, 1]
```

计算：

```text

```

得到：

```text
[1,4,6,4,1]
```

```text
[
 [1],
 [1,1],

]
```

# ④ 完整代码

我建议你用这个版本：

```cpp
class Solution {
public:
    vector<vector<int>> generate(int numRows) {
        vector<vector<int>> result;

        for (int i = 0; i < numRows; ++i) {
            // 第 i 行一共有 i + 1 个元素
            vector<int> row(i + 1, 1);

            // 只计算中间部分
            for (int j = 1; j < i; ++j) {
                row[j] =
                    result[i - 1][j - 1]
                    + result[i - 1][j];
            }

            result.push_back(row);
        }

        return result;
    }
};
```

这份代码很值得你自己完整敲一遍。

# ⑤ 关键设计解释

## 1. 为什么第 `i` 行有 `i + 1` 个元素？

因为我们从 `0` 开始编号。

```text
第 0 行：1 个
第 1 行：2 个
第 2 行：3 个
第 3 行：4 个
```

所以：

```cpp
vector<int> row(i + 1, 1);
```

比如：

```cpp
i = 3;
```

就创建：

```text
[1,1,1,1]
```

一共 `4` 个元素。

---

## 2. `vector<int> row(i + 1, 1)` 是什么意思？

这句表示：

> 创建一个长度为 `i + 1` 的 `vector<int>`，所有元素初始化成 `1`。

例如：

```cpp
vector<int> row(5, 1);
```

得到：

```text
[1,1,1,1,1]
```

这特别适合杨辉三角，因为：

```text
每一行左右边界本来就是 1
```

我们只需要修改中间元素。

---

## 3. 为什么内层循环是：

```cpp
for (int j = 1; j < i; ++j)
```

而不是从 `0` 开始？

因为：

```text
j = 0
```

是最左边：

```text
永远为 1
```

而：

```text
j = i
```

是最右边：

```text
永远为 1
```

所以只需要计算：

```text
1 ~ i-1
```

这些中间位置。

例如第 `4` 行：

```text
下标：

0   1   2   3   4

1   ?   ?   ?   1
```

真正需要计算的是：

```text
1、2、3
```

所以：

```cpp
j = 1;
j < i;
```

---

## 4. 为什么访问的是：

```cpp
result[i - 1][j - 1]
```

和：

```cpp
result[i - 1][j]
```

来看位置关系：

```text
上一行：

      j-1    j
       3     3
        \   /
          6
          j

当前行
```

所以当前：

```cpp
row[j]
```

来自上一行：

```cpp
result[i - 1][j - 1]
+
result[i - 1][j]
```

一定要把这个下标关系理解清楚，而不是死记。

---

## 5. 为什么不会出现 `i - 1 = -1`？

第一次：

```cpp
i = 0
```

内层循环条件：

```cpp
j = 1;
j < i;
```

相当于：

```text
1 < 0
```

不成立。

所以内层循环根本不会执行。

不会访问：

```cpp
result[-1]
```

第 1 行也是一样：

```text
j = 1
i = 1

1 < 1
```

不成立。

真正第一次计算中间元素是在：

```text
i = 2
```

此时上一行 `result[1]` 已经存在。

# ⑥ 动态规划怎么理解这道题？

继续套你上一题“爬楼梯”的 DP 思考步骤。

### 1. 状态是什么？

可以理解：

```text
dp[i][j]
=
杨辉三角第 i 行第 j 个元素
```

---

### 2. 状态转移

中间元素：

```cpp
dp[i][j]
=
dp[i - 1][j - 1]
+
dp[i - 1][j];
```

---

### 3. 初始化

每一行左右边界：

```cpp
dp[i][0] = 1;
dp[i][i] = 1;
```

---

### 4. 遍历顺序

当前行依赖上一行：

```text
第 0 行
↓
第 1 行
↓
第 2 行
↓
第 3 行
```

因此必须：

```cpp
for (int i = 0; i < numRows; ++i)
```

从上往下构造。

---

### 5. 最终答案

这题和普通 DP 有一点区别。

普通 DP 可能只要求：

```text
dp[n]
```

但这道题要求：

> 所有前 `numRows` 行。

所以整个：

```cpp
result
```

就是答案。

---

# ⑦ 为什么不推荐递归？

理论上完全可以递归算某个位置：

```text
f(i,j)
=
f(i-1,j-1) + f(i-1,j)
```

但会产生大量重复计算。

比如：

```text
          f(4,2)
          /    \
      f(3,1)  f(3,2)
       / \      / \
      ...      ...
```

很多位置会被重复求。

而且题目本身要求：

```text
整张杨辉三角
```

所以最自然的方法就是：

> 从第一行开始，一行一行往下生成。

因此这题没有必要为了递归而递归。

# ⑧ 面试追问

### Q1：时间复杂度是多少？

一共需要生成：

```text
1 + 2 + 3 + ... + numRows
```

个元素。

所以时间复杂度：

```text
O(numRows²)
```

---

### Q2：空间复杂度是多少？

答案本身就要保存整个三角形：

```text
O(numRows²)
```

如果不计算最终返回结果所占空间，那么额外辅助空间很小。

---

### Q3：能不能把空间优化成 O(numRows)？

如果题目只让你求：

> 杨辉三角的第 `k` 行

那当然可以只维护一维数组。

但是当前题目要求：

```cpp
vector<vector<int>>
```

把所有行都返回。

因此最终答案本身就已经需要：

```text
O(numRows²)
```

空间，没有必要强行优化掉结果存储。

---

### Q4：为什么这是 DP？

因为当前状态：

```text
第 i 行
```

可以直接利用已经求出的：

```text
第 i-1 行
```

而不是重新计算。

它符合：

```text
当前状态 ← 前面已经计算出的状态
```

这一典型动态规划特征。

---

### 面试表达

> 我从上到下逐行构造杨辉三角。第 `i` 行有 `i+1` 个元素，左右边界固定为 1。对于中间位置 `j`，根据杨辉三角性质，它等于上一行的左上元素与右上元素之和，也就是 `result[i-1][j-1] + result[i-1][j]`。因此每一行可以直接由上一行递推得到。总共生成约 `numRows²/2` 个元素，所以时间和结果空间复杂度都是 `O(numRows²)`。
