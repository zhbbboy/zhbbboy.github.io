这题非常经典，而且核心比看起来简单很多。

最推荐你掌握：

> **一次遍历 + 维护历史最低买入价。**

本质是：

> 对于每一天，如果今天卖出，那么最好的买入时机一定是“今天之前价格最低的那一天”。

---

## ① 破题：题目真正要求什么

例如：

```
prices = [7,1,5,3,6,4]
```

你只能：

```
买一次
卖一次
```

并且必须：

```
先买
后卖
```

不能：

```
第5天买
第2天卖
```

因为时间不能倒流。

这里：

```
第2天价格 = 1
第5天价格 = 6
```

所以：

```
利润 = 6 - 1 = 5
```

答案：

```
5
```

---

# ② 核心技巧

假设我们正在遍历到某一天：

```
今天股价 = prices[i]
```

如果决定：

> **今天卖出**

那么应该在哪一天买？

当然是在：

> 今天之前价格最低的那一天。

所以我们只需要始终维护：

```
minPrice
```

表示：

> **到目前为止出现过的最低股票价格。**

然后每天计算：

```
prices[i] - minPrice
```

表示：

> 如果今天卖出，最多能赚多少钱。

再维护：

```
maxProfit
```

记录历史最大利润。

---

# ③ 图解执行过程

还是：

```
prices = [7,1,5,3,6,4]
```

初始化：

```
minPrice = 7
maxProfit = 0
```

---

### 第一天：7

```
价格 = 7
```

最低价格：

```
minPrice = 7
```

还不能真正赚钱。

```
maxProfit = 0
```

---

### 第二天：1

当前价格：

```
1
```

发现：

```
1 < 7
```

所以最低价格更新：

```
minPrice = 1
```

相当于：

> 到目前为止，最好的买入价格变成了 1。

---

### 第三天：5

如果今天卖：

```
利润 = 5 - 1
     = 4
```

所以：

```
maxProfit = 4
```

此时：

```
买入：1
卖出：5

利润：4
```

---

### 第四天：3

如果今天卖：

```
3 - 1 = 2
```

但是：

```
2 < 4
```

所以：

```
maxProfit = 4
```

不变。

---

### 第五天：6

如果今天卖：

```
6 - 1 = 5
```

发现：

```
5 > 4
```

所以：

```
maxProfit = 5
```

---

### 第六天：4

如果今天卖：

```
4 - 1 = 3
```

没有超过 5。

最终：

```
maxProfit = 5
```

答案：

```
5
```

# ④ 完整代码

推荐你写这个版本：

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int minPrice = prices[0];
        int maxProfit = 0;

        for (int i = 1; i < prices.size(); ++i) {
            minPrice = min(minPrice, prices[i]);

            int profit = prices[i] - minPrice;

            maxProfit = max(maxProfit, profit);
        }

        return maxProfit;
    }
};
```

---

# ⑤ 每一行是什么意思

先：

```
int minPrice = prices[0];
```

表示：

> 当前见过的最低价格。

刚开始只有第一天，所以：

```
minPrice = 第一天价格
```

---

然后：

```
int maxProfit = 0;
```

因为题目说：

> 如果不能获得利润，返回 0。

例如：

```
[7,6,4,3,1]
```

一直跌。

最好的选择就是：

```
不交易
```

利润：

```
0
```

所以初始化：

```
maxProfit = 0;
```

很合理。

---

然后：

```
for (int i = 1; i < prices.size(); ++i)
```

为什么从：

```
i = 1
```

开始？

因为：

```
prices[0]
```

已经被我们用来初始化：

```
minPrice
```

了。

---

最核心两句：

```
minPrice = min(minPrice, prices[i]);
```

意思：

> 更新截至今天为止的最低价格。

然后：

```
int profit = prices[i] - minPrice;
```

意思：

> 假设今天卖出，那么能获得多少利润。

最后：

```
maxProfit = max(maxProfit, profit);
```

保存最大利润。

---

# ⑥ 一个非常重要的问题：这样会不会出现“今天买今天卖”？

你可能注意到：

```
minPrice = min(minPrice, prices[i]);

int profit = prices[i] - minPrice;
```

我们先更新了 `minPrice`。

比如今天价格突然变成：

```
1
```

那么：

```
minPrice = 1
```

接下来：

```
profit = 1 - 1 = 0
```

相当于：

```
今天买
今天卖
```

这会不会有问题？

不会。

因为这种情况利润只是：

```
0
```

不会影响最大答案。

不过如果你想让逻辑更加严格地表达：

> 今天卖出时，只能使用今天之前的最低价格。

也可以写成：

```
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int minPrice = prices[0];
        int maxProfit = 0;

        for (int i = 1; i < prices.size(); ++i) {

            // 先假设今天卖出
            maxProfit = max(
                maxProfit,
                prices[i] - minPrice
            );

            // 再考虑今天是否成为新的最低买入价
            minPrice = min(
                minPrice,
                prices[i]
            );
        }

        return maxProfit;
    }
};
```

这个版本从语义上更清楚：

```
先：
今天卖的话能赚多少？

再：
今天价格是否适合未来买入？
```

我更推荐你记这个顺序。

---

# ⑦ 为什么只需要记录最低价格？

你可能会想到：

> 难道不用记最低价格是哪一天吗？

不用。

题目只问：

```
最大利润是多少
```

没有问：

```
具体第几天买、第几天卖
```

所以只需要价格：

```
minPrice
```

就够了。

因为遍历是：

```
从左到右
```

所以 `minPrice` 永远来自：

```
当前天或者当前天之前
```

自然保证了：

```
买入时间 <= 卖出时间
```

如果我们采用“先计算利润，再更新 minPrice”的版本，则更严格地保证：

```
买入时间 < 卖出时间
```

---

# ⑧ 为什么不能直接找全局最小值和全局最大值？

这是一个非常容易犯的错误。

例如：

```
prices = [7,6,4,3,10,1,20]
```

这里：

```
全局最小 = 1
全局最大 = 20
```

这个例子恰好能交易：

```
1 -> 20
```

没问题。

但看：

```
prices = [2,10,1]
```

全局：

```
最小 = 1
最大 = 10
```

如果直接：

```
10 - 1 = 9
```

就错了。

因为：

```
10出现在前面
1出现在后面
```

你不能：

```
先在1买
再回到过去10卖
```

真正答案：

```
2买
10卖

利润 = 8
```

所以这题不能简单：

```
最大值 - 最小值
```

关键约束是：

> **买入必须发生在卖出之前。**

而“从左往右维护历史最低价”天然满足这个条件。

---

# ⑨ 这题其实也可以理解成动态规划

虽然最简单的理解是：

```
贪心 / 一次遍历
```

但它也可以理解成一个非常简单的 DP。

定义：

```
minPrice
```

其实就是：

> 前 i 天的最低价格。

而：

```
maxProfit
```

就是：

> 前 i 天能够获得的最大利润。

每天状态变化：

```
今天价格
      ↓
更新历史最低价
      ↓
计算今天卖出的利润
      ↓
更新最大利润
```

不过这题没必要写一个：

```
vector<int> dp
```

因为只需要前面的两个状态，所以直接用两个变量就够了。

---

# ⑩ 再看下降数组

例如：

```
prices = [7,6,4,3,1]
```

过程：

```
minPrice：
7 → 6 → 4 → 3 → 1
```

每天利润：

```
6 - 7 = -1
4 - 6 = -2
3 - 4 = -1
1 - 3 = -2
```

但是：

```
maxProfit
```

初始就是：

```
0
```

所以它永远不会被负数替换。

最终：

```
return 0;
```

符合题意。

---

# ⑪ 时间复杂度

只遍历一次数组：

```
时间复杂度：O(n)
```

只用了：

```
minPrice
maxProfit
```

两个变量：

```
空间复杂度：O(1)
```

这是最优解。

---

# ⑫ 递归还是迭代？

这题明显推荐：

> **迭代。**

递归完全没有必要。

因为我们只需要从左到右扫描一次，并维护两个状态：

```
历史最低价格
历史最大利润
```

---

# ⑬ 面试追问

面试官很可能会问：

**为什么这个方法一定不会漏掉答案？**

你可以回答：

> 对于任意一天 `i`，如果选择第 `i` 天卖出，那么最大利润一定来自第 `i` 天之前的最低价格。因此遍历时维护历史最低价格 `minPrice`，就能求出“以今天为卖出日”的最大利润。再对所有卖出日取最大值，就得到全局最大利润。

这句话非常值得记。

# ⑭ 复习总结

以后复习可以直接看：

```
121 买卖股票最佳时机

只能：

买一次
卖一次

而且：

先买后卖


核心：

遍历每一天，
维护之前的最低价格。


minPrice：

到目前为止
最便宜的买入价格


maxProfit：

到目前为止
最大的利润


每一天：

今天卖出的利润：

prices[i] - minPrice

更新：

maxProfit

然后：

minPrice =
min(minPrice, prices[i])


复杂度：

时间 O(n)
空间 O(1)
```

最核心的一句话：

> **把每一天都当成“卖出日”，那么这一天能获得的最大利润，就是“今天价格 − 今天之前出现过的最低价格”；遍历所有天取最大值即可。**
