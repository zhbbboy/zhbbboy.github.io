这题最推荐的思路是：

> **先记录每个字母最后一次出现的位置，再用贪心维护当前片段的最远右边界。**

核心非常像你刚做的跳跃游戏：

- 跳跃游戏：维护当前能覆盖到的最远位置
- 这题：维护当前片段必须覆盖到的最远位置

---

## ① 破题：题目真正要求什么

例如：

```
s = "ababcbacadefegdehijhklij"
```

题目要求把字符串切成尽可能多的片段，并且：

> 同一个字母最多只能出现在一个片段里。

正确划分：

```
"ababcbaca" | "defegde" | "hijhklij"
```

长度：

```
[9,7,8]
```

---

问题关键在于：

假设当前片段里已经出现了：

```
a
```

那么这个片段就必须一直包含到：

> `a` 最后一次出现的位置。

比如：

```
a b a b c b a c a
↑               ↑
第一次a         最后一次a
```

既然开头已经把 `a` 放进这个片段，那么最后那个 `a` 也必须属于这个片段。

否则：

```
a 出现在两个不同片段
```

违反题意。

---

# ② 核心技巧：先记录每个字母最后出现的位置

字符串：

```
s = "ababcbaca"
```

下标：

```
0 1 2 3 4 5 6 7 8
a b a b c b a c a
```

那么：

```
a 最后出现位置 = 8
b 最后出现位置 = 5
c 最后出现位置 = 7
```

所以先准备：

```
vector<int> last(26);
```

遍历字符串：

```
for (int i = 0; i < s.size(); ++i) {
    last[s[i] - 'a'] = i;
}
```

例如处理 `'a'`：

```
s[i] - 'a'
```

就是：

```
'a' - 'a' = 0
'b' - 'a' = 1
'c' - 'a' = 2
...
```

所以：

```
last[0]
```

保存 `'a'` 最后一次出现的位置。

---

# ③ 第二次遍历：维护当前片段的最远右边界

我们需要两个变量：

```
int start = 0;
int end = 0;
```

含义：

```
start
当前片段的起点

end
当前片段必须延伸到的最远位置
```

每遇到一个字符：

```
end = max(end, last[s[i] - 'a']);
```

什么意思？

> 当前片段既然包含了 `s[i]`，那么至少必须延伸到这个字符最后一次出现的位置。

而且当前片段里可能已经出现了很多字符，所以取：

```
max
```

保留最远的那个右边界。

---

# ④ 用 `"ababcbaca"` 跑一遍

先得到：

```
a -> 8
b -> 5
c -> 7
```

初始化：

```
start = 0
end = 0
```

---

### i = 0，字符 `'a'`

```
end = max(0, last['a']);
```

也就是：

```
end = max(0,8)
    = 8
```

这意味着：

> 因为当前片段出现了 `a`，所以这个片段至少必须延伸到下标8。

当前：

```
a b a b c b a c a
↑               ↑
start           end
0               8
```

---

### i = 1，字符 `'b'`

`b` 最后出现：

```
5
```

所以：

```
end = max(8,5);
```

还是：

```
end = 8
```

---

### i = 2，字符 `'a'`

最后位置：

```
8
```

所以：

```
end = 8
```

---

### i = 4，字符 `'c'`

最后位置：

```
7
```

所以：

```
end = max(8,7)
    = 8
```

---

最后扫描到：

```
i = 8
```

发现：

```
i == end
```

即：

```
8 == 8
```

这是什么意思？

> 当前片段中所有出现过的字母，它们最后一次出现的位置都已经包含进来了。

所以：

> 这里可以安全切一刀。

片段：

```
s[0..8]
```

长度：

```
end - start + 1
```

即：

```
8 - 0 + 1 = 9
```

加入答案：

```
result.push_back(9);
```

然后下一段起点：

```
start = end + 1;
```

即：

```
start = 9
```

---

# ⑤ 为什么一定要不断更新 `end`？

这是这题最关键的地方。

比如：

```
a ...
```

假设 `a` 最后出现：

```
8
```

所以当前片段最初必须到：

```
8
```

但是在 `[0,8]` 这段里面，又遇到了一个字母：

```
x
```

而 `x` 最后出现的位置可能是：

```
12
```

那么怎么办？

因为当前片段已经包含了 `x`，所以：

> `x` 的所有出现也必须全部放进当前片段。

于是当前片段就必须继续延伸到：

```
12
```

所以：

```
end = max(end, last[s[i] - 'a']);
```

本质就是不断扩张当前区间。

---

# ⑥ 为什么 `i == end` 就能切？

假设：

```
当前片段：

start ---------------- end
```

当扫描到：

```
i == end
```

说明：

> 当前片段里所有已经出现过的字符，它们最后一次出现的位置都没有超过 `end`。

也就是说这些字符：

```
以后不会再出现了
```

因此从：

```
end + 1
```

开始的新片段，不可能再次出现前一个片段里的字符。

所以这里就是合法分割点。

# ⑦ 完整代码

推荐你掌握这个版本：

```cpp
class Solution {
public:
    vector<int> partitionLabels(string s) {
        vector<int> last(26);

        // 1. 记录每个字母最后出现的位置
        for (int i = 0; i < s.size(); ++i) {
            last[s[i] - 'a'] = i;
        }

        vector<int> result;

        int start = 0;
        int end = 0;

        // 2. 贪心划分区间
        for (int i = 0; i < s.size(); ++i) {

            // 当前片段至少要延伸到
            // 当前字符最后一次出现的位置
            end = max(end, last[s[i] - 'a']);

            // 当前片段扫描完成，可以切一刀
            if (i == end) {
                result.push_back(end - start + 1);

                start = end + 1;
            }
        }

        return result;
    }
};
```

---

# ⑧ 最重要的两行

第一行：

```
end = max(end, last[s[i] - 'a']);
```

意思：

> 当前字符既然进入了这个片段，那么当前片段必须至少覆盖到它最后一次出现的位置。

第二行：

```
if (i == end)
```

意思：

> 我已经扫描到当前片段所有字符要求的最远位置了，所以这个片段可以结束。

然后：

```
result.push_back(end - start + 1);
```

保存这一段长度。

---

# ⑨ 为什么这是贪心？

我们的目标是：

> 分成尽可能多的片段。

所以希望：

> 每个片段尽可能早结束。

但是又不能乱切。

我们一直等到：

```
i == end
```

也就是：

> 当前片段里的所有字母都已经不会再出现在后面。

这就是**最早合法分割点**。

在最早合法的位置立即切开：

> 自然能够留下最多空间给后面继续划分。

因此是贪心。

# ⑪ 为什么不是看到某个字母最后一次出现就直接切？

比如：

```
当前字符 a 的最后位置到了
```

不能只看 `a`。

因为当前片段里可能还包含：

```
b、c、d
```

而其中某个字母可能在更远的位置再次出现。

所以我们不能维护：

```
当前字符自己的最后位置
```

而必须维护：

```
end = max(...)
```

即：

> **当前片段里所有字符最后位置的最大值。**

---

# ⑫ 递归是否适合？

不适合。

这题是典型的：

```
预处理最后位置
+
从左到右贪心扫描
```

没有必要递归。

---

# ⑬ 时间复杂度

第一次遍历：

```
记录每个字母最后位置
O(n)
```

第二次遍历：

```
划分区间
O(n)
```

所以：

```
总时间 O(n)
```

`last` 只有 26 个：

```
额外空间 O(1)
```

如果不算返回结果的话。

# ⑭ 面试追问

### 为什么只记录最后出现位置就够了？

因为一个片段是否合法，关键在于：

> 片段里出现过的字符，是否还会在片段外再次出现。

只要知道每个字符：

```
最后一次出现的位置
```

就能判断当前片段最少必须扩展到哪里。

---

### 为什么 `start` 不参与 `end` 的计算？

因为：

```
start
```

只是用来计算：

```
end - start + 1
```

当前片段长度。

真正决定片段能不能结束的是：

```
当前扫描位置 i
和
当前最远边界 end
```
