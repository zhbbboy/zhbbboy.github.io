这题非常适合接在你刚做的 **35 搜索插入位置** 后面。

核心其实还是二分查找，只不过这次不是找到 `target` 就结束，而是要找：

> **第一个等于 target 的位置 + 最后一个等于 target 的位置。**

最推荐你用：

> **两次二分查找。**

第一次找左边界，第二次找右边界。

---

# ① 破题：题目真正要求什么

例如：

```
nums = [5,7,7,8,8,10]
target = 8
```

下标：

```
下标：  0  1  2  3  4   5
nums：  5  7  7  8  8  10
                ↑  ↑
                3  4
```

所以返回：

```
[3,4]
```

如果：

```
target = 6
```

数组中不存在：

```
[-1,-1]
```

---

# ② 核心技巧：找到 target 后不能直接 return

普通二分：

```
if (nums[mid] == target)
    return mid;
```

这题不能这么干。

因为例如：

```
nums = [5,7,7,8,8,10]
```

你找到：

```
下标3的 8
```

只能说明：

> 找到了一个 `8`。

但你不知道：

```
左边还有没有8？
右边还有没有8？
```

所以需要继续向两边逼近。

---

## 左边界

目标：

> 找第一个 `target`。

如果：

```
nums[mid] == target
```

虽然找到一个，但还得继续：

```
往左找
```

所以：

```
right = mid - 1;
```

---

## 右边界

目标：

> 找最后一个 `target`。

如果：

```
nums[mid] == target
```

还得继续：

```
往右找
```

所以：

```
left = mid + 1;
```

这就是两次二分最大的区别。

---

# ③ 图解执行过程

使用：

```
nums = [5,7,7,8,8,10]
target = 8
```

---

## 第一次：找最左边的 8

初始：

```
left = 0
right = 5
```

### 第一次

```
mid = 2
nums[2] = 7
```

因为：

```
7 < 8
```

所以：

```
left = mid + 1;
```

得到：

```
left = 3
right = 5
```

---

### 第二次

```
mid = 4
nums[4] = 8
```

找到 `8`。

但是我们要找的是：

> 第一个 8。

所以不能结束。

先记录：

```
ans = 4;
```

然后继续往左：

```
right = mid - 1;
```

得到：

```
left = 3
right = 3
```

---

### 第三次

```
mid = 3
nums[3] = 8
```

再次找到。

更新：

```
ans = 3;
```

继续向左：

```
right = 2;
```

循环结束。

所以：

```
leftBoundary = 3
```

---

# 第二次：找最右边的 8

重新：

```
left = 0
right = 5
```

过程类似。

找到 `8` 时：

```
ans = mid;
```

但是这次继续：

```
left = mid + 1;
```

最终找到：

```
rightBoundary = 4
```

答案：

```
{3,4}
```

# ④ 完整代码

这个版本最好理解：

```cpp
class Solution {
private:
    // 找第一个 target
    int findLeft(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size() - 1;

        int ans = -1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                ans = mid;

                // 已经找到，但继续往左找
                right = mid - 1;
            }
            else if (nums[mid] < target) {
                left = mid + 1;
            }
            else {
                right = mid - 1;
            }
        }

        return ans;
    }

    // 找最后一个 target
    int findRight(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size() - 1;

        int ans = -1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                ans = mid;

                // 已经找到，但继续往右找
                left = mid + 1;
            }
            else if (nums[mid] < target) {
                left = mid + 1;
            }
            else {
                right = mid - 1;
            }
        }

        return ans;
    }

public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int leftIndex = findLeft(nums, target);

        // 连一个 target 都没有找到
        if (leftIndex == -1) {
            return {-1, -1};
        }

        int rightIndex = findRight(nums, target);

        return {leftIndex, rightIndex};
    }
};
```

# ⑤ 关键设计解释

## 1. 为什么需要 `ans = -1`？

因为有可能：

```
target
```

根本不存在。

例如：

```
nums = [5,7,7,8,8,10]
target = 6
```

整个二分过程中永远不会：

```
nums[mid] == target
```

所以：

```
ans
```

一直保持：

```
-1
```

自然表示：

> 没找到。

---

# 2. 为什么找左边界时，找到以后还要：

```
right = mid - 1;
```

例如：

```
7 7 7 7
    ↑
   mid
```

你找到中间这个 `7`。

但：

```
左边可能还有7
```

所以必须缩小到左半边：

```
7 7
↑ ↑
继续找
```

最终才会停在第一个。

---

# 3. 为什么找右边界相反？

因为我们想找最后一个。

找到：

```
nums[mid] == target
```

之后：

```
右边可能还有 target
```

所以：

```
left = mid + 1;
```

继续向右。

---

# 4. 为什么找到的时候要先：

```
ans = mid;
```

因为后面继续搜索以后，有可能再也找不到 target。

例如：

```
nums = [5,7,7,8,8,10]
target = 8
```

你已经在：

```
mid = 4
```

找到 `8`。

为了找左边界，又继续向左。

所以我们先记录：

```
ans = 4;
```

如果后面发现更左的 `8`：

```
ans = 3
```

覆盖掉。

如果没发现：

```
ans = 4
```

至少保留刚刚找到的结果。

---

# ⑥ 和 35 搜索插入位置有什么关系

实际上这道题也可以完全使用你刚刚学的：

> **找第一个 `>= target` 的位置。**

左边界就是：

```
第一个 >= target
```

然后检查这个位置是否真的等于 target。

右边界则可以转化为：

> **第一个 > target 的位置 - 1。**

例如：

```
nums：

5  7  7  8  8  10
         ↑      ↑
         3      5
```

对于：

```
target = 8
```

第一个：

```
>= 8
```

的位置：

```
3
```

第一个：

```
> 8
```

的位置：

```
5
```

因此最后一个 `8`：

```
5 - 1 = 4
```

所以从本质来看：

```
左边界 = lower_bound(target)

右边界 = upper_bound(target) - 1
```

这也是面试里很常见的说法。

# ⑦ 用你刚学的 lower_bound 风格也可以这样写

如果你更想统一二分模板，可以写一个：

```
// 找第一个 >= target 的位置
int lowerBound(vector<int>& nums, int target) {
    int left = 0;
    int right = nums.size();

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] >= target) {
            right = mid;
        }
        else {
            left = mid + 1;
        }
    }

    return left;
}
```

然后再写一个：

```
// 找第一个 > target 的位置
int upperBound(vector<int>& nums, int target) {
    int left = 0;
    int right = nums.size();

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] > target) {
            right = mid;
        }
        else {
            left = mid + 1;
        }
    }

    return left;
}
```

最终：

```
class Solution {
private:
    int lowerBound(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size();

        while (left < right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] >= target) {
                right = mid;
            }
            else {
                left = mid + 1;
            }
        }

        return left;
    }

    int upperBound(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size();

        while (left < right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] > target) {
                right = mid;
            }
            else {
                left = mid + 1;
            }
        }

        return left;
    }

public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int left = lowerBound(nums, target);

        if (left == nums.size() || nums[left] != target) {
            return {-1, -1};
        }

        int right = upperBound(nums, target) - 1;

        return {left, right};
    }
};
```

# ⑧ 面试追问

这题最核心的追问是：

> 为什么普通二分找到 target 后不能直接返回？

因为：

```
nums 中允许出现重复元素
```

当前找到的 target 不一定是：

```
第一个
或者
最后一个
```

所以必须继续搜索边界。

时间复杂度：

```
找左边界：O(log n)
找右边界：O(log n)

总共：
O(log n)
```

因为：

```
2 × log n
```

忽略常数仍然是：

```
O(log n)
```

空间：

```
O(1)
```

```

右：

```

最值得记住的一句话：

> **二分找边界时，“找到 target”不是结束，而是先记录答案，再继续往目标边界方向搜索：找第一个就往左，找最后一个就往右。**
