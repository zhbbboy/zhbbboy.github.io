## 解题思路

这道题是一个很经典的 **动态规划 + 完全背包思想**。

推荐主方法：

> **一维 DP：`dp[i]` 表示组成整数 `i` 最少需要多少个完全平方数。**

这题其实和你前面做的“爬楼梯”“打家劫舍”“单词拆分”一样，本质都是：

> 当前状态 `dp[i]`，由更小的状态转移过来。

---

## ① 破题：题目真正要求什么

例如：

```
n = 12
```

完全平方数有：

```
1, 4, 9
```

因为：

```
1 = 1²
4 = 2²
9 = 3²
```

我们希望用这些数相加得到 `12`，并且使用的数量最少。

例如：

```
12 = 4 + 4 + 4
```

用了 `3` 个。

也可以：

```
12 = 9 + 1 + 1 + 1
```

用了 `4` 个。

所以答案是：

```
3
```

再比如：

```
n = 13
```

可以：

```
13 = 9 + 4
```

只用了 `2` 个，因此答案是：

```
2
```

---

# ② 核心技巧：考虑“最后加入哪个平方数”

这是这题最重要的 DP 思路。

假设我们正在计算：

```
dp[i]
```

表示：

> 组成整数 `i` 最少需要多少个完全平方数。

假设最后一个使用的平方数是：

```
j²
```

那么在加入 `j²` 之前，我们需要先组成：

```
i - j²
```

而组成：

```
i - j²
```

最少需要：

```
dp[i - j * j]
```

个平方数。

现在再加上最后这个：

```
j²
```

所以总数量：

```
dp[i - j * j] + 1
```

因为最后这个平方数 `j²` 自己占 `1` 个。

于是我们枚举所有满足：

```
j² <= i
```

的平方数，然后取最小值。

核心状态转移是：

```cpp
dp[i] = min(
    dp[i],
    dp[i - j * j] + 1
);
```

一句话：

> **枚举最后一个平方数 `j²`，看看从 `i-j²` 转移过来要几个，取最少。**

以：

```
n = 12
```

为例。

定义：

```
dp[i] = 组成 i 最少需要几个完全平方数
```

首先：

```
dp[0] = 0
```

## 计算 `dp[1]`

可用平方数只有：

```
1
```

所以：

```
1 = 0 + 1
```

因此：

```
dp[1] = dp[0] + 1 = 1;
```

---

## 计算 `dp[2]`

平方数还是只有：

```
1
```

所以：

```
2 = 1 + 1
```

```
dp[2] = dp[1] + 1 = 2;
```

---

## 计算 `dp[3]`

```
3 = 1 + 1 + 1
```

所以：

```
dp[3] = 3;
```

---

## 计算 `dp[4]`

现在平方数可以选：

```
1
4
```

如果最后选 `1`：

```
dp[3] + 1 = 3 + 1 = 4
```

如果最后选 `4`：

```
dp[0] + 1 = 0 + 1 = 1
```

取最小：

```
dp[4] = 1
```

这说明：

```
4 本身就是完全平方数
```

---

## 计算 `dp[5]`

平方数可以选：

```
1
4
```

最后选 `1`：

```
dp[4] + 1
= 1 + 1
= 2
```

对应：

```
4 + 1
```

最后选 `4`：

```
dp[1] + 1
= 1 + 1
= 2
```

所以：

```
dp[5] = 2
```

平方数：

```
1, 4, 9
```

尝试最后一个选 `1`：

```
dp[11] + 1
```

最后选 `4`：

```
dp[8] + 1
```

最后选 `9`：

```
dp[3] + 1
```

其中：

```
dp[8] = 2
```

因为：

```
8 = 4 + 4
```

所以：

```
dp[8] + 1 = 3
```

对应：

```
4 + 4 + 4
```

因此：

```
dp[12] = 3
```

# ④ 完整代码

```cpp
class Solution {
public:
    int numSquares(int n) {
        vector<int> dp(n + 1, INT_MAX);

        dp[0] = 0;

        for (int i = 1; i <= n; ++i) {
            for (int j = 1; j * j <= i; ++j) {
                dp[i] = min(
                    dp[i],
                    dp[i - j * j] + 1
                );
            }
        }

        return dp[n];
    }
};
```

# ⑤ 关键设计解释

## 1. `dp[i]` 到底表示什么？

一定要记准确：

```
dp[i]
=
组成整数 i 最少需要多少个完全平方数
```

例如：

```
dp[12] = 3
```

表示：

```
12 最少需要 3 个完全平方数
```

一种方案：

```
4 + 4 + 4
```

---

## 2. 为什么 `dp[0] = 0`？

因为：

```
组成 0
```

不需要任何平方数。

所以：

```
dp[0] = 0;
```

更重要的是，它是递推的起点。

例如：

```
i = 4
j = 2
```

有：

```
dp[4 - 4] + 1
= dp[0] + 1
= 1
```

这样才能正确得到：

```
dp[4] = 1
```

表示 `4` 本身就是一个平方数。

---

## 3. 为什么初始化成 `INT_MAX`？

我们要求的是最小值：

```
dp[i] = min(...)
```

所以一开始要给一个足够大的值：

```
vector<int> dp(n + 1, INT_MAX);
```

表示：

> 目前还没有找到合法方案。

然后不断用更小的值更新它。

如果一开始写成：

```
0
```

那么：

```
min(0, 其他正数)
```

永远还是 `0`，就错了。

---

## 4. 为什么 `+1`？

因为：

```
dp[i - j*j]
```

只是组成剩余部分所需的最少个数。

现在我们又选了一个：

```
j²
```

所以总数量要再加一个：

```
dp[i - j*j] + 1
```

例如：

```
12
```

最后选 `4`：

```
剩下 8
```

而：

```
dp[8] = 2
```

表示 `8` 最少需要两个平方数：

```
4 + 4
```

再加最后这个 `4`：

```
4 + 4 + 4
```

所以：

```
2 + 1 = 3
```

---

## 5. 为什么循环条件是：

```
j * j <= i
```

因为我们只能选择不超过当前目标 `i` 的平方数。

例如：

```
i = 5
```

平方数：

```
1² = 1
2² = 4
3² = 9
```

`9 > 5`，显然不能选。

所以只需要枚举：

```
1, 4
```

---

## 6. 为什么平方数可以重复使用？

例如：

```
12 = 4 + 4 + 4
```

同一个平方数 `4` 使用了三次。

这也是为什么这道题有明显的：

> **完全背包**

特征。

完全背包的典型特点就是：

```
一个物品可以使用无限次
```

这里可以把：

```
1, 4, 9, 16, ...
```

看成“物品”。

目标是：

```
凑出 n
```

而价值不是最大化，而是：

```
使用物品数量最少
```

# ⑥ 动态规划五步法

这题你可以这样复习。

### 1. 定义状态

```
dp[i]
=
凑出整数 i 最少需要多少个完全平方数
```

### 2. 状态转移

枚举最后一个平方数：

```
j²
```

则：

```
dp[i] = min(
    dp[i],
    dp[i - j*j] + 1
);
```

### 3. 初始化

```
dp[0] = 0;
```

其他：

```
INT_MAX
```

### 4. 遍历顺序

从小到大：

```
for (int i = 1; i <= n; ++i)
```

因为：

```
dp[i]
```

依赖更小的：

```
dp[i - j²]
```

### 5. 返回答案

```
return dp[n];
```

# ⑦ 为什么不推荐普通递归？

递归也很容易写出：

```
f(n)
=
1 + min(
    f(n-1),
    f(n-4),
    f(n-9),
    ...
)
```

但是会重复计算大量子问题。

例如：

```
f(12)
```

可能算：

```
f(11)
f(8)
f(3)
```

而这些内部又会反复调用同样的小状态。

加入记忆化之后当然可以优化。

但本题：

> 状态简单、依赖方向明确、从小到大递推非常自然。

所以直接 DP 更推荐。

# ⑧ 面试追问

## Q1：为什么这题是完全背包？

因为每个完全平方数：

```
1,4,9,16,...
```

都可以重复使用任意次。

例如：

```
12 = 4 + 4 + 4
```

同一个“物品 4”被用了多次。

---

## Q2：和零钱兑换很像吗？

非常像。

假设零钱：

```
coins = [1,4,9,...]
```

目标：

```
amount = n
```

问：

> 最少使用多少枚硬币凑出 n？

这和这题几乎就是同一个 DP 模型。

所以之后你做：

> LeetCode 322. 零钱兑换

会发现状态转移非常类似：

```
dp[i] = min(dp[i], dp[i - coin] + 1);
```

---

## Q3：时间复杂度是多少？

外层：

```
1 ~ n
```

内层平方数数量最多：

```
√n
```

所以：

```
时间复杂度 O(n√n)
```

空间：

```
dp 数组 O(n)
```

---

## Q4：如果 `n` 本身就是完全平方数呢？

例如：

```
n = 16
```

当：

```
j = 4
```

有：

```
dp[16] = min(
    dp[16],
    dp[0] + 1
);
```

得到：

```
1
```

所以会自然处理，不需要额外判断。

---

## Q5：为什么这题不用贪心？

比如 `12`，你如果每次都选不超过当前值的最大平方数：

```
先选 9
剩 3
```

然后：

```
1 + 1 + 1
```

共：

```
4 个
```

但最优解其实：

```
4 + 4 + 4
```

只有：

```
3 个
```

所以：

> 局部选最大平方数，不保证全局最优。

这就是为什么不能简单贪心。

---

## 面试表达

> 我定义 `dp[i]` 表示组成整数 `i` 所需的最少完全平方数个数。对于每个 `i`，枚举所有不超过 `i` 的完全平方数 `j²`，如果最后选择的是 `j²`，那么前面的部分就是 `i-j²`，因此状态转移为 `dp[i] = min(dp[i], dp[i-j²] + 1)`。初始化 `dp[0]=0`，其他状态设为无穷大。最终返回 `dp[n]`。时间复杂度为 `O(n√n)`，空间复杂度为 `O(n)`。
