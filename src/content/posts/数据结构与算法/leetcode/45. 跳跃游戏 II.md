这题和你上一题 **55. 跳跃游戏** 几乎是同一套贪心思想，但多了一个要求：

- 55：问 **能不能到终点**
- 45：保证一定能到终点，问 **最少跳几次**

这题最推荐：

> **贪心 + 区间覆盖**

核心变量有三个：

```
int jumps = 0;      // 已经跳了几次
int currentEnd = 0; // 当前这一跳能够覆盖到的最远边界
int maxReach = 0;   // 在当前覆盖范围内，下一跳最远能到哪里
```

---

## ① 破题

例如：

```
nums = [2,3,1,1,4]
```

下标：

```
下标：  0  1  2  3  4
nums： [2, 3, 1, 1, 4]
```

从 0：

```
最多跳2步
```

可以去：

```
1 或 2
```

如果：

```
0 → 1
```

因为：

```
nums[1] = 3
```

可以直接：

```
1 → 4
```

所以：

```
0 → 1 → 4
```

一共：

```
2次
```

答案就是：

```
2
```

---

# ② 为什么不能简单“每次跳最大步数”？

比如：

```
nums = [2,3,1,1,4]
```

如果你从下标 0 直接跳最大步数：

```
0 → 2
```

然后：

```
nums[2] = 1
```

只能：

```
2 → 3 → 4
```

一共：

```
3次
```

但真正最优：

```
0 → 1 → 4
```

只需要：

```
2次
```

所以：

> 不能看当前这一格“自己能跳多远”。

应该看：

> **当前这一跳能够到达的所有位置中，哪个位置能让下一跳覆盖得最远。**

这就是贪心的核心。

---

# ③ 和 55 题相比，多了什么？

55 题只有：

```
maxReach
```

因为只需要知道：

> 最远能不能覆盖终点。

但是这题要计算：

> **到底用了几跳。**

所以我们还需要知道：

```
currentEnd
```

表示：

> **当前这一跳的覆盖范围到哪里结束。**

你可以把它理解成一个“层”。

---

# ④ 三个变量分别是什么意思

## `maxReach`

```
int maxReach = 0;
```

表示：

> 在目前扫描过的所有可达位置中，下一跳最远能够到哪里。

通过：

```
maxReach = max(maxReach, i + nums[i]);
```

不断更新。

---

## `currentEnd`

```
int currentEnd = 0;
```

表示：

> **当前这一次跳跃能够覆盖到的最右边界。**

当我们遍历到：

```
i == currentEnd
```

意味着：

> 当前这一跳能够到的位置全部考察完了。

这时候必须真正增加一次跳跃。

---

## `jumps`

```
int jumps = 0;
```

就是：

> 已经使用的跳跃次数。

---

# ⑤ 用 `[2,3,1,1,4]` 完整跑一遍

初始化：

```
jumps = 0

currentEnd = 0

maxReach = 0
```

---

## i = 0

当前：

```
nums[0] = 2
```

从这里最远：

```
0 + 2 = 2
```

所以：

```
maxReach = max(0, 2);
```

得到：

```
maxReach = 2
```

现在又发现：

```
i == currentEnd
```

因为：

```
0 == 0
```

什么意思？

> 当前这一跳的所有候选位置已经检查完了。

一开始我们就在下标 0，第一跳必须发生。

所以：

```
++jumps;
```

得到：

```
jumps = 1
```

然后：

```
currentEnd = maxReach;
```

得到：

```
currentEnd = 2
```

什么意思？

> 第一跳之后，我能够到达的范围是 `1 ~ 2`。

画一下：

```
0 | 1 2 | 3 4
    ↑ ↑
 第一跳能到
```

---

# ⑥ 现在不要立刻决定跳到 1 还是 2

这是本题最重要的地方。

我们并没有说：

```
第一跳一定跳到1
```

也没有说：

```
第一跳一定跳到2
```

而是说：

> 第一跳可以覆盖 `1~2`，那我就把这整个范围都考察一遍，看看谁能让第二跳走得最远。

---

## i = 1

```
nums[1] = 3
```

从这里：

```
1 + 3 = 4
```

所以：

```
maxReach = max(2, 4);
```

得到：

```
maxReach = 4
```

此时：

```
i = 1
currentEnd = 2
```

还没到当前这一层的边界。

所以：

```
暂时不增加 jumps
```

---

## i = 2

```
nums[2] = 1
```

从这里：

```
2 + 1 = 3
```

所以：

```
maxReach = max(4, 3);
```

还是：

```
maxReach = 4
```

现在：

```
i == currentEnd
```

即：

```
2 == 2
```

这说明：

> 第一跳能到达的所有位置 `1、2`，我们全部检查完了。

发现这两个位置里面：

```
1 可以让下一跳到4
2 只能让下一跳到3
```

所以最优的下一层覆盖：

```
到4
```

此时：

```
++jumps;
```

得到：

```
jumps = 2
```

然后：

```
currentEnd = maxReach;
```

变成：

```
currentEnd = 4
```

已经覆盖终点。

所以答案：

```
2
```

---

# ⑦ 你可以把整个过程理解成“分层”

对于：

```
[2,3,1,1,4]
```

其实相当于：

```
第0层：
位置0

        ↓ 第一跳

第1层：
位置1、2

        ↓ 第二跳

第2层：
位置3、4
```

我们想要的是：

> 到达最后一层需要多少层。

所以这道题其实和 **BFS（广度优先搜索）分层** 很像。

但是我们不需要真的：

```
queue
```

因为数组的可达范围是连续的。

只需要：

```
currentEnd
```

标记当前层结束位置，

```
maxReach
```

记录下一层结束位置。

这就是为什么这个贪心算法非常漂亮。

---

# ⑧ 完整代码

推荐你掌握这一版：

```cpp
class Solution {
public:
    int jump(vector<int>& nums) {
        int n = nums.size();

        int jumps = 0;
        int currentEnd = 0;
        int maxReach = 0;

        for (int i = 0; i < n - 1; ++i) {

            // 当前范围内，下一跳最远能到哪里
            maxReach = max(maxReach, i + nums[i]);

            // 当前这一跳的范围已经扫描完
            if (i == currentEnd) {
                ++jumps;

                currentEnd = maxReach;
            }
        }

        return jumps;
    }
};
```

---

# ⑨ 最关键的代码

就是：

```
maxReach = max(maxReach, i + nums[i]);
```

意思：

> 在当前这一跳能够到达的所有位置中，不断寻找“下一跳能覆盖得最远”的位置。

然后：

```
if (i == currentEnd)
```

表示：

> 当前这一跳能覆盖的位置已经全部考察完了。

所以：

```
++jumps;
```

真正完成一次跳跃。

然后：

```
currentEnd = maxReach;
```

把下一跳的覆盖范围确定下来。

---

# ⑩ 为什么 `i == currentEnd` 才增加一次跳跃？

还是：

```
第一跳可到：

1、2
```

我们必须先把：

```
i = 1
i = 2
```

都看完。

因为我们需要比较：

```
从1出发能到多远？

从2出发能到多远？
```

只有整个范围检查完，才能知道：

> 下一跳最好的覆盖范围是什么。

所以：

```
if (i == currentEnd)
```

就是：

> **当前这一层扫描结束。**

于是进入下一层：

```
currentEnd = maxReach;
```

并且：

```
jumps++;
```

---

# ⑪ 为什么循环只到 `n - 2`？

你会发现：

```
for (int i = 0; i < n - 1; ++i)
```

不是：

```
i < n
```

这是非常重要的边界。

因为：

> 到达最后一个下标以后，就已经完成任务了，不需要再从最后一个位置跳一次。

例如：

```
nums = [1,1]
```

只有：

```
下标0 → 下标1
```

需要：

```
1跳
```

如果遍历：

```
i = 0
```

更新：

```
maxReach = 1
```

因为：

```
i == currentEnd
```

所以：

```
jumps = 1
```

结束。

正确。

---

如果你连最后一个下标：

```
i = 1
```

也继续处理，

很可能又执行：

```
++jumps;
```

错误变成：

```
2跳
```

所以：

```
i < n - 1
```

意思就是：

> **只考虑从哪些位置出发跳跃，不处理终点本身。**

```
nums = [2,3,0,1,4]
```

初始化：

```
jumps = 0

maxReach = 0
```

```
0 + 2 = 2
```

所以：

```
maxReach = 2
```

达到当前边界：

```
i == currentEnd
```

于是：

```
jumps = 1
currentEnd = 2
```

第一跳范围：

```
1 ~ 2
```

---

### i = 1

```
1 + 3 = 4
```

所以：

```
maxReach = 4
```

---

### i = 2

虽然：

```
nums[2] = 0
```

只能：

```
2 + 0 = 2
```

但是：

```
maxReach
```

之前已经被下标1扩展到了：

```
4
```

所以仍然：

```
maxReach = 4
```

```

```


# ⑬ 为什么遇到 `0` 不一定有问题？

比如：

```
[2,3,0,1,4]
```

这里：

```
nums[2] = 0
```

但仍然能到终点。

因为我们并不是规定：

```
一定要站在2上继续跳
```

第一跳的覆盖范围：

```
1、2
```

里面还有：

```
nums[1] = 3
```

它已经把下一跳范围扩展到了：

```
4
```

所以 `0` 完全没影响。

这进一步说明：

> 这题不能模拟某一条具体路径，而应该维护整个可达区间。

# ⑭ 和 55 跳跃游戏最关键的区别

### 55：

只需要：

```
maxReach
```

因为只问：

```
能不能覆盖终点？
```

逻辑：

```
maxReach = max(maxReach, i + nums[i]);
```

---

### 45：

除了：

```
maxReach
```

还必须有：

```
currentEnd
```

因为需要知道：

> 哪些位置属于“同一次跳跃可以到达的范围”。

只有扫描完当前范围：

```
i == currentEnd
```

才能：

```
jumps++;
```

所以：

```
55：

维护最远可达位置


45：

维护当前跳跃边界
+
下一跳最远边界
+
跳跃次数
```

---

# ⑮ `currentEnd` 和 `maxReach` 很容易混

这两个一定分清。

假设：

```
currentEnd = 2
maxReach = 4
```

是什么意思？

不是说现在人在：

```
2
```

也不是说现在人在：

```
4
```

而是：

```
currentEnd = 2

当前这一跳
最多覆盖到2
```

而：

```
maxReach = 4

在当前这一跳能到的所有位置中，
已经发现下一跳最多能覆盖到4
```

所以可以理解成：

```
当前层：

0 ------- currentEnd
          2


下一层：

0 ---------------- maxReach
                   4
```

到：

```
i == currentEnd
```

以后：

```
currentEnd = maxReach;
```

下一层就正式变成当前层。

---

# ⑯ 为什么这种贪心一定是最少跳？

因为在使用同样一次跳跃的情况下：

> 下一层覆盖得越远，绝对不会比覆盖得更近更差。

比如当前这一跳可以到：

```
1、2、3
```

从这些位置出发：

```
1 → 最远4
2 → 最远7
3 → 最远5
```

那么下一跳我们只关心：

```
最远能覆盖7
```

只要能用同样的跳跃次数把可达边界扩展到 7：

> 没有理由故意只扩展到 4 或 5。

所以每一层都把下一层边界扩大到最大：

```
maxReach = max(maxReach, i + nums[i]);
```

就能保证使用的层数，也就是跳跃次数最少。

---

# ⑰ 为什么不用 DP？

可以定义：

```
dp[i]
```

表示：

> 到达 i 最少需要多少步。

然后枚举：

```
哪些 j 可以跳到 i
```

但容易达到：

```
O(n²)
```

而这题存在非常明显的连续区间结构：

```
当前一跳覆盖一个区间
下一跳又覆盖更大的区间
```

所以贪心可以：

```
O(n)
```

完成。

---

# ⑱ 递归是否适合？

不推荐。

递归会变成：

```
当前位置
├─ 跳1步
├─ 跳2步
├─ 跳3步
...
```

会产生大量路径。

但实际上我们根本不关心具体路径，只需要知道：

```
用1跳最远能到哪里

用2跳最远能到哪里

用3跳最远能到哪里
```

所以：

> 贪心 / BFS 分层思想最合适。

```
maxReach
→ 在当前范围内，
```

你把 55 和 45 放一起记最容易：

```
55 跳跃游戏：

我最远能到哪里？

→ maxReach


45 跳跃游戏 II：

我用这一跳能覆盖到哪里？
下一跳又最远能覆盖到哪里？

→ currentEnd + maxReach

每扫描完一个 currentEnd：
→ jumps++
```

一句话记忆：

> **把一次跳跃能够到达的所有位置看成“一层”：扫描这一层时不断计算下一层最远能到哪里；当 `i == currentEnd`，说明这一层扫描完，必须增加一次跳跃，并令 `currentEnd = maxReach` 进入下一层。**
