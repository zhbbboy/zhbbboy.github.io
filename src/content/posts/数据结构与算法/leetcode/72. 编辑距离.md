这题是字符串 DP 里非常经典的一道，比刚才的 **1143 最长公共子序列** 再难一层。

核心是：
> `dp[i][j]` 表示：把 `word1` 的前 `i` 个字符，转换成 `word2` 的前 `j` 个字符，最少需要多少次操作。

允许三种操作：

```
插入
删除
替换
```

---

# ① 破题：题目真正要求什么

例如：

```
word1 = "horse"
word2 = "ros"
```

可以这样：

```
horse
↓ h 替换成 r
rorse

↓ 删除 r
rose

↓ 删除 e
ros
```

总共：

```
3 次
```

所以答案：

```
3
```

---

# ② 核心状态：`dp[i][j]`

定义：

```
dp[i][j]
```

表示：

> 把 `word1` 的前 `i` 个字符，变成 `word2` 的前 `j` 个字符，最少需要多少次操作。

例如：

```
word1 = "horse"
word2 = "ros"
```

那么：

```
dp[2][1]
```

表示：

```
"ho"
变成
"r"

需要的最少操作数
```

注意还是和上一题一样：

```
i、j 表示“前几个字符”
不是字符串真实下标
```

所以当前真正比较的字符是：

```
word1[i - 1]
word2[j - 1]
```

---

# ③ 先理解最简单情况：两个当前字符一样

假设：

```
word1前i个： "abc"
word2前j个： "adc"
```

最后字符：

```
c == c
```

既然最后这个 `c` 已经一样：

> 我根本不需要对它做任何操作。

所以问题退化成：

```
"ab"
变成
"ad"
```

也就是：

```
dp[i][j] = dp[i - 1][j - 1];
```

因此：

```
if (word1[i - 1] == word2[j - 1]) {
    dp[i][j] = dp[i - 1][j - 1];
}
```

这个比较好理解。

---

# ④ 最关键：两个字符不一样怎么办？

假设：

```
word1前i个：
abc

word2前j个：
abd
```

最后：

```
c != d
```

现在有三种操作。

---

## 第一种：替换

直接把：

```
c
```

替换成：

```
d
```

那么当前最后两个字符就解决了。

剩下：

```
ab
ab
```

对应：

```
dp[i - 1][j - 1]
```

然后因为刚才进行了一次替换：

```
dp[i - 1][j - 1] + 1
```

所以：

```
替换：
dp[i-1][j-1] + 1
```

---

# ⑤ 第二种：删除

假设：

```
word1 = "abc"
word2 = "ab"
```

当前：

```
abc
  ↑
  c
```

我们可以：

> 把 `word1` 最后一个字符 `c` 删除。

变成：

```
ab
```

这样问题就变成：

```
word1 前 i-1 个字符
变成
word2 前 j 个字符
```

所以：

```
删除：
dp[i - 1][j] + 1
```

这里的 `+1`：

> 就是删除当前字符这一次操作。

---

# ⑥ 第三种：插入

这个是最容易绕的。

假设：

```
word1 = "ab"
word2 = "abc"
```

想把：

```
ab
```

变成：

```
abc
```

可以在 `word1` 后面插入：

```
c
```

得到：

```
abc
```

也就是说：

> 我插入一个字符，让它和 `word2` 当前最后一个字符匹配。

插入完成后，`word2` 的最后一个字符相当于解决了。

剩下的问题：

```
word1 前 i 个字符
变成
word2 前 j-1 个字符
```

所以：

```
插入：
dp[i][j - 1] + 1
```

---

# ⑦ 三种操作汇总

当：

```
word1[i - 1] != word2[j - 1]
```

时：

```
替换：
dp[i-1][j-1] + 1

删除：
dp[i-1][j] + 1

插入：
dp[i][j-1] + 1
```

当然要选操作次数最少的那个：

```
dp[i][j] =
    min({
        dp[i - 1][j - 1],
        dp[i - 1][j],
        dp[i][j - 1]
    }) + 1;
```

这就是整道题最核心的状态转移。

---

# ⑧ 图解记忆三个方向

你可以把 `dp[i][j]` 想成这样：

```
                dp[i-1][j]
                   ↑
                 删除

dp[i-1][j-1] ← dp[i][j] ← dp[i][j-1]
     替换                     插入
```

更准确说：

```
左上 dp[i-1][j-1]
→ 替换

上方 dp[i-1][j]
→ 删除 word1 当前字符

左边 dp[i][j-1]
→ 插入一个字符
```

以后看到编辑距离，你直接记：

```
左上：替换
上：删除
左：插入
```

---

# ⑨ 为什么初始化很重要？

我们创建：

```
vector<vector<int>> dp(m + 1, vector<int>(n + 1));
```

第一行第一列需要初始化。

---

## `dp[i][0]`

表示：

> `word1` 前 `i` 个字符变成空字符串 `""`。

比如：

```
"abc"
→ ""
```

只能：

```
删除 a
删除 b
删除 c
```

需要：

```
3 次
```

所以：

```
dp[i][0] = i;
```

例如：

```
dp[1][0] = 1
dp[2][0] = 2
dp[3][0] = 3
```

---

## `dp[0][j]`

表示：

> 空字符串 `""` 变成 `word2` 前 `j` 个字符。

比如：

```
""
→ "abc"
```

只能插入：

```
插入 a
插入 b
插入 c
```

需要：

```
3 次
```

所以：

```
dp[0][j] = j;
```

---

# ⑩ 用一个小例子完整推

假设：

```
word1 = "ab"
word2 = "ac"
```

构造：

```
        ""   a   c
      ----------------
""      0    1   2
a       1
b       2
```

---

### `dp[1][1]`

比较：

```
word1[0] = a
word2[0] = a
```

相同。

所以：

```
dp[1][1] = dp[0][0];
```

即：

```
0
```

---

### `dp[1][2]`

比较：

```
a != c
```

三种选择：

```
替换：
dp[0][1] + 1
= 1 + 1
= 2

删除：
dp[0][2] + 1
= 2 + 1
= 3

插入：
dp[1][1] + 1
= 0 + 1
= 1
```

所以：

```
dp[1][2] = 1
```

也就是：

```
"a"
→ "ac"

插入 c
```

一次。

---

### `dp[2][1]`

比较：

```
b != a
```

最后结果：

```
1
```

因为：

```
"ab"
→ "a"

删除 b
```

---

### `dp[2][2]`

比较：

```
b != c
```

三种：

```
替换：
dp[1][1] + 1
= 0 + 1
= 1

删除：
dp[1][2] + 1
= 1 + 1
= 2

插入：
dp[2][1] + 1
= 1 + 1
= 2
```

所以：

```
dp[2][2] = 1
```

也就是：

```
"ab"
→ "ac"

把 b 替换成 c
```

一次。

最终：

```
        ""   a   c
      ----------------
""      0    1   2
a       1    0   1
b       2    1   1
```

答案：

```
dp[2][2] = 1;
```

# ⑪ 完整代码

```cpp
class Solution {
public:
    int minDistance(string word1, string word2) {
        int m = word1.size();
        int n = word2.size();

        vector<vector<int>> dp(
            m + 1,
            vector<int>(n + 1, 0)
        );

        // word1 前 i 个字符 -> 空字符串
        for (int i = 0; i <= m; ++i) {
            dp[i][0] = i;
        }

        // 空字符串 -> word2 前 j 个字符
        for (int j = 0; j <= n; ++j) {
            dp[0][j] = j;
        }

        for (int i = 1; i <= m; ++i) {
            for (int j = 1; j <= n; ++j) {

                if (word1[i - 1] == word2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1];
                }
                else {
                    dp[i][j] =
                        min({
                            dp[i - 1][j - 1], // 替换
                            dp[i - 1][j],     // 删除
                            dp[i][j - 1]      // 插入
                        }) + 1;
                }
            }
        }

        return dp[m][n];
    }
};
```

# ⑫ 为什么遍历从左上到右下？

因为：

```
dp[i][j]
```

依赖：

```
左上：
dp[i-1][j-1]

上：
dp[i-1][j]

左：
dp[i][j-1]
```

所以计算当前格子之前，这三个位置必须已经算好。

于是：

```
for (int i = 1; i <= m; ++i) {
    for (int j = 1; j <= n; ++j) {
```

正好满足依赖关系。

---

# ⑬ 这题最容易混的就是“插入”和“删除”

你可以始终站在：

> **“把 word1 变成 word2”**

这个角度。

假设当前：

```
word1前i个
word2前j个
```

### 删除

删除的是：

```
word1 当前最后一个字符
```

所以：

```
word1 少一个
word2 不变
```

因此：

```
dp[i - 1][j]
```

---

### 插入

给 `word1` 插入一个字符，用来匹配：

```
word2 当前最后一个字符
```

于是：

```
word2 当前最后一个字符被解决
```

所以：

```
word1 还是前i个
word2 变成前j-1个
```

因此：

```
dp[i][j - 1]
```

---

### 替换

把：

```
word1 当前字符
```

直接变成：

```
word2 当前字符
```

两边当前字符都解决。

所以：

```
dp[i - 1][j - 1]
```

---

你直接记：

```
删除 word1：
i - 1，j 不变

插入匹配 word2：
i 不变，j - 1

替换：
i - 1，j - 1
```

---

# ⑭ 和 1143 最长公共子序列很像

这两题可以放一起记。

1143：

```
两个字符相同：
dp[i-1][j-1] + 1

不同：
max(
    dp[i-1][j],
    dp[i][j-1]
)
```

因为求：

> 最长公共长度。

---

72 编辑距离：

```
两个字符相同：
dp[i-1][j-1]

不同：
min(
    dp[i-1][j-1],
    dp[i-1][j],
    dp[i][j-1]
) + 1
```

因为求：

> 最少操作次数。

所以你会发现字符串二维 DP 的共同特点：

```
当前字符相不相同
↓
决定状态转移
```

---

# ⑮ 递归适不适合？

逻辑上非常适合递归：

如果当前字符相同：

```
solve(i-1,j-1)
```

否则：

```
1 + min(
    solve(i-1,j-1),
    solve(i-1,j),
    solve(i,j-1)
)
```

但是裸递归会产生大量重复计算。

所以：

```
递归 + memo
```

可以。

面试标准写法还是：

> **二维 DP。**

---

# ⑯ 面试追问

最重要的是能解释三种转移：

```
dp[i - 1][j - 1]
```

> 替换。

```
dp[i - 1][j]
```

> 删除 `word1` 当前字符。

```
dp[i][j - 1]
```

> 给 `word1` 插入字符，匹配 `word2` 当前字符。

然后取：

```
min(...)
```

再：

```
+ 1
```

因为我们刚刚执行了一次编辑操作。

---

# ⑰ 复杂度

DP 表大小：

```
(m + 1) × (n + 1)
```

所以：

```
时间复杂度：O(mn)

空间复杂度：O(mn)
```

也可以压缩成：

```
O(n)
```

空间，但第一次学习建议二维版本。
