这道题是非常经典的 **回溯 + 剪枝**。

这题最推荐：

> **一行一行放皇后，每一行枚举所有列；如果当前位置不会和之前的皇后发生攻击，就放下皇后并递归处理下一行，回来以后再撤销。**

这题非常适合递归回溯，不推荐为了迭代而迭代。因为它天然就是一棵“第 0 行选哪一列 → 第 1 行选哪一列 → ……”的搜索树。

---

# ① 破题：题目真正要求什么

假设：

```
n = 4;
```

我们有一个：

```
4 × 4
```

棋盘，要放：

```
4 个皇后
```

皇后可以攻击：

```
同一行
同一列
两条斜线
```

所以任意两个皇后都不能满足下面任何一种关系：

```
同行
同列
同斜线
```

最终要求返回：

> 所有合法摆放方案。

例如其中一个答案：

```
.Q..
...Q
Q...
..Q.
```

这里：

```
Q = 皇后
. = 空格
```

---

# ② 核心技巧：一行一行放

这是整道题最关键的设计。

我们规定：

> **递归第 `row` 层，只负责给第 `row` 行放一个皇后。**

所以：

```
第 0 层递归 → 第 0 行
第 1 层递归 → 第 1 行
第 2 层递归 → 第 2 行
...
```

这样一来：

> 同一行有两个皇后的问题天然就不存在了。

因为每层只会：

```
board[row][col] = 'Q';
```

然后立刻进入：

```
backtrack(row + 1);
```

不会在同一行继续放第二个皇后。

所以我们真正需要检查的只有：

```
同一列
左上斜线
右上斜线
```

为什么只检查“上面”？

因为：

> 我们是从上往下一行一行放，下面的行还根本没有皇后。

# ③ 图解执行过程

以：

```
n = 4;
```

为例。

初始棋盘：

```
....
....
....
....
```

开始：

```
row = 0
```

---

## 第 0 行

尝试第 0 列：

```
Q...
....
....
....
```

合法，于是进入：

```
row = 1
```

---

## 第 1 行

尝试 `(1,0)`：

```
Q...
Q...
....
....
```

同列，不合法。

尝试 `(1,1)`：

```
Q...
.Q..
....
....
```

和 `(0,0)` 在斜线上，不合法。

尝试 `(1,2)`：

```
Q...
..Q.
....
....
```

合法。

于是继续：

```
row = 2
```

---

## 第 2 行

现在：

```
Q...
..Q.
....
....
```

尝试每一列。

你会发现：

```
col = 0  同列冲突
col = 1  斜线冲突
col = 2  同列冲突
col = 3  斜线冲突
```

没有任何地方能放。

说明：

> `row0 col0 + row1 col2` 这条路线走死了。

怎么办？

**回溯。**

把第 1 行的皇后拿走：

```
Q...
....
....
....
```

然后第 1 行继续尝试下一列：

```
col = 3
```

得到：

```
Q...
...Q
....
....
```

再继续递归。

---

最终如果某一路成功走到：

```
row == n
```

例如：

```
.Q..
...Q
Q...
..Q.
```

说明：

```
第 0 行放了皇后
第 1 行放了皇后
第 2 行放了皇后
第 3 行放了皇后
```

并且每一步都经过合法性检查。

于是这一定是一组合法答案：

```
result.push_back(board);
```

# ④ 完整代码

我推荐你先掌握这个最直观版本：

```cpp
class Solution {
private:
    vector<vector<string>> result;

    bool isValid(int row, int col,
                 vector<string>& board, int n) {
        // 1. 检查同一列
        for (int i = 0; i < row; ++i) {
            if (board[i][col] == 'Q') {
                return false;
            }
        }

        // 2. 检查左上斜线
        for (int i = row - 1, j = col - 1;
             i >= 0 && j >= 0;
             --i, --j) {
            if (board[i][j] == 'Q') {
                return false;
            }
        }

        // 3. 检查右上斜线
        for (int i = row - 1, j = col + 1;
             i >= 0 && j < n;
             --i, ++j) {
            if (board[i][j] == 'Q') {
                return false;
            }
        }

        return true;
    }

    void backtrack(int row,
                   vector<string>& board,
                   int n) {
        // 所有行都成功放置皇后
        if (row == n) {
            result.push_back(board);
            return;
        }

        // 当前 row 行，枚举每一列
        for (int col = 0; col < n; ++col) {

            if (!isValid(row, col, board, n)) {
                continue;
            }

            // 做选择
            board[row][col] = 'Q';

            // 递归处理下一行
            backtrack(row + 1, board, n);

            // 回溯：撤销选择
            board[row][col] = '.';
        }
    }

public:
    vector<vector<string>> solveNQueens(int n) {
        vector<string> board(
            n,
            string(n, '.')
        );

        backtrack(0, board, n);

        return result;
    }
};
```

---

# ⑤ 关键设计解释

## 1. `row` 到底表示什么？

```
backtrack(row, board, n)
```

表示：

> 前 `0 ~ row-1` 行已经成功放好了皇后，现在准备给第 `row` 行寻找一个合法位置。

例如：

```
.Q..
...Q
....
....
```

此时：

```
row = 2;
```

表示：

> 第 0、1 行已经确定，现在给第 2 行找位置。

---

## 2. 为什么 `for` 枚举的是列？

因为：

```
row
```

已经由递归层数确定了。

当前层只需要考虑：

```
这一行的皇后放在哪一列？
```

所以：

```
for (int col = 0; col < n; ++col)
```

---

## 3. 为什么不用检查同一行？

因为当前递归层：

```
row
```

只会选择一个：

```
col
```

选完以后马上：

```
backtrack(row + 1);
```

所以当前行不可能同时留下两个皇后。

---

## 4. 为什么只检查上面，不检查下面？

因为我们按：

```
row = 0
row = 1
row = 2
...
```

从上往下放。

当准备放：

```
(row, col)
```

时：

```
row + 1
row + 2
...
```

这些下面的位置还是：

```
....
....
```

没有皇后。

所以只检查已经放好的区域即可。

---

# 5. 怎么检查左上斜线？

假设当前位置：

```
(row, col)
```

左上方向每走一步：

```
row - 1
col - 1
```

所以：

```
int i = row - 1;
int j = col - 1;

while (i >= 0 && j >= 0) {
    ...
    --i;
    --j;
}
```

例如：

```
      col
       ↓
. Q . .
. . ? .
```

如果 `?` 是当前准备放皇后的位置，就不断：

```
↖
```

检查。

---

# 6. 怎么检查右上斜线？

右上方向：

```
row - 1
col + 1
```

所以：

```
int i = row - 1;
int j = col + 1;
```

然后：

```
--i;
++j;
```

不断往：

```
↗
```

检查。

---

# 7. 为什么一定要：

```
board[row][col] = '.';
```

这就是回溯。

例如：

```
第 0 行选择 col=1
↓
继续往下搜索
↓
这条路线全部搜索完
```

接下来第 0 行还要尝试：

```
col=2
col=3
```

因此之前：

```
board[0][1] = 'Q';
```

必须恢复：

```
board[0][1] = '.';
```

也就是：

```
board[row][col] = 'Q';   // 做选择

backtrack(...);          // 搜索这条路线

board[row][col] = '.';   // 撤销选择
```

和你刚才问的：

```
path.push_back(...);

backtrack(...);

path.pop_back();
```

本质完全一样。

只是以前恢复的是：

```
path
```

现在恢复的是：

```
棋盘 board
```

# ⑥ 递归三要素

这题非常适合用递归三要素理解。

### 1. 递归函数含义

```
backtrack(row, board, n)
```

表示：

> 前面的行已经合法放好，现在给 `row` 行安排皇后。

### 2. 终止条件

```
if (row == n)
```

表示：

> `0 ~ n-1` 共 n 行已经全部放置完成。

于是：

```
result.push_back(board);
```

### 3. 当前层做什么

当前 `row` 行：

```
依次尝试 col = 0 ~ n-1
```

如果：

```
isValid(row, col)
```

就：

```
放皇后
↓
递归下一行
↓
撤销皇后
```

---

# ⑦ 为什么不推荐迭代？

理论上可以自己维护一个栈，记录：

```
当前第几行
这一行尝试到了哪一列
之前哪些位置有皇后
```

但这实际上是在：

> 手动模拟递归调用栈。

代码会明显更复杂。

N 皇后的搜索结构就是：

```
第0行
  ↓
选择一列
  ↓
第1行
  ↓
选择一列
  ↓
...
```

因此递归回溯是最自然的写法。

# ⑧ 面试追问

最常问的是：**还能不能优化 `isValid()`？**

可以。

当前每次检查：

```
列
左上斜线
右上斜线
```

都需要遍历。

实际上可以维护三个数组：

```
vector<bool> cols(n);
vector<bool> diag1(2 * n - 1);
vector<bool> diag2(2 * n - 1);
```

这样就可以 `O(1)` 判断冲突。

关键是两条斜线的编号。

对于同一条：

```
↘
```

斜线，有：

```
row - col
```

相同。

由于可能是负数，可以写：

```
row - col + n - 1
```

对于同一条：

```
↙
```

斜线，有：

```
row + col
```

相同。

所以高级版本可以做到：

```
if (cols[col] ||
    diag1[row - col + n - 1] ||
    diag2[row + col]) {
    continue;
}
```

这属于很不错的面试优化点。

复杂度最坏仍然是指数级/阶乘级搜索，但剪枝会排除大量非法排列。

# ⑨ 复习总结

你可以这样记：

```
51. N 皇后

题型：
回溯 + 棋盘搜索 + 剪枝

核心思想：
一行一行放皇后。

row：
当前准备处理哪一行。

col：
当前行尝试哪一列。

为什么不用检查同行：
每一层只负责一行，
一行只会留下一个皇后。

合法性检查：
1. 同一列
2. 左上斜线
3. 右上斜线

合法：
board[row][col] = 'Q'
backtrack(row + 1)
board[row][col] = '.'

终止：
row == n

说明所有 n 行都成功放好了皇后，
记录 board。
```

你可以把这题和前面的回溯题串起来理解：

> **全排列是“每层决定放哪个数字”，括号生成是“每层决定放左括号还是右括号”，分割回文串是“每层决定这一刀切在哪里”，N 皇后则是“每层决定当前这一行的皇后放在哪一列”。**

一句话记忆：

> **一行一个皇后，当前行枚举所有列；检查列和两条上方斜线，合法就放下递归下一行，回来后恢复为 `.`。**
