这题 **BFS 层序遍历** 和 **DFS 递归** 都很适合。

推荐顺序：

> **主方法：BFS 层序遍历。**  
> 因为“右视图”本质上就是取每一层最右边的节点，和你刚学过的 102 层序遍历直接对应。

DFS 递归也非常巧妙，可以帮助你理解“每一层第一次访问的节点”。

---
## ① 破题：题目真正要求什么
站在二叉树右侧，从上往下看，返回每一层能够看到的节点。
例如：
```
        1
       / \
      2   3
       \   \
        5   4
```
从右侧看：
```
第 0 层看到：1
第 1 层看到：3
第 2 层看到：4
```
所以答案是：
```
[1, 3, 4]
```
### 一个容易误解的地方
右视图并不是：不断沿着 `right` 指针向下走。
例如：
```
        1
       / \
      2   3
     /
    4
   /
  5
```
第 2、3 层虽然没有右子树节点，但从右边仍然能看到：
```
4、5
```
所以答案是：
```
[1, 3, 4, 5]
```

准确理解应该是：

> 每一层最右边存在的那个节点。
## 解题思路
1. 该题的核心其实就是在层次遍历中添加当遍历到该层最右边时，则将最右边节点的值给push到res数组里面去。

## ④ 完整代码：推荐的 BFS 写法

```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> result;

        if (root == nullptr) {
            return result;
        }

        queue<TreeNode*> q;
        q.push(root);

        while (!q.empty()) {
            int size = q.size();

            for (int i = 0; i < size; ++i) {
                TreeNode* node = q.front();
                q.pop();

                // 当前层最后一个节点，就是右视图看到的节点
                if (i == size - 1) {
                    result.push_back(node->val);
                }

                // 按从左到右的顺序加入下一层
                if (node->left != nullptr) {
                    q.push(node->left);
                }

                if (node->right != nullptr) {
                    q.push(node->right);
                }
            }
        }

        return result;
    }
};
```

## ⑤ 关键设计解释

### 1. 为什么必须提前保存 `size`？

```
int size = q.size();
```

这个 `size` 表示：

> 当前层原本有多少个节点。

处理当前层时，我们会把下一层的孩子加入队列，队列大小会动态变化。

所以不能写：

```
for (int i = 0; i < q.size(); ++i)
```

否则 `q.size()` 一边出队、一边入队，会不断变化，无法准确区分当前层和下一层。

---

### 2. 为什么 `i == size - 1` 就是最右节点？

孩子按下面顺序进入队列：

```
先左孩子
再右孩子
```

因此，同一层节点会按照从左到右的顺序出队。

例如：

```
[2, 3]
```

处理顺序就是：

```
先 2，后 3
```

最后处理的 `3` 就是这一层最右边的节点。

所以：

```
if (i == size - 1) {
    result.push_back(node->val);
}
```

---

### 3. 为什么不能只沿 `root->right` 向下？

因为某一层可能不存在右孩子，但左边的节点依然会从右侧被看到。

例如：

```
    1
   /
  2
 /
3
```

右视图是：

```
[1, 2, 3]
```

所以我们找的是：

> 每一层最右边存在的节点。

不是“所有右孩子”。

---

### 4. 能不能先右孩子、后左孩子入队？

可以。

假如先把右孩子入队，那么每一层第一个处理的节点就是右视图节点：

```cpp
if (i == 0) {
    result.push_back(node->val);
}

if (node->right) {
    q.push(node->right);
}

if (node->left) {
    q.push(node->left);
}
```

这也正确。

不过更推荐保持常见的：

```
先左后右
记录每层最后一个
```

因为它和标准层序遍历模板一致，更容易复用。

## ⑥ DFS 递归方法

递归也很适合这题。

核心思想是：

> 按照“根 → 右 → 左”的顺序遍历。  
> 对于每一层，第一个访问到的节点，就是右视图节点。

例如：

```
        1
       / \
      2   3
       \   \
        5   4
```

右优先 DFS 的访问顺序：

```
1 → 3 → 4 → 2 → 5
```

第一次到达：

```
深度 0：1
深度 1：3
深度 2：4
```

所以答案是：

```
[1, 3, 4]
```

### DFS 完整代码

```cpp
class Solution {
private:
    void dfs(TreeNode* node, int depth, vector<int>& result) {
        if (node == nullptr) {
            return;
        }

        // result.size() 等于 depth，说明这是本层第一次被访问
        if (depth == result.size()) {
            result.push_back(node->val);
        }

        // 必须先遍历右子树
        dfs(node->right, depth + 1, result);
        dfs(node->left, depth + 1, result);
    }

public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> result;
        dfs(root, 0, result);
        return result;
    }
};
```

---

## ⑦ 递归三要素

### 1. 递归函数定义

```
dfs(node, depth, result)
```

表示：

> 从当前 `node` 开始进行右优先 DFS；`depth` 表示当前节点所在层数，将每层第一个访问的节点加入 `result`。

---

### 2. 终止条件

```
if (node == nullptr) {
    return;
}
```

当前节点为空，没有内容需要处理。

---

### 3. 当前层做什么

先判断当前层是否已经记录过节点：

```
if (depth == result.size()) {
    result.push_back(node->val);
}
```

然后按照右优先顺序递归：

```
dfs(node->right, depth + 1, result);
dfs(node->left, depth + 1, result);
```

---

### 为什么 `depth == result.size()` 表示第一次到达这一层？

初始：

```
result.size() = 0
depth = 0
```

说明第 0 层还没记录，加入根节点。

加入后：

```
result.size() = 1
```

第一次到达深度 1 时：

```
depth = 1
result.size() = 1
```

说明第 1 层还没记录，加入当前节点。

如果后来再次到达深度 1：

```
depth = 1
result.size() 已经大于 1
```

说明这一层已经记录过，不再添加。

因为 DFS 是先右后左，所以第一次到达每一层的一定是最右侧节点。

---

## ⑧ BFS 和 DFS 怎么选择？

两种都适合，但本题更推荐先掌握 BFS。

### BFS

优点：

```
题意就是“每一层最右节点”
与层序遍历直接对应
逻辑直观
不依赖递归深度
```

### DFS

优点：

```
代码简洁
能够训练“深度 + 首次访问”的递归思维
```

但是 DFS 有一个必须注意的条件：

```
必须先递归右子树，再递归左子树
```

如果先左后右，那么每层第一次访问的是最左节点，得到的是左视图。

## ⑨ 面试追问

### Q1：为什么 BFS 的时间复杂度是 `O(n)`？

每个节点：

```
进入队列一次
离开队列一次
```

所以总时间复杂度是：

```
O(n)
```

空间复杂度最坏是：

```
O(n)
```

因为某一层可能同时包含大量节点。

---

### Q2：DFS 的复杂度是多少？

每个节点只访问一次：

```
时间复杂度：O(n)
```

递归栈深度等于树高 `h`：

```
空间复杂度：O(h)
```

平衡树中：

```
O(log n)
```

树退化成链表时：

```
O(n)
```

---

### Q3：如果要找左视图怎么办？

BFS：

```
if (i == 0) {
    result.push_back(node->val);
}
```

记录每一层第一个节点。

DFS：

```
dfs(node->left, depth + 1, result);
dfs(node->right, depth + 1, result);
```

改成先左后右。

---

### 面试表达

> 这题本质上是获取二叉树每一层最右侧的节点。我使用 BFS 层序遍历，每轮先记录当前层节点数量 `size`，然后处理这一层的 `size` 个节点。由于节点按照先左后右的顺序入队，因此当前层最后一个出队的节点就是右视图能够看到的节点，将其加入结果。每个节点只进出队列一次，时间复杂度是 `O(n)`，空间复杂度最坏为 `O(n)`。

## ⑩ 复习总结

```
199. 二叉树的右视图

题型：
二叉树 BFS / DFS。

推荐方法：
BFS 层序遍历。

核心含义：
右视图 = 每一层最右边存在的节点，
并不是只沿 right 指针向下走。

BFS 流程：
1. root 为空，返回空数组。
2. root 加入队列。
3. 每轮记录 size = q.size()。
4. 处理当前层 size 个节点。
5. 如果 i == size - 1，当前节点是本层最右节点。
6. 按先左后右加入孩子。
7. 队列为空后返回结果。

DFS 补充：
按 根 → 右 → 左 遍历。
当 depth == result.size() 时，
说明第一次到达这一层，记录当前节点。
```

一句话记忆：

> **BFS：记录每层最后一个节点；DFS：右边优先，记录每层第一个节点。**
