这题我建议你**主学二维动态规划 DP**，因为你刚刚连续学了 62、64，这题正好能让你接触一种新的二维 DP：

> 前面的网格 DP 是“当前位置依赖上面和左边”；  
> 这题是“区间 `[i,j]` 是否为回文，依赖更小的区间 `[i+1,j-1]`”。

这也是非常重要的一类：

> **区间 DP（Interval DP，区间动态规划）**

# ① 破题：题目真正要求什么

例如：

```
s = "babad"
```

它的连续子串有很多：

```
b
a
b
a
d

ba
ab
ba
ad

bab
aba
bad

baba
abad

babad
```

其中回文子串包括：

```
"b"
"a"
"bab"
"aba"
...
```

最长的是：

```
"bab"
```

或者：

```
"aba"
```

长度都是 3，所以返回任意一个都可以。

---

## 什么叫回文？

回文就是：

> 从左往右读和从右往左读完全相同。

例如：

```
"a"       ✅

"aa"      ✅

"aba"     ✅

"abba"    ✅

"abc"     ❌
```

---

# ② 核心技巧：判断 `s[i...j]` 是不是回文

我们定义：

```
dp[i][j]
```

表示：

> **字符串从下标 `i` 到下标 `j` 的子串 `s[i...j]` 是否为回文串。**

类型是：

```
bool
```

所以：

```
dp[i][j] = true

表示：

s[i...j] 是回文串
```

例如：

```
s = "babad";
```

如果：

```
i = 0
j = 2
```

那么：

```
s[0...2] = "bab"
```

所以：

```
dp[0][2] = true;
```

---

# ③ 一个字符串什么时候是回文？

假设：

```
s[i ... j]
```

例如：

```
a b c b a
↑       ↑
i       j
```

想判断整个：

```
"abcba"
```

是不是回文。

首先要求：

```
s[i] == s[j]
```

也就是：

```
左边字符 == 右边字符
```

这里：

```
'a' == 'a'
```

成立。

但是光这样还不够。

例如：

```
a b c d a
↑       ↑
```

首尾也是：

```
a == a
```

但：

```
"abcda"
```

显然不是回文。

所以还必须保证：

> 去掉首尾以后，中间部分也是回文。

也就是：

```
dp[i + 1][j - 1] == true
```

于是核心状态转移就是：

```
dp[i][j] =
    (s[i] == s[j])
    &&
    dp[i + 1][j - 1];
```

---

# ④ 但是有个特殊情况：短字符串怎么办？

比如：

```
"a"
```

当然是回文。

再比如：

```
"aa"
```

也是回文。

但是如果我们按照：

```
dp[i + 1][j - 1]
```

去访问，长度很短时就会出现不好处理的情况。

所以我们把：

```
长度 <= 3
```

单独考虑。

---

## 长度为 1

例如：

```
"a"
```

一定是回文。

所以：

```
dp[i][i] = true;
```

---

## 长度为 2

例如：

```
"aa"
```

只需要：

```
第一个字符 == 第二个字符
```

就是回文。

例如：

```
"aa" ✅
"ab" ❌
```

---

## 长度为 3

例如：

```
"aba"
```

只需要首尾相同：

```
a == a
```

中间只有一个字符：

```
b
```

而单字符一定是回文。

所以：

```
"aba" ✅
```

---

因此可以统一写成：

```
if (s[i] == s[j] &&
    (j - i <= 2 || dp[i + 1][j - 1])) {
    dp[i][j] = true;
}
```

这句非常重要。

---

# ⑤ 为什么是 `j - i <= 2`？

这个你一定要搞清楚。

子串长度实际上是：

```
j - i + 1
```

如果：

```
j - i <= 2
```

那么长度：

```
<= 3
```

也就是：

```
长度1
长度2
长度3
```

都属于很容易判断的短字符串。

例如：

### `"aa"`

```
i = 0
j = 1

j - i = 1 <= 2
```

只要：

```
s[i] == s[j]
```

就是回文。

---

### `"aba"`

```
i = 0
j = 2

j - i = 2 <= 2
```

首尾：

```
a == a
```

中间一个：

```
b
```

天然回文。

因此 `"aba"` 是回文。

---

# ⑥ 状态转移公式

所以最终：

```
dp[i][j] =
    s[i] == s[j]
    &&
    (j - i <= 2 || dp[i + 1][j - 1]);
```

你可以翻译成人话：

> `s[i...j]` 是回文，当且仅当：
> 
> 1. 左右两个字符相同；
> 2. 并且要么子串长度不超过 3，要么里面的 `s[i+1...j-1]` 已经是回文。

---

# ⑦ 图解依赖关系

比如判断：
```
"abcba"
```

也就是：
```
i       j
↓       ↓
a b c b a
```

首先：
```
a == a
```

然后看里面：
```
  b c b
  ↑   ↑
 i+1 j-1
```

所以：
```
dp["abcba"]
      ↓
依赖
      ↓
dp["bcb"]
```
而：
```
"bcb"
```

首尾：
```
b == b
```

中间只有：

```
c
```

所以：

```
"bcb" 是回文
```

于是：

```
"abcba" 也是回文
```

这就是区间 DP 的核心：

```
大区间
   ↓
依赖
   ↓
小区间
```

---

# ⑧ 最关键的问题：遍历顺序

这里比前面的 DP 更容易写错。

因为：
```
dp[i][j]
```
依赖：
```
dp[i + 1][j - 1]
```

也就是说：

> 我计算 `[i,j]` 之前，必须保证 `[i+1,j-1]` 已经计算完成。

比如：

```
dp[0][4]

依赖

dp[1][3]
```

所以：

```
dp[1][3]
```

必须先算。

这意味着：

> `i` 必须从大到小遍历。

代码：

```
for (int i = n - 1; i >= 0; --i)
```

然后：

```
for (int j = i; j < n; ++j)
```

也就是：

```
先计算靠右、比较小的区间

再慢慢向左扩展
```

# ⑩ 我们需要记录什么？

`dp` 只能告诉我们：

```
某个子串是不是回文
```

但最后题目要求返回：

```
string
```

所以还需要记录：

```
int start = 0;
int maxLen = 1;
```

其中：

```
start
→ 最长回文子串的起始下标

maxLen
→ 最长回文子串的长度
```

如果发现：

```
dp[i][j] == true
```

而且：

```
j - i + 1 > maxLen
```

那么更新：

```
start = i;
maxLen = j - i + 1;
```

最后：

```
return s.substr(start, maxLen);
```

---

# ⑪ 完整代码

推荐你先掌握这个 DP 版本：

```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        int n = s.size();

        vector<vector<bool>> dp(
            n,
            vector<bool>(n, false)
        );

        int start = 0;
        int maxLen = 1;

        // i 必须从后往前
        for (int i = n - 1; i >= 0; --i) {

            // j 从 i 往右
            for (int j = i; j < n; ++j) {

                if (s[i] == s[j] &&
                    (j - i <= 2 || dp[i + 1][j - 1])) {

                    dp[i][j] = true;

                    int len = j - i + 1;

                    if (len > maxLen) {
                        maxLen = len;
                        start = i;
                    }
                }
            }
        }

        return s.substr(start, maxLen);
    }
};
```

---

# ⑫ 这段代码最核心的三句话

第一句：

```
s[i] == s[j]
```

表示：

> 当前区间首尾必须一样。

第二句：

```
j - i <= 2 || dp[i + 1][j - 1]
```

表示：

> 要么字符串很短，首尾相等就够了；要么中间部分必须也是回文。

第三句：

```
dp[i][j] = true;
```

表示：

> `[i,j]` 这个区间已经确认是回文。

---

# ⑬ 为什么 `i` 不能从 0 开始往后？

真正的规则不是：
> `i` 必须倒序。

而是：
> **计算 `dp[i][j]` 之前，必须保证它依赖的 `dp[i+1][j-1]` 已经计算完成。**


假设你写：

```
for (int i = 0; i < n; ++i)
```

然后想计算：

```
dp[0][4]
```

但它需要：

```
dp[1][3]
```

问题是：

```
i = 1
```

还没处理。

也就是说你在使用：

> **未来还没有计算出来的状态。**

因此遍历顺序必须满足：

```
先算 dp[i+1][j-1]
再算 dp[i][j]
```

所以：

```
i 从 n-1 向 0
```

另外一种写法的代码如下
```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        int n = s.size();

        vector<vector<bool>> dp(
            n,
            vector<bool>(n, false)
        );

        int start = 0;
        int maxLen = 1;

        // j 表示子串右端点
        for (int j = 0; j < n; ++j) {

            // i 表示子串左端点
            for (int i = 0; i <= j; ++i) {

                if (s[i] == s[j] &&
                    (j - i <= 2 || dp[i + 1][j - 1])) {

                    dp[i][j] = true;

                    int len = j - i + 1;

                    if (len > maxLen) {
                        maxLen = len;
                        start = i;
                    }
                }
            }
        }

        return s.substr(start, maxLen);
    }
};
```

---

# ⑭ 这和前面的网格 DP 有什么区别？

前面的 64：

```
dp[i][j]
=
min(dp[i - 1][j],
    dp[i][j - 1])
+ grid[i][j];
```

依赖：

```
上面
左边
```

所以从：

```
左上 → 右下
```

遍历。

但是这题：

```
dp[i][j]
```

依赖：

```
dp[i + 1][j - 1]
```

也就是：

```
左下方向的小区间
```

所以遍历顺序发生了变化。

这就是 DP 很重要的思想：

> **遍历顺序不是背出来的，而是由状态依赖关系决定的。**

---

# ⑮ 中心扩展其实更适合这道题吗？

这题还有一个非常经典的方法：

> **中心扩展法（Expand Around Center，中心扩展）**

比如回文：

```
a b a
  ↑
中心
```

从 `b` 向两边扩：

```
a == a
```

所以得到：

```
aba
```

偶数长度：

```
a b b a
    ↑
中心在两个b之间
```

因此每个位置都尝试：

```
奇数回文中心：i,i

偶数回文中心：i,i+1
```

中心扩展：

```
时间 O(n²)
空间 O(1)
```

而 DP：

```
时间 O(n²)
空间 O(n²)
```

所以如果只追求这道题最简洁的最优空间解：

> **中心扩展其实更推荐。**

但是你现在正在学习 DP，这题用 DP 特别适合帮助你理解：

> **区间状态 + 状态依赖决定遍历顺序。**

所以建议你：

> **先掌握 DP，再知道中心扩展是这题更省空间的写法。**

---

# ⑯ 递归适不适合？

这题可以用递归判断：

```
s[i...j] 是不是回文
↓
检查 s[i] == s[j]
↓
递归判断 s[i+1...j-1]
```

但是如果再枚举所有子串，会产生大量重复计算。

所以直接递归并不推荐。

可以加记忆化，但最后本质上还是 DP。

# ⑰ 面试追问

面试最容易问三个问题。

**第一，`dp[i][j]` 是什么？**

> 表示子串 `s[i...j]` 是否为回文串。

**第二，状态转移是什么？**

```
s[i] == s[j]
&&
(j - i <= 2 || dp[i + 1][j - 1])
```

**第三，为什么 `i` 倒序？**

> 因为 `dp[i][j]` 依赖 `dp[i+1][j-1]`，必须确保内层小区间先计算出来。

这个第三问尤其重要。

```
n × n
```

个 `(i,j)` 状态。

所以：

```
时间复杂度：O(n²)
```

二维 DP 表：

```
空间复杂度：O(n²)
```
