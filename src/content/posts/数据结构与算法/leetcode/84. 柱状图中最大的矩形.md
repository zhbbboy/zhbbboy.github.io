这题正好接在你刚学的 **739 每日温度** 后面。

两题都是单调栈，但思路稍微不同：

- 739：找右边第一个**更大**
- 84：对于每根柱子，找左右两边第一个**更矮**

因为只有找到左右两边第一个更矮的柱子，我们才能知道：

> **以当前柱子的高度作为矩形高度时，最多能够向左右延伸多宽。**

---

# ① 破题：题目真正要求什么

例如：

```
heights = [2,1,5,6,2,3]
```

每根柱子宽度都是：

```
1
```

题目让你选择连续的若干根柱子，在这些柱子里画一个矩形。

比如：

```
5 6
```

这两根柱子：

```
高度分别是 5、6
```

如果组成一个矩形，高度最多只能取：

```
5
```

因为第二根虽然有 6，但第一根只有 5。

宽度：

```
2
```

所以：

```
面积 = 5 × 2 = 10
```

这就是答案。

---

# ② 核心问题：对于每一根柱子，它能向左右延伸多远？

假设我们现在研究高度：

```
5
```

也就是：

```
[2,1,5,6,2,3]
     ↑
```

如果我们规定：

> 矩形高度就是 5。

向右：

```
6 >= 5
```

所以可以继续。

但是再往右：

```
2 < 5
```

不能继续。

向左：

```
1 < 5
```

也不能继续。

因此高度 5 可以覆盖：

```
5 6
```

宽度：

```
2
```

面积：

```
5 × 2 = 10
```

所以对于每一根柱子，我们真正想找：

```
左边第一个比它矮的位置

右边第一个比它矮的位置
```

然后：

```
矩形宽度
=
右边界 - 左边界 - 1
```

这就是这道题的核心。

# ⑥ 出现一个新问题：最后剩在栈里的怎么办？

现在遍历结束了，但栈里还有：

```
1
2
3
```

这些柱子右边一直没有遇到比它们更矮的柱子。

怎么办？

一个非常经典的技巧：

> **在数组最后想象一个高度为 0 的柱子。**

也就是把：

```
[2,1,5,6,2,3]
```

看成：

```
[2,1,5,6,2,3,0]
```

最后这个：

```
0
```

一定比所有正高度都小。

所以：

```
所有剩下的柱子
```

都会被依次弹出来，把面积算完。

我们不用真的修改数组，可以这样写：

```
for (int i = 0; i <= n; ++i) {
    int curHeight = (i == n ? 0 : heights[i]);
}
```

当：

```
i == n
```

人为：

```
curHeight = 0
```

# ⑨ 完整代码

推荐你先掌握这一版：

```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        int n = heights.size();

        stack<int> st;

        int ans = 0;

        for (int i = 0; i <= n; ++i) {

            // 最后人为添加一个高度为0的柱子
            int curHeight = (i == n ? 0 : heights[i]);

            while (!st.empty() &&
                   curHeight < heights[st.top()]) {

                int index = st.top();
                st.pop();

                int height = heights[index];

                int width;

                if (st.empty()) {
                    width = i;
                }
                else {
                    width = i - st.top() - 1;
                }

                ans = max(ans, height * width);
            }

            if (i < n) {
                st.push(i);
            }
        }

        return ans;
    }
};
```

# ⑩ 这段代码到底在干什么？

核心代码：

```
while (!st.empty() &&
       curHeight < heights[st.top()])
```

意思：

> 当前出现了一个更矮的柱子，那么栈顶那根柱子再也不能继续向右扩展。

因此它的：

```
右边第一个更矮的位置
```

已经确定：

```
就是 i
```

然后：

```
int index = st.top();
st.pop();
```

弹出当前要计算面积的柱子。

高度：

```
int height = heights[index];
```

弹出以后：

```
st.top()
```

就是它的：

```
左边第一个更矮的位置
```

所以：

```
width = i - st.top() - 1;
```

最后：

```
ans = max(ans, height * width);
```

和每日温度一样。

例如：

```
1 5 6
```

突然来了：

```
2
```

那么：

```
2 < 6
```

6 要结算。

弹掉 6 后：

```
2 < 5
```

5 也要结算。

所以：

```
while (...)
```

一个矮柱子可能一次让很多柱子结算。

# ⑭ 面试追问

### 为什么栈存下标？

因为既需要：

```
heights[st.top()]
```

比较高度，

又需要：

```
i - st.top() - 1
```

计算宽度。

---

### 为什么时间复杂度是 O(n)？

虽然有：

```
for
```

里面套：

```
while
```

但是每根柱子：

```
最多入栈一次
最多出栈一次
```

所以所有：

```
push + pop
```

最多：

```
2n
```

因此：

```
时间 O(n)
空间 O(n)
```

对于每根柱子，求：

右边第一个更矮

这样：

宽度 =
右边界 - 左边界 - 1

面积 =
