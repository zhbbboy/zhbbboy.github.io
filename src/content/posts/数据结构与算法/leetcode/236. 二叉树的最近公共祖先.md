这道题最适合使用：
> **递归 DFS + 后序遍历思想**

原因是：判断当前节点是不是最近公共祖先，必须先知道它的左子树和右子树中是否找到了 `p` 或 `q`。因此要先处理左右子树，再判断当前节点。

迭代也能通过“父节点哈希表”实现，但状态更多，不如递归自然，所以本题重点掌握递归法。

---

## ① 破题：题目真正要求什么

给定二叉树中的两个节点 `p` 和 `q`，找到它们的**最近公共祖先**。

“公共祖先”表示某个节点同时是 `p` 和 `q` 的祖先。
“最近”表示：
> 在所有公共祖先中，深度最大，也就是离 `p、q` 最近的那个。

例如：
```
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4
```
如果：
```
p = 5
q = 1
```
那么公共祖先有：
```
3
```
所以最近公共祖先是 `3`。

但如果：
```
p = 5
q = 4
```
那么答案是：
```
5
```

因为节点可以是它自己的祖先，而 `4` 位于 `5` 的子树中。

---
## ② 核心技巧：左右子树分别寻找 p 和 q

对于当前节点 `root`，递归搜索左右子树：
```
TreeNode* left = lowestCommonAncestor(root->left, p, q);
TreeNode* right = lowestCommonAncestor(root->right, p, q);
```

递归返回值可以这样理解：
> 当前子树中如果找到了 `p`、`q` 或它们的最近公共祖先，就把那个节点返回；如果什么也没找到，就返回 `nullptr`。

于是当前节点只有几种情况。
### 情况一：左右两边都找到了

```
left != nullptr
right != nullptr
```
说明：
- 一个目标在左子树；
- 另一个目标在右子树。

那么当前节点就是它们第一次汇合的位置，也就是最近公共祖先：
```
return root;
```

---
### 情况二：只有左边找到了
```
left != nullptr
right == nullptr
```
说明两个目标的有效信息都在左子树中，返回：
```
return left;
```

这里的 `left` 可能是：
- 节点 `p`；
- 节点 `q`；
- 已经在左子树中找到的最近公共祖先。

---
### 情况三：只有右边找到了

```
left == nullptr
right != nullptr
```
返回：
```
return right;
```

---
### 情况四：左右都没找到

```
left == nullptr
right == nullptr
```
返回：
```
nullptr;
```

## 解题思路
1. 首先得思考该题用的是递归法，然后我就来推测该函数的意思看看是否可以直接作为递归函数，然后发现该函数就是来寻找最近祖先，并且参数合适直接用来做递归函数
2. 递归三要素-函数意义：在以 `root` 为根的子树中寻找 `p` 和 `q`，返回找到的目标节点或它们的最近公共祖先；如果都没找到，返回 `nullptr`。
3. 递归三要素-终止条件：如果root为空那就返回nullptr，如果root== p或者root == q，那就返回root。其实合起来就是root 如果 == 这三者中的一个就返回root
4. 递归三要素-当层做什么：首先得思考做什么，一看这个就知道是要遍历节点，我才能去判断哪些节点是最近公共祖先，所以我们得思考用什么遍历方法，对于二叉树而言，用层次遍历呢还是前序遍历呢，还是中序遍历呢，还是后序遍历呢，其实就是我们的具体操作是在前，在中，还是在后，经过分析，我们得先知道自己左右孩子的情况才能去进行自己这个节点进行判断。所以用后序遍历。所以就是先看自己的左右孩子是否存在最近公共祖先或者是p或q，如果左孩子和右孩子都有，那么自己就是最近公共祖先，如果只左或右孩子有，那么最近公共最近祖先就是左或者右孩子
## ④ 完整代码
```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(
        TreeNode* root,
        TreeNode* p,
        TreeNode* q
    ) {
        if (root == nullptr || root == p || root == q) {
            return root;
        }

        TreeNode* left =
            lowestCommonAncestor(root->left, p, q);

        TreeNode* right =
            lowestCommonAncestor(root->right, p, q);

        if (left != nullptr && right != nullptr) {
            return root;
        }

        return left != nullptr ? left : right;
    }
};
```

## ⑤ 关键设计解释

### 1. 递归函数的返回值到底表示什么？
这是本题最重要的地方。
```
lowestCommonAncestor(root, p, q)
```
返回值表示：
> 在以 `root` 为根的子树中，如果找到了 `p`、`q` 或者它们的最近公共祖先，就返回对应节点；如果都没找到，返回 `nullptr`。

所以返回值不一定已经是最终公共祖先，也可能只是：
```
p 或 q
```

它要继续向上传递，等待与另一边的结果汇合。

---
### 2. 为什么 `root == p || root == q` 就直接返回？
```
if (root == p || root == q) {
    return root;
}
```
有两种意义。

第一种：当前节点是目标节点之一，需要告诉祖先：
```
这条分支中找到了 p 或 q
```

第二种：当前节点可能就是答案。
例如：
```
p = 5
q = 4
```
而 `4` 在 `5` 的子树里，那么最近公共祖先就是 `5` 本身。

题目定义中明确说明：
> 一个节点可以是它自己的祖先。

---
### 3. 为什么左右都不为空时，当前节点一定是最近公共祖先？

假设：
```
left 找到了 p
right 找到了 q
```

说明 `p` 和 `q` 分别位于当前节点的左右子树。

它们要想同时拥有一个祖先，至少必须上升到当前节点。
而当前节点已经是两条路径第一次汇合的地方，所以它是**最近**公共祖先。

---

### 4. 为什么只有一边非空时直接返回那一边？
例如：
```
left = 5
right = nullptr
```
说明当前右子树中没有发现目标节点信息，所有有效信息都来自左子树。

因此当前节点不能确定为公共祖先，只需要把左边找到的结果继续向上传递：
```
return left;
```
这个 `left` 可能是单独找到的 `p/q`，也可能已经是左子树内部确定的最近公共祖先。

---

### 5. 为什么代码比较指针，而不是比较节点值？
代码写的是：
```
root == p
```

而不是：
```
root->val == p->val
```
因为题目给的 `p` 和 `q` 本身就是树中的节点指针，我们真正寻找的是这两个具体节点。
虽然本题节点值互不相同，比较值理论上也能判断，但比较指针更准确，也符合题目的参数定义。

---
## ⑥ 递归三要素

### 1. 递归函数定义

```
lowestCommonAncestor(root, p, q)
```

表示：
> 在以 `root` 为根的子树中寻找 `p` 和 `q`，返回找到的目标节点或它们的最近公共祖先；如果都没找到，返回 `nullptr`。

---
### 2. 终止条件

```
if (root == nullptr || root == p || root == q) {
    return root;
}
```
分别表示：
```
root == nullptr：
当前分支没有节点，返回空。

root == p：
当前分支找到 p，返回 p。

root == q：
当前分支找到 q，返回 q。
```

---
### 3. 当前层做什么
当前层先获取左右子树的搜索结果：
```cpp
TreeNode* left =
    lowestCommonAncestor(root->left, p, q);

TreeNode* right =
    lowestCommonAncestor(root->right, p, q);
```
然后判断：
```
左右都非空：
    当前 root 是最近公共祖先。

只有左边非空：
    返回 left。

只有右边非空：
    返回 right。

左右都为空：
    返回 nullptr。
```
这是一种典型的后序处理：
```
左子树 → 右子树 → 当前节点
```
因为必须先知道左右子树搜索结果，才能判断当前节点。

---
## ⑦ 为什么不推荐迭代作为主方法？

迭代方法通常需要：
```
1. 遍历整棵树
2. 用哈希表记录每个节点的父节点
3. 从 p 不断向上，将所有祖先放入集合
4. 从 q 不断向上，第一个出现在集合中的节点就是答案
```
这种方法可以实现，但需要：
```
unordered_map<TreeNode*, TreeNode*> parent;
unordered_set<TreeNode*> ancestors;
```
额外状态更多，代码更长。
递归方法直接利用了二叉树的结构：
```
左边找
右边找
当前节点汇总结果
```
所以更自然，也是面试中最推荐的方法。

## ⑧ 面试追问

### Q1：时间复杂度是多少？
最坏情况下需要访问整棵树：
```
时间复杂度：O(n)
```
其中 `n` 是节点数量。
递归调用栈深度等于树高 `h`：
```
空间复杂度：O(h)
```
平衡树：
```
O(log n)
```
退化成链表：
```
O(n)
```

---
### Q2：如果 p 或 q 不一定存在，代码还能直接使用吗？

当前题目保证：
```
p 和 q 都存在于树中
```
如果不保证存在，仅返回一个非空节点可能产生歧义。
例如只找到了 `p`，没有找到 `q`，当前代码最终可能返回 `p`，但实际上不存在公共祖先。
这种情况下需要额外记录：
```
是否找到 p
是否找到 q
```
只有二者都存在时，才返回公共祖先。

---

### Q3：如果这是二叉搜索树，可以优化吗？
可以利用 BST 性质：
```
如果 p、q 都小于 root：
    去左子树。

如果 p、q 都大于 root：
    去右子树。

否则：
    root 就是最近公共祖先。
```
但本题是普通二叉树，没有大小关系，所以必须搜索左右子树。

---

### 面试表达
> 我使用递归后序遍历。递归函数返回当前子树中找到的 `p`、`q` 或它们的最近公共祖先。如果当前节点为空，或者当前节点等于 `p` 或 `q`，直接返回当前节点。然后递归搜索左右子树：如果左右结果都非空，说明 `p` 和 `q` 分别位于当前节点两侧，当前节点就是最近公共祖先；否则返回非空的一侧继续向上传递。每个节点最多访问一次，时间复杂度为 `O(n)`，递归空间复杂度为 `O(h)`。

## ⑨ 复习总结
```
236. 二叉树的最近公共祖先

题型：
二叉树 DFS + 后序递归。

递归返回值：
当前子树中找到的 p、q 或最近公共祖先；
如果什么也没找到，返回 nullptr。

终止条件：
root == nullptr：
    返回 nullptr。

root == p 或 root == q：
    返回 root。

递归过程：
1. 去左子树寻找，得到 left。
2. 去右子树寻找，得到 right。
3. left 和 right 都非空：
   当前 root 是最近公共祖先。
4. 只有一边非空：
   返回非空的一边。
5. 两边都为空：
   返回 nullptr。
```

一句话记忆：
> **左右分别找到，当前节点就是祖先；只找到一边，就把这一边继续向上传。**
