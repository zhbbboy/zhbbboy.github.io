输入实体列表
  │
  ▼
① 输入准备
   检查输入、缝合选项和有效容差
  │
  ├─ 输入或选项不合法
  │    └─ 返回相应错误
  │
  ├─ 受限边缝合选项
  │    └─ 进入受限边专用流程
  │         检查输入边
  │           → 遍历候选边对
  │           → 判断几何、方向和拓扑
  │           → 缝合可匹配边
  │           → 收集并返回输出 BODY
  │
  └─ 精确缝合 / 普通容差缝合
       │
       ▼
     将输入整理为 BODY
       │
       ├─ 只有一个有效输入 BODY
       │    └─ 按接口规则直接返回
       │
       └─ 多个 BODY
            │
            ▼
② 部分曲线处理【仅普通容差缝合执行】
   │
   ├─ 收集受支持的自由边
   │    └─ 有几何、有端点、属于面、尚无 partner
   │
   ├─ 候选边搜索
   │    └─ 计算世界坐标边包围盒
   │         → 按 X 最小坐标排序
   │         → X 窗口筛选
   │         → Y、Z 范围筛选
   │
   ├─ 曲线区间匹配
   │    └─ 求共同区间、方向和间隙
   │
   ├─ 没有需要此路径处理的情况
   │    └─ 不在此处缝合，进入③
   │
   └─ 有需要此路径处理的情况
        │
        ├─ 按相关 BODY 分组
        ├─ 检查方向、面域及多伙伴歧义
        ├─ 必要时拆边，选出共同区间对应的子边
        ├─ 必要时建立容差边、容差顶点等表示
        ├─ 缝合子边，并可能处理同组其他完整接缝
        └─ 检查该路径修改后的结果
             │
             ├─ 某组不能安全处理
             │    └─ 回滚该组，保留后续路径继续处理
             │
             ├─ 出现需要上报的执行错误
             │    └─ 回滚并返回错误
             │
             └─ 已处理且只剩一个有效 BODY
                  └─ 返回结果

   【若为精确缝合，跳过②，直接进入③】
  │
  ▼
③ 简单单面批处理
   │
   ├─ 检查 BODY 是否满足简单单面拓扑条件
   │
   ├─ 不满足条件
   │    └─ 不由此路径完成，进入④
   │
   └─ 满足条件
        │
        ├─ 收集各面的边界和端点
        │
        ├─ 两个简单单面 BODY，且规模满足条件
        │    └─ 尝试直接扫描边对
        │
        └─ 一般批处理候选搜索
             └─ 端点按 X 坐标排序
                  → 在容差窗口内查找近邻端点
                  → 检查 Y、Z 坐标
                  → 构造候选边对
        │
        ▼
       检查完整边几何、端点、方向和拓扑
        │
        ├─ 条件满足
        │    └─ 缝合可执行的边对，更新拓扑
        │
        ├─ 此路径完成处理
        │    └─ 收集并返回输出 BODY
        │
        └─ 不适用或不能由此路径完成
             └─ 进入④
  │
  ▼
④ 特定边界预处理
   │
   ├─ 在满足条件的普通容差缝合输入中
   │    └─ 尝试恢复特定平面自由边界的完整邻接环
   │
   └─ 继续进入⑤
  │
  ▼
⑤ 精确闭合边界处理
   │
   ├─ 检查是否所有相关自由边都具有唯一精确配对
   │
   ├─ 满足条件
   │    └─ 缝合这些精确边对 → 收集并返回结果
   │
   └─ 不满足条件
        └─ 进入⑥
  │
  ▼
⑥ 通用流程前的端点预检查
   │
   ├─ 特定的两个 BODY 输入，可以进行预检查
   │    │
   │    ├─ 确定没有可接触端点
   │    │    └─ 返回保持分离的输出 BODY
   │    │
   │    └─ 找到可能接触的端点
   │         └─ 记录相关候选边和顶点，进入⑦
   │
   └─ 不满足预检查条件
        └─ 直接进入⑦
  │
  ▼
⑦ 通用 BODY 对处理
   │
   ├─ 选取一个当前 BODY
   │
   ├─ 寻找其他可能接触的 BODY
   │    │
   │    ├─ BODY 数量大于 8
   │    │    └─ 使用扩张的 BODY 包围盒排除远处体对
   │    │
   │    └─ BODY 数量不大于 8
   │         └─ 不使用此处的 BODY 盒筛选
   │
   └─ 对可能接触的 BODY 对调用 gme_stitch
        │
        ▼
⑧ gme_stitch：处理一对 BODY
   │
   ├─ 必要时统一两个 BODY 的坐标系
   │
   ├─ 收集两个 BODY 的 COEDGE / EDGE
   │
   ├─ 寻找候选边对
   │    │
   │    ├─ 两侧 COEDGE 数量乘积 ≤ 256
   │    │    └─ 直接双重遍历
   │    │
   │    └─ 两侧 COEDGE 数量乘积 > 256
   │         └─ 对第二个 BODY 的边端点建立空间哈希
   │              → 查询第一个 BODY 的端点所在格及邻近格
   │              → 得到候选边对
   │
   ├─ 逐对检查候选
   │    └─ 几何类型、端点、曲线几何
   │         → EDGE / COEDGE 方向
   │         → 面域、顶点替换和流形等条件
   │
   ├─ 某对边未通过
   │    └─ 跳过该对，继续检查其他候选
   │
   └─ 某对边通过
        └─ 执行边缝合
             ├─ 重接旧顶点相关的相邻边
             ├─ 两侧 COEDGE 使用共享 EDGE
             ├─ 建立或更新 partner 关系
             ├─ 必要时处理方向、参数曲线和旧实体
             └─ 更新 SHELL / LUMP / BODY 归属
        │
        ▼
       继续检查该 BODY 对中的其他候选边
        │
        ├─ 至少缝合了一对边
        │    └─ 返回成功，回到⑦
        │         当前 BODY 吸收对方后，继续尝试其他 BODY
        │
        └─ 没有缝合任何边
             └─ 返回不可缝结果，回到⑦尝试其他 BODY
  │
  ▼
⑨ 收集输出结果
   │
   ├─ 对每个无法再吸收其他体的当前 BODY，加入输出
   ├─ 继续处理尚未并入的 BODY
   └─ 返回 output_bodies / new_bodies
