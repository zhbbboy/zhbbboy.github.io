## 解题思路

这道题和你之前做过的 **53. 最大子数组和** 非常像，但它多了一个关键难点：

> **乘法遇到负数会“翻转大小关系”：原来的最小负数 × 负数，可能瞬间变成最大的正数。**

因此这题最推荐：

> **动态规划，同时维护“以当前位置结尾的最大乘积”和“以当前位置结尾的最小乘积”。**

这题不推荐递归。它本身是典型的从左到右状态转移，用迭代 DP 最自然。

---

# ① 破题：题目真正要求什么

例如：

```
nums = [2,3,-2,4]
```

题目要求找一个**连续子数组**，让乘积最大。

可能的子数组包括：

```
[2]            = 2
[3]            = 3
[-2]           = -2
[4]            = 4

[2,3]          = 6
[3,-2]         = -6
[-2,4]         = -8

[2,3,-2]       = -12
[3,-2,4]       = -24
[2,3,-2,4]     = -48
```

最大是：

```
[2,3]

2 × 3 = 6
```

所以返回：

```
6
```

注意题目要求：

> **连续子数组。**

所以不能跳着选：

```
[2,3,4]
```

因为原数组中间有 `-2`，不能跳过去。

---

# ② 核心技巧：为什么只记录最大值不够？

对于「最大子数组和」，我们只需要维护：

```
以 nums[i] 结尾的最大和
```

但是乘积不行。

比如：

```
nums = [-2, 3, -4]
```

来看。

到 `3` 时：

```
最大乘积 = 3
最小乘积 = -6
```

因为：

```
[3]      = 3
[-2,3]   = -6
```

接下来来了：

```
-4
```

如果你只保存之前的最大值 `3`：

```
3 × (-4) = -12
```

看起来不好。

但是之前的**最小值**：

```
-6
```

乘上：

```
-4
```

变成：

```
(-6) × (-4) = 24
```

突然成为最大值！

所以这题必须同时维护：

```
maxProduct：以当前位置结尾的最大乘积

minProduct：以当前位置结尾的最小乘积
```

因为：

> **负数 × 负数 = 正数，昨天最差的状态，今天可能变成最好的状态。**

---

## 状态转移

假设当前位置：

```
x = nums[i]
```

那么以 `i` 结尾的子数组只有三种来源：

```
① 不接前面的，自己重新开始：
x

② 接在前面的最大乘积后面：
maxProduct × x

③ 接在前面的最小乘积后面：
minProduct × x
```

所以：

这就是整道题的核心。

```
3

之前最小 × 3：

```


```
ans = 6
```

## 遇到 `-2`

现在：

```
之前：
max = 6
min = 3

当前：
x = -2
```

三个候选：

```
-2

6 × (-2) = -12

```

所以：

```
maxProduct = -2

```

```

```

虽然现在它非常差，但是我们**必须留下它**。

```

```

```

6
```

# ④ 完整代码

第一次学，我建议你先写最直观的 DP 数组版本。

```cpp
class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int n = nums.size();

        vector<int> maxDP(n);
        vector<int> minDP(n);

        maxDP[0] = nums[0];
        minDP[0] = nums[0];

        int ans = nums[0];

        for (int i = 1; i < n; ++i) {
            maxDP[i] = max(
                nums[i],
                max(
                    maxDP[i - 1] * nums[i],
                    minDP[i - 1] * nums[i]
                )
            );

            minDP[i] = min(
                nums[i],
                min(
                    maxDP[i - 1] * nums[i],
                    minDP[i - 1] * nums[i]
                )
            );

            ans = max(ans, maxDP[i]);
        }

        return ans;
    }
};
```

# ⑤ 关键设计解释

## 1. `maxDP[i]` 到底是什么？

一定要记准确：

```
maxDP[i]
=
必须以 nums[i] 结尾的连续子数组中，
乘积最大的那个。
```

比如：

```
nums = [2,3,-2,4]
```

对于：

```
i = 1
nums[i] = 3
```

以 `3` 结尾的连续子数组：

```
[3]
[2,3]
```

乘积：

```
3
6
```

所以：

```
maxDP[1] = 6
```

---

## 2. 为什么这样就保证了“连续”？

这是很重要的一点。

我们计算：

```
maxDP[i - 1] * nums[i]
```

意味着：

> 把 `nums[i]` 接到一个**以 `i-1` 结尾的连续子数组**后面。

例如：

```
... i-2, i-1
          ↓
再接 i
```

自然就是：

```
... i-2, i-1, i
```

仍然连续。

而另一种选择：

```
nums[i]
```

表示：

> 不接前面的，从当前位置重新开一个子数组。

所以状态永远只可能是：

```
继续连续地接
或者
从当前位置重新开始
```

不会出现跳着选元素。

---

## 3. 为什么还需要 `minDP[i]`？

因为负数会翻转最大最小。

例如：

```
之前：

最大 = 3
最小 = -6

现在：
x = -4
```

则：

```
最大 × 负数：
3 × -4 = -12

最小 × 负数：
-6 × -4 = 24
```

原来的最小值，反而产生了新的最大值。

所以：

> **乘积 DP 与和 DP 最大的区别，就是必须同时维护 max 和 min。**

---

## 4. 为什么要考虑 `nums[i]` 自己？

例如：

```
nums = [-2, 3]
```

到了 `3`。

如果强行接前面：

```
-2 × 3 = -6
```

但是我们完全可以：

```
把前面的 -2 丢掉
从 3 重新开始
```

得到：

```
[3]
```

乘积：

```
3
```

所以一定要比较：

```
nums[i]
```

这代表：

> **从当前位置重新开一个子数组。**

---

# 5. `0` 会怎么样？

例如：

```
nums = [-2, 0, -3]
```

遇到 `0` 时三个候选：

```
0
前最大 × 0 = 0
前最小 × 0 = 0
```

所以：

```
max = 0
min = 0
```

相当于前面的乘积链断掉。

后面遇到：

```
-3
```

就可以重新开始：

```
[-3]
```

因此根本不需要单独写：

```
if (nums[i] == 0)
```

DP 会自然处理。

---

# 6. 为什么答案不能直接返回最后的 `maxDP[n-1]`？

因为最大乘积子数组不一定以最后一个元素结尾。

例如：

```
nums = [2,3,-2]
```

最大乘积：

```
[2,3] = 6
```

但是最后：

```
maxDP[2] = -2
```

如果返回：

```
maxDP[n - 1]
```

会得到：

```
-2
```

错误。

所以需要一个：

```
ans
```

记录所有位置：

```
maxDP[0]
maxDP[1]
...
maxDP[n-1]
```

中的最大值。

---

# ⑥ 为什么不推荐递归？

理论上当然可以递归枚举：

```
当前位置继续乘
或者
当前位置重新开始
```

但：

- 会有大量重复状态；
- 还要同时记录最大、最小；
- 状态天然只依赖前一个位置。

所以这题明显更适合：

> **从左到右迭代 DP。**

不需要为了递归而递归。

---

# ⑦ 空间优化：面试推荐版本

观察：

```
maxDP[i]
minDP[i]
```

只依赖：

```
maxDP[i-1]
minDP[i-1]
```

所以不需要整个数组。

只保存前一个状态即可：

```
class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int maxProduct = nums[0];
        int minProduct = nums[0];

        int ans = nums[0];

        for (int i = 1; i < nums.size(); ++i) {
            int x = nums[i];

            // 一定要先保存旧值
            int oldMax = maxProduct;
            int oldMin = minProduct;

            maxProduct = max(
                x,
                max(oldMax * x, oldMin * x)
            );

            minProduct = min(
                x,
                min(oldMax * x, oldMin * x)
            );

            ans = max(ans, maxProduct);
        }

        return ans;
    }
};
```

---

## 为什么必须保存 `oldMax` 和 `oldMin`？

这是代码里很容易写错的地方。

不能直接：

```
maxProduct = ...;

minProduct = min(
    x,
    min(maxProduct * x, minProduct * x)
);
```

因为此时：

```
maxProduct
```

已经是**当前轮新值**了。

但计算新的 `minProduct` 时，需要的是：

```
上一轮的 maxProduct
上一轮的 minProduct
```

所以必须：

```
int oldMax = maxProduct;
int oldMin = minProduct;
```

然后两个新状态都基于旧状态计算。

# ⑧ 面试追问

### Q1：这题和 53. 最大子数组和最大的区别是什么？

53 最大子数组和：

```
只需要维护最大值。
```

因为加法不会改变大小关系。

152 最大乘积子数组：

```
必须同时维护最大值和最小值。
```

因为：

```
负数 × 负数 = 正数
```

最小值可能在下一步变成最大值。

---

### Q2：为什么不能用滑动窗口？

因为数组中可能出现：

```
负数
0
```

乘积并不具有简单的单调性。

加入一个元素后：

```
结果可能变大
也可能变小
甚至符号翻转
```

因此不能像某些正数数组问题那样根据大小简单移动左右指针。

---

### Q3：复杂度是多少？

DP 数组版：

```
时间：O(n)
空间：O(n)
```

滚动变量优化：

```
时间：O(n)
空间：O(1)
```

面试最终推荐：

```
O(n) 时间 + O(1) 空间
```

---

### Q4：如果全是负数怎么办？

例如：

```
[-2]
```

答案就是：

```
-2
```

所以初始化千万不能写：

```
int ans = 0;
```

否则会错误返回 `0`。

应该：

```
int ans = nums[0];
```

同理：

```
maxProduct = nums[0];
minProduct = nums[0];
```

---

### 面试表达

> 我定义两个状态，分别表示以当前位置结尾的最大乘积和最小乘积。之所以要同时维护最小值，是因为当前元素如果为负数，之前的最小负乘积乘上负数可能转化成新的最大正乘积。对于当前 `nums[i]`，新的最大值从 `nums[i]`、上一轮最大值乘 `nums[i]`、上一轮最小值乘 `nums[i]` 三者中取最大，最小值同理取最小。再用全局变量记录所有位置的最大值。状态只依赖前一轮，因此可以优化到 O(1) 空间。

# ⑨ 复习总结

```
152. 乘积最大子数组

题型：
一维 DP

核心难点：
负数会让最大值和最小值交换身份。

状态：

maxProduct =
以当前位置结尾的最大乘积

minProduct =
以当前位置结尾的最小乘积

当前位置 x 有三种可能：

1. 从 x 自己重新开始

2. 前面的最大乘积 × x

3. 前面的最小乘积 × x

所以：

newMax =
max(x, oldMax*x, oldMin*x)

newMin =
min(x, oldMax*x, oldMin*x)

全局答案：
ans = max(ans, newMax)

注意：
必须保存 oldMax / oldMin，
不能让更新后的状态污染当前计算。

复杂度：
O(n) 时间
O(1) 空间
```

你可以把 **53 最大子数组和** 和这题一起记：

```
53 最大子数组和：

当前要么自己开始，
要么接前面的最大和。

152 最大乘积子数组：

当前要么自己开始，
要么接前面的最大乘积，
要么接前面的最小乘积。

为什么多一个最小值？

因为负 × 负 = 正。
```

**一句话记忆：**

> **乘积最大子数组不能只记最大值：负数可能把“最小负数”翻成“最大正数”，所以每个位置都同时维护最大乘积和最小乘积。**
