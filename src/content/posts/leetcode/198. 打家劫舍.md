## 解题思路

# 198. 打家劫舍

这道题是非常经典的 **一维动态规划**。

推荐主方法：

> **DP：当前位置只有“偷”和“不偷”两种决策。**

它和刚才的“爬楼梯”很像：都是让 `dp[i]` 由前面的状态推出来。

普通递归也能做，但会重复计算，所以不推荐作为最终解法。

---

# ① 破题：题目真正要求什么

给你：

```cpp
nums = [2, 7, 9, 3, 1]
```

`nums[i]` 表示第 `i` 间房里的钱。

限制：

> **不能偷相邻的两间房。**

也就是说，如果偷了：

```text
nums[i]
```

就不能偷：

```text
nums[i - 1]
```

题目要求：

> 在不偷相邻房屋的情况下，最多能偷多少钱？

例如：

```text
[2,7,9,3,1]
```

可以偷：

```text
2 + 9 + 1 = 12
```

答案：

```text
12
```

---

# ② 核心技巧：对于第 i 间房，只有偷或不偷

这是这题最关键的思路。

假设现在来到第 `i` 间房。

你只有两个选择。

### 选择 1：不偷第 i 间房

那么最大金额仍然是：

```text
前 i-1 间房能够得到的最大金额
```

也就是：

```cpp
dp[i - 1]
```

---

### 选择 2：偷第 i 间房

如果偷当前房：

```text
nums[i]
```

那么第 `i-1` 间不能偷。

所以只能接：

```text
前 i-2 间房的最大金额
```

于是金额是：

```cpp
dp[i - 2] + nums[i]
```

---

所以：

翻译成一句话：

> **当前最大值 = 偷当前房 和 不偷当前房 两种方案中更大的那个。**

这是整道题的灵魂。

---

# ③ 图解执行过程

使用：

```cpp
nums = [2,7,9,3,1]
```

定义：

```text
dp[i] = 偷到第 i 间房为止，能够获得的最大金额
```

注意：

> `dp[i]` 并不代表一定偷第 `i` 间房。

而是：

> **考虑了 `0~i` 这些房屋以后能获得的最大值。**

---

## 第 0 间房

只有：

```text
[2]
```

当然偷：

```text
dp[0] = 2
```

---

## 第 1 间房

房屋：

```text
[2,7]
```

因为不能同时偷，所以：

```text
偷 2：获得 2
偷 7：获得 7
```

选择大的：

```text
dp[1] = 7
```

---

## 第 2 间房：金额 9

现在：

```text
[2,7,9]
```

考虑：

### 不偷 9

继承：

```text
dp[1] = 7
```

### 偷 9

不能偷前面的 `7`。

因此：

```text
dp[0] + 9
= 2 + 9
= 11
```

取最大：

```text
dp[2] = max(7, 11)
      = 11
```

对应方案：

```text
2 + 9
```

---

## 第 3 间房：金额 3

```text
[2,7,9,3]
```

### 不偷 3

```text
dp[2] = 11
```

### 偷 3

不能使用第 2 间房：

```text
dp[1] + 3
= 7 + 3
= 10
```

取：

```text
dp[3] = max(11,10)
      = 11
```

所以这间房：

> **不偷反而更赚。**

---

## 第 4 间房：金额 1

### 不偷 1

```text
dp[3] = 11
```

### 偷 1

```text
dp[2] + 1
= 11 + 1
= 12
```

所以：

```text
dp[4] = 12
```

最终：

```text
dp = [2,7,11,11,12]
```

答案：

```text
12
```

对应：

```text
2 + 9 + 1
```

# ④ 完整代码

第一次学习建议先写 `dp` 数组。

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();

        if (n == 1) {
            return nums[0];
        }

        vector<int> dp(n);

        dp[0] = nums[0];
        dp[1] = max(nums[0], nums[1]);

        for (int i = 2; i < n; ++i) {
            dp[i] = max(
                dp[i - 1],
                dp[i - 2] + nums[i]
            );
        }

        return dp[n - 1];
    }
};
```

# ⑤ 关键设计解释

## 1. `dp[i]` 到底表示什么？

一定要记准确：

```text
dp[i]
=
考虑 nums[0] ~ nums[i]
这些房屋时，
能够偷到的最大金额。
```

不是：

```text
一定偷第 i 间房后的金额
```

这是初学 DP 最容易搞错的地方。

例如：

```text
nums = [2,7,9,3]
```

我们得到：

```text
dp[3] = 11
```

但方案其实是：

```text
2 + 9
```

第 `3` 间房金额 `3` 根本没偷。

所以：

> `dp[i]` 表示“考虑到这里的最优答案”，不是“必须选择当前元素”。

---

## 2. 为什么不偷当前房是 `dp[i-1]`？

因为如果第 `i` 间不偷：

```text
前面的决策完全不受影响
```

所以直接使用前 `i-1` 间的最优答案：

```cpp
dp[i - 1]
```

---

## 3. 为什么偷当前房是 `dp[i-2] + nums[i]`？

因为：

```text
i 和 i-1 相邻
```

偷 `i` 就绝对不能偷 `i-1`。

因此只能接到：

```text
0 ~ i-2
```

这些房子的最优方案：

```cpp
dp[i - 2]
```

再加当前金额：

```cpp
nums[i]
```

因此：

```cpp
dp[i - 2] + nums[i]
```

---

## 4. 为什么不能写 `dp[i-1] + nums[i]`？

因为 `dp[i-1]` 的最优方案有可能已经偷了第 `i-1` 间房。

例如：

```text
nums = [2,7,9]
```

```text
dp[1] = 7
```

如果写：

```text
dp[1] + nums[2]
= 7 + 9
```

相当于同时偷：

```text
7 和 9
```

而它们相邻，违反题目条件。

所以偷当前房必须跨过前一间：

```cpp
dp[i - 2] + nums[i]
```

---

## 5. 为什么初始化这样写？

```cpp
dp[0] = nums[0];
```

只有一间房，最大金额当然就是它自己。

第二间：

```cpp
dp[1] = max(nums[0], nums[1]);
```

因为两间相邻，只能二选一。

例如：

```text
[2,7]
```

最大就是：

```text
7
```

# ⑥ 动态规划五步法

这题建议你用下面这个模板复习。

### 第一步：定义 `dp`

```text
dp[i] =
考虑前 0~i 间房时能偷到的最大金额
```

### 第二步：状态转移

第 `i` 间房：

```text
不偷：
dp[i-1]

偷：
dp[i-2] + nums[i]
```

取最大：

```cpp
dp[i] = max(
    dp[i - 1],
    dp[i - 2] + nums[i]
);
```

### 第三步：初始化

```cpp
dp[0] = nums[0];
dp[1] = max(nums[0], nums[1]);
```

### 第四步：遍历顺序

当前状态依赖：

```text
i-1
i-2
```

所以从左往右：

```cpp
for (int i = 2; i < n; ++i)
```

### 第五步：返回答案

```cpp
return dp[n - 1];
```

# ⑦ 空间优化：面试可以写这个版本

观察：

```cpp
dp[i] = max(dp[i-1], dp[i-2] + nums[i]);
```

只使用：

```text
dp[i-1]
dp[i-2]
```

所以整个 `dp` 数组其实不需要保存。

可以只保存前两个状态：

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();

        if (n == 1) {
            return nums[0];
        }

        int prev2 = nums[0];
        int prev1 = max(nums[0], nums[1]);

        for (int i = 2; i < n; ++i) {
            int cur = max(
                prev1,
                prev2 + nums[i]
            );

            prev2 = prev1;
            prev1 = cur;
        }

        return prev1;
    }
};
```

例如：

```text
nums = [2,7,9,3,1]
```

开始：

```text
prev2 = 2
prev1 = 7
```

遇到 `9`：

```text
cur = max(7, 2+9)
    = 11
```

移动：

```text
prev2 = 7
prev1 = 11
```

遇到 `3`：

```text
cur = max(11, 7+3)
    = 11
```

继续直到最后。

空间复杂度：

```text
O(1)
```

# ⑧ 面试追问

## Q1：为什么这道题不能贪心？

例如你可能想：

> 每次都偷当前金额较大的房。

但局部最大不一定得到全局最大。

例如：

```text
[2,7,9,3,1]
```

不能简单根据某两间大小局部决定，因为当前选择会影响后面的可选择范围。

DP 会同时保留：

```text
偷当前
不偷当前
```

两种可能产生的最优结果。

---

## Q2：如果房屋首尾相连怎么办？

例如房屋形成一个环：

```text
0 -- 1 -- 2 -- 3
|              |
----------------
```

那么：

```text
第 0 间
和
最后一间
```

也不能同时偷。

这就是 LeetCode 213「打家劫舍 II」。

核心做法：

```text
情况一：不考虑最后一间
rob(0 ~ n-2)

情况二：不考虑第一间
rob(1 ~ n-1)

取最大值。
```

因为第一间和最后一间至少有一个不能偷。

---

## Q3：如果房屋变成二叉树呢？

这就是 LeetCode 337「打家劫舍 III」。

每个树节点同样有：

```text
偷当前节点
不偷当前节点
```

两个状态。

所以这道题实际上是一整类问题的基础：

> **对于每个位置做“选 / 不选”，并且选择当前会限制相邻状态。**

---

## Q4：时间复杂度？

DP 数组：

```text
时间：O(n)
空间：O(n)
```

滚动变量：

```text
时间：O(n)
空间：O(1)
```

```text

```

> **走到每间房只问两个问题：偷它，就拿 `dp[i-2] + nums[i]`；不偷它，就拿 `dp[i-1]`，两者取最大。**
