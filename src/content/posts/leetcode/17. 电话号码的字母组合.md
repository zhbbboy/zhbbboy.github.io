这道题最适合使用：
> **回溯 + 递归索引 `index`**

它和刚才的“全排列”“子集”都是回溯题，但选择规则不同：

```text
全排列：当前位置可以从所有未使用元素中选择
子集：从 startIndex 之后选择元素
电话号码：第 index 个位置，只能从当前数字对应的字母中选择
```
普通迭代也能实现，但回溯写法更自然，也更容易迁移到其他“多个位置分别选择一个候选项”的题目。

---
# ① 破题：题目真正要求什么

手机数字与字母的对应关系是：
```text
2 → abc
3 → def
4 → ghi
5 → jkl
6 → mno
7 → pqrs
8 → tuv
9 → wxyz
```
例如输入：
```cpp
digits = "23";
```
第一个位置来自数字 `2`，可以选择：
```text
a、b、c
```
第二个位置来自数字 `3`，可以选择：
```text
d、e、f
```
因此所有组合是：
```text
ad  ae  af
bd  be  bf
cd  ce  cf
```
返回：
```cpp
["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

---
## 这题本质上在做什么？

输入有几个数字，最终字符串就有几个位置。
例如：
```cpp
digits = "23";
```
有两个数字，因此每个答案长度都是 `2`：
```text
第 0 个位置：从 "abc" 中选择一个字母
第 1 个位置：从 "def" 中选择一个字母
```

再例如：

```cpp
digits = "279";
```

需要决定三个位置：

```text
第 0 个位置：从 "abc" 中选一个
第 1 个位置：从 "pqrs" 中选一个
第 2 个位置：从 "wxyz" 中选一个
```

所以这题的核心就是：

> 每层递归处理一个数字，并从这个数字对应的字母中选择一个。

---

# ② 核心技巧：数字映射 + 回溯

首先需要保存数字与字母的映射：
```cpp
vector<string> mapping = {
    "",     // 0
    "",     // 1
    "abc",  // 2
    "def",  // 3
    "ghi",  // 4
    "jkl",  // 5
    "mno",  // 6
    "pqrs", // 7
    "tuv",  // 8
    "wxyz"  // 9
};
```
之所以前面放两个空字符串，是为了让：
```cpp
mapping[2]
```
直接得到：
```cpp
"abc"
```
而不用额外做下标偏移。

## 回溯中的三个状态

我们需要维护：
```cpp
index
```
表示当前正在处理 `digits` 中的第几个数字。
```cpp
path
```
表示当前已经选择出的字母组合。
```cpp
result
```
保存所有完整答案。

例如：
```text
digits = "23"

index = 0
path = ""
```
表示准备处理数字 `'2'`。
选择 `'a'` 后：
```text
index = 1
path = "a"
```
表示数字 `'2'` 已经处理完，现在处理数字 `'3'`。
再选择 `'d'`：
```text
index = 2
path = "ad"
```
此时所有数字都处理完，保存 `"ad"`。

---

## 回溯固定流程
```text
1. 找到当前数字对应的字母
2. 依次选择其中一个字母
3. 将字母加入 path
4. 递归处理下一个数字
5. 删除刚加入的字母
6. 尝试下一个字母
```
代码形式：
```cpp
for (char letter : letters) {
    path.push_back(letter);  // 做选择

    backtrack(index + 1);    // 处理下一个数字

    path.pop_back();         // 撤销选择
}
```

# ④ 完整代码

```cpp
class Solution {
private:
    vector<string> result;
    string path;

    const vector<string> mapping = {
        "",     // 0
        "",     // 1
        "abc",  // 2
        "def",  // 3
        "ghi",  // 4
        "jkl",  // 5
        "mno",  // 6
        "pqrs", // 7
        "tuv",  // 8
        "wxyz"  // 9
    };

    void backtrack(const string& digits, int index) {
        // 所有数字都已经处理完成
        if (index == digits.size()) {
            result.push_back(path);
            return;
        }

        // 当前字符数字转换为整数下标
        int digit = digits[index] - '0';

        // 找到当前数字对应的所有字母
        const string& letters = mapping[digit];

        // 为当前字符串位置选择一个字母
        for (char letter : letters) {
            // 1. 做选择
            path.push_back(letter);

            // 2. 递归处理下一个数字
            backtrack(digits, index + 1);

            // 3. 撤销选择
            path.pop_back();
        }
    }

public:
    vector<string> letterCombinations(string digits) {
        // 空字符串没有任何字母组合
        if (digits.empty()) {
            return {};
        }

        backtrack(digits, 0);

        return result;
    }
};
```

# ⑤ 关键设计解释

## 1. `digits[index] - '0'` 是什么意思？

`digits[index]` 是字符，不是整数。

例如：

```cpp
digits[index] == '2';
```

我们需要将字符 `'2'` 转换成整数 `2`：

```cpp
int digit = digits[index] - '0';
```

因为字符编码连续：

```cpp
'2' - '0' == 2
'7' - '0' == 7
'9' - '0' == 9
```

于是：

```cpp
mapping[digit]
```

就可以得到对应字母。

例如：

```cpp
digit = 2;
mapping[2] == "abc";
```

注意不要直接写：

```cpp
mapping[digits[index]]
```

因为字符 `'2'` 的编码值并不是整数下标 `2`。

---

## 2. `index` 表示什么？

```cpp
int index
```

表示：

> 当前正在处理 `digits` 中第几个数字。

例如：

```text
digits = "279"
```

状态可能是：

```text
index = 0：处理数字 2
index = 1：处理数字 7
index = 2：处理数字 9
index = 3：三个数字全部处理完
```

每次选择一个字母后：

```cpp
backtrack(digits, index + 1);
```

进入下一层，处理下一个数字。

---

## 3. 为什么终止条件是 `index == digits.size()`？

一个合法答案必须为每个数字选择一个字母。

例如：

```text
digits = "23"
digits.size() = 2
```

当：

```text
index = 2
```

说明：

```text
数字 2 已经处理
数字 3 已经处理
```

此时 `path` 已经是完整组合，例如：

```text
"ad"
```

所以保存：

```cpp
result.push_back(path);
```

---

## 4. 为什么不是判断 `path.size()`？

实际上也可以写：

```cpp
if (path.size() == digits.size())
```

因为每个数字恰好选择一个字母，所以二者长度始终一致。

但使用：

```cpp
index == digits.size()
```

更直接表达：

> 所有数字都已经处理完成。

`index` 同时还负责确定当前使用哪个数字，因此推荐使用 `index`。

---

## 5. 为什么空字符串要单独返回空数组？

题目规定：

```cpp
digits = ""
```

时返回：

```cpp
[]
```

如果不单独处理，直接调用：

```cpp
backtrack(digits, 0);
```

此时一开始就满足：

```cpp
index == digits.size()
```

于是会把空字符串加入结果：

```cpp
[""]
```

但题目要求的是：

```cpp
[]
```

所以必须先判断：

```cpp
if (digits.empty()) {
    return {};
}
```

这里：

```text
[]
```

表示没有任何组合。

而：

```text
[""]
```

表示有一个组合，只不过它是空字符串。

二者含义不同。

---

## 6. 为什么不需要 `used` 数组？

全排列中需要 `used`，因为同一个数字不能在一个排列中重复使用。

但本题每一层对应一个固定数字：

```text
第 0 层只处理 digits[0]
第 1 层只处理 digits[1]
第 2 层只处理 digits[2]
```

选择完当前数字对应的一个字母后，就进入下一个数字，不会再次回到同一个位置选择。

因此不需要记录字母是否使用过。

例如：

```cpp
digits = "22";
```

结果中可以出现：

```text
"aa"
```

这是合法的，因为两个 `'a'` 分别来自两个不同的数字位置。

所以也不能使用全局 `used` 禁止重复字母。

---

## 7. 为什么不使用 `startIndex`？

子集题中使用 `startIndex`，是为了让数组下标只能向后选择，避免：

```text
[1,2]
[2,1]
```

这种重复集合。

但本题选择顺序由输入数字固定：

```text
先处理 digits[0]
再处理 digits[1]
再处理 digits[2]
```

所以只需要：

```cpp
index + 1
```

不需要在同一个候选数组中设置起点。

---

## 8. 为什么要回溯 `path.pop_back()`？

假设当前：

```text
path = "ad"
```

记录 `"ad"` 后，还需要生成：

```text
"ae"
```

所以必须先撤销字母 `'d'`：

```cpp
path.pop_back();
```

恢复成：

```text
path = "a"
```

然后再加入 `'e'`：

```text
path = "ae"
```

如果不撤销，可能会变成：

```text
"ade"
```

这显然不是两个数字产生的合法结果。

---

# ⑥ 递归三要素

## 1. 递归函数定义

```cpp
backtrack(digits, index)
```

表示：

> 当前已经为 `digits[0...index-1]` 选择好了字母，接下来从 `digits[index]` 开始继续生成所有可能的组合。

例如：

```text
digits = "23"
index = 1
path = "a"
```

表示：

> 数字 `2` 已选择字母 `a`，现在为数字 `3` 选择字母。

---

## 2. 递归终止条件

```cpp
if (index == digits.size()) {
    result.push_back(path);
    return;
}
```

所有数字都已经处理，形成一个完整组合。

---

## 3. 当前层做什么？

当前层只负责：

> 从当前数字对应的字母中选择一个。

流程：

```text
1. 将 digits[index] 转换成整数。
2. 找到它对应的字母字符串。
3. 依次选择其中每个字母。
4. 将字母加入 path。
5. 递归处理 index + 1。
6. 删除刚加入的字母。
7. 尝试当前数字对应的下一个字母。
```

---

# ⑦ 为什么本题不重点讲迭代法？

迭代也可以做。

例如初始：

```text
result = [""]
```

处理数字 `2` 后：

```text
["a", "b", "c"]
```

处理数字 `3` 后，把每个已有字符串分别拼接 `d、e、f`：

```text
["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

但回溯写法更能体现：

```text
每个位置选择一个候选项
→ 递归处理下一个位置
→ 撤销后尝试其他候选项
```

这个模板可以继续迁移到：

```text
括号生成
组合总和
N 皇后
单词搜索
IP 地址复原
```

所以本题建议重点掌握回溯。

# ⑧ 面试追问

## Q1：这题和全排列有什么区别？

### 全排列

每层可以从所有未使用数字中选择：

```text
候选范围是整个 nums
需要 used 数组
```

### 电话号码组合

每层只能从当前数字对应的字母中选择：

```text
候选范围是 mapping[digits[index]]
不需要 used
```

---

## Q2：这题和子集有什么区别？

### 子集

每个元素可以选，也可以不选：

```text
结果长度不固定
使用 startIndex
每个递归节点都是答案
```

### 电话号码组合

每个数字必须恰好选择一个字母：

```text
结果长度固定为 digits.size()
使用 index
只有处理完全部数字才保存答案
```

---

## Q3：时间复杂度是多少？

数字：

```text
2、3、4、5、6、8
```

各对应 3 个字母。

数字：

```text
7、9
```

各对应 4 个字母。

如果输入长度为 `n`，最坏情况下全部是 `7` 或 `9`，组合数量为：

```text
4^n
```

每个答案长度为 `n`，保存答案需要复制字符串，因此总时间复杂度为：

```text
O(n × 4^n)
```

更准确地说，组合数量等于每个数字对应字母数量的乘积。

---

## Q4：辅助空间复杂度是多少？

不计算最终结果：

```text
path 长度最多为 n
递归栈深度最多为 n
```

所以辅助空间复杂度：

```text
O(n)
```

最终答案本身最多需要：

```text
O(n × 4^n)
```

空间。

---

## Q5：为什么递归树的每层候选数量不同？

因为不同数字对应的字母数量不同：

```text
2 → 3 个字母
7 → 4 个字母
```

例如：

```cpp
digits = "27";
```

组合数：

```text
3 × 4 = 12
```

不是每一层都固定有三个分支。

## 面试表达

> 我使用回溯算法。首先建立数字到字母字符串的映射，递归参数 `index` 表示当前正在处理输入中的第几个数字。每层递归获取当前数字对应的字母集合，依次选择一个字母加入 `path`，递归处理下一个数字，返回后撤销选择。当 `index` 等于输入长度时，说明每个数字都已经选择了一个字母，将当前字符串加入结果。最坏时间复杂度为 `O(n·4^n)`，辅助空间复杂度为 `O(n)`。

# ⑨ 复习总结

```text
17. 电话号码的字母组合

题型：
回溯 + 多位置选择。

核心含义：
输入中的每个数字对应答案中的一个位置；
每个位置从当前数字对应的字母中选择一个。

核心变量：
result：保存所有组合。
path：当前组合字符串。
index：当前正在处理第几个数字。

流程：
1. 空输入直接返回空数组。
2. 根据 digits[index] 找到对应字母。
3. 遍历当前数字对应的所有字母。
4. path.push_back(letter)。
5. 递归处理 index + 1。
6. path.pop_back() 回溯。
7. 当 index == digits.size() 时保存答案。
```

三类回溯题对比：

```text
全排列：
每层从所有未使用元素中选择
→ used

子集：
每层只从当前位置之后选择
→ startIndex

电话号码组合：
每层处理一个固定数字
→ index
```

一句话记忆：

> **每层处理一个数字，从它对应的字母中选一个；选完递归下一位，回来后撤销选择。**
