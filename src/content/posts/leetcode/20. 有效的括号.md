这题最推荐的方法就是：

> **栈 `stack`。**

核心思想非常简单：

> 左括号先入栈；遇到右括号时，它必须和**最近一个还没有匹配的左括号**配对。

之所以用栈，就是因为括号匹配具有明显的：

> **后进先出 LIFO**

特征。

---

## ① 破题：题目真正要求什么

有三种括号：

```
()
[]
{}
```

合法必须同时满足：

```
左右括号类型一致
括号顺序正确
所有左括号最终都被匹配
```

例如：

```
()[]{}      true
([])        true
{[]}        true
```

而：

```
(]          false
([)]        false
((          false
```

特别注意：

```
([)]
```

虽然：

```
( 有 )
[ 有 ]
```

数量都对，但顺序不对。

因为：

```
(
  [
    )
```

当 `)` 出现时，最近等待匹配的是：

```
[
```

它应该等的是：

```
]
```

而不是 `)`。

所以必须返回 `false`。

---

# ② 核心技巧：栈

遇到左括号：

```
'('
'['
'{'
```

直接入栈。

例如：

```
s = "(["
```

执行：

```
读取 '('

stack:
(


读取 '['

stack:
(
[
↑ top
```

注意栈顶是：

```
[
```

---

当遇到右括号时，比如：

```
]
```

它必须匹配：

```
栈顶的 [
```

如果栈顶不是对应的左括号：

```
return false;
```

如果匹配：

```
st.pop();
```

表示这一对括号已经处理完成。

# ③ 图解执行过程

看：

```
s = "([])"
```

---

### 第一个字符 `(`

左括号：

```
st.push('(');
```

栈：

```
(
```

---

### 第二个字符 `[`

继续入栈：

```
(
[
↑ top
```

---

### 第三个字符 `]`

这是右括号。

它对应：

```
[
```

而当前：

```
st.top() == '['
```

匹配成功。

所以：

```
st.pop();
```

变成：

```
(
```

---

### 第四个字符 `)`

它对应：

```
(
```

而：

```
st.top() == '('
```

匹配。

继续：

```
st.pop();
```

最终：

```
stack = empty
```

所有括号全部匹配：

```
true
```

过程：

```
(
```

然后：

```
(

```

接下来遇到：

```

```


> **当前右括号只能和最近一个没有匹配的左括号配对。**

# ④ 完整代码

我建议你先掌握这个最直观版本：

```cpp
class Solution {
public:
    bool isValid(string s) {
        stack<char> st;

        for (char ch : s) {

            // 左括号直接入栈
            if (ch == '(' || ch == '[' || ch == '{') {
                st.push(ch);
            }
            else {
                // 出现右括号，但没有左括号可以匹配
                if (st.empty()) {
                    return false;
                }

                // 检查类型是否匹配
                if (ch == ')' && st.top() != '(') {
                    return false;
                }

                if (ch == ']' && st.top() != '[') {
                    return false;
                }

                if (ch == '}' && st.top() != '{') {
                    return false;
                }

                // 匹配成功，弹出左括号
                st.pop();
            }
        }

        // 最后必须全部匹配完
        return st.empty();
    }
};
```

# ⑤ 关键设计解释

### 为什么只把左括号放进栈？

因为右括号的作用就是：

> 去消掉一个之前留下来的左括号。

例如：

```
({[]})
```

左括号不断入栈：

```
(
{
[
```

然后：

```
]
```

消掉 `[`：

```
(
{
```

接着：

```
}
```

消掉 `{`：

```
(
```

最后：

```
)
```

消掉 `(`。

所以栈其实保存的是：

> **当前还没有找到配对右括号的左括号。**

这个定义很重要。

---

### 为什么一定检查 `st.empty()`？

假设：

```
s = ")"
```

第一个字符就是右括号。

如果直接：

```
st.top()
```

但栈为空，会非法访问。

而且从逻辑上也说明：

> 这个右括号根本没有对应的左括号。

所以：

```
if (st.empty()) {
    return false;
}
```

---

### 为什么匹配之后一定要 `pop()`？

例如：

```
()
```

遇到：

```
(
```

入栈。

然后遇到：

```
)
```

这一对已经匹配成功。

所以之前的：

```
(
```

已经不能再参与后面的匹配，必须：

```
st.pop();
```

否则比如：

```
())
```

后面的第二个 `)` 可能错误地再次使用同一个 `(`。

---

### 为什么最后还要：

```
return st.empty();
```

因为可能出现：

```
(((
```

整个遍历过程中：

> 没有任何“错误的右括号”。

所以不会提前 `return false`。

但最后栈：

```
(
(
(
```

还有三个没有配对的左括号。

显然不合法。

所以最后必须保证：

```
stack为空
```

也就是：

> 每个左括号都成功找到了对应右括号。

# ⑥ 这题不推荐递归

这题没有必要递归。

因为我们只需要：

```
从左向右扫描字符串
+
维护一个栈
```

没有类似：

```
当前有多个选择
→ 递归尝试
→ 回溯
```

这样的搜索树。

所以这题明显是：

> **迭代 + 栈**

而不是递归/回溯。

# ⑦ 一个更简洁的写法

还有一种很经典的方法：

> 遇到左括号时，不是把左括号自己入栈，而是把它“期待的右括号”入栈。

例如遇到：

```
(
```

就：

```
st.push(')');
```

遇到：

```
[
```

就：

```
st.push(']');
```

遇到：

```
{
```

就：

```
st.push('}');
```

这样遇到右括号以后只需要：

```
if (st.empty() || st.top() != ch)
    return false;
```

完整代码：

```cpp
class Solution {
public:
    bool isValid(string s) {
        stack<char> st;

        for (char ch : s) {
            if (ch == '(') {
                st.push(')');
            }
            else if (ch == '[') {
                st.push(']');
            }
            else if (ch == '{') {
                st.push('}');
            }
            else {
                if (st.empty() || st.top() != ch) {
                    return false;
                }

                st.pop();
            }
        }

        return st.empty();
    }
};
```

这个版本代码更漂亮。

但是如果你现在正在第一次理解这题，我更建议先掌握前面的：

```
存左括号
→ 右括号检查栈顶
```

因为逻辑更直接。

# ⑧ 面试追问

最重要的问题是：**为什么括号匹配一定适合栈？**

例如：

```
([{}])
```

括号闭合的顺序：

```
第一个进入：(
第二个进入：[
第三个进入：{

第一个关闭：}
第二个关闭：]
第三个关闭：)
```

你会发现：

```
最后进去的 {
最先出来

然后 [
然后 (
```

正好是：

```
LIFO
Last In First Out
后进先出
```

所以栈天然适合括号匹配。

时间复杂度：

```
O(n)
```

因为每个字符最多：

```
入栈一次
出栈一次
```

空间复杂度：

```
O(n)
```

最坏情况：

```
(((((((((
```

所有字符都进入栈。
