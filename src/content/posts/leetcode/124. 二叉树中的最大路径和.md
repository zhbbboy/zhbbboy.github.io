这道题属于二叉树递归中的难题，核心难点不是遍历，而是区分两件事：
> 当前节点能够向父节点提供多少“单边贡献”？  
> 以当前节点为最高点的完整路径，最大能有多大？

本题最推荐：
> **递归 DFS + 后序遍历 + 全局最大值。**

迭代虽然可以用栈模拟后序遍历，但还要额外保存每个节点的贡献值，代码更复杂且没有性能优势，因此不推荐作为主方法。

---
## ① 破题：题目真正要求什么
题目要求在二叉树中寻找一条路径，使路径上所有节点值之和最大。

路径需要满足：
- 至少包含一个节点；
- 相邻节点之间必须有边；
- 同一个节点不能重复经过；
- 可以从任意节点开始；
- 可以在任意节点结束；
- 不一定经过根节点。

例如：

```
       -10
       /  \
      9    20
          /  \
         15   7
```
最大路径是：
```
15 → 20 → 7
```
路径和：
```
15 + 20 + 7 = 42
```
注意，它没有经过整棵树的根节点 `-10`。

---
## ② 核心技巧

### 先思考：以某个节点为最高点，路径有几种形态？

假设当前节点是 `node`：
```
          node
          /  \
      left   right
```

经过当前节点的路径可能是：

```
只有 node
left → node
node → right
left → node → right
```
因此，以当前节点为“拐点”的完整路径最大值可以是：
```
node->val + 左子树贡献 + 右子树贡献
```
但是，递归向父节点返回时不能把左右两边都返回。

### 为什么？
假设当前节点还要连接父节点：

```
              parent
                |
               node
              /    \
          left     right
```
如果 `node` 同时把左边和右边都带给父节点，那么路径会变成三个方向：
```
left → node → right
         |
       parent
```
这已经不是一条链，而是出现了分叉。
所以当前节点向父节点只能返回：
```
node + 左边
```
或者：
```
node + 右边
```
选择更大的那一边。
这就是本题最重要的两个值：
```
完整路径：
leftGain + node->val + rightGain

向上返回：
node->val + max(leftGain, rightGain)
```
## 解题思路
1. 递归三要素-maxGain函数的含义：从当前节点出发，向下选择一个有最大贡献的分支，也就是走一条路然后值最大，然后将其返回
2. 递归三要素-终止条件：如果node为空则返回0
3. 递归三要素-当层做什么：首先获取左孩子树最大贡献分支，在获取右孩子树最大贡献分支，然后再将当前节点值+左孩子最大贡献分支值+右孩子最大贡献分支值，然后再将其与全局变量，也就是我们要获得的最终答案进行比较，谁大就取谁值。然后再将自己的最大分支值返回给父亲节点那一层。
4. 其中要最注意的一个点就是`int leftGain = max(0,maxGain(node->left));`和`int rightGain = max(0,maxGain(node->right));`因为如果自己孩子提供的最大贡献分支值是一个负值，那我们宁愿不用，也就是将自己的子树最大贡献分支值赋值为0
## ④ 完整代码
```cpp
class Solution {
private:
    int answer = INT_MIN;

    // 返回：从当前节点出发，向下选择一条分支时的最大贡献
    int maxGain(TreeNode* node) {
        if (node == nullptr) {
            return 0;
        }

        // 负贡献不要，宁可不选择该子树
        int leftGain = max(0, maxGain(node->left));
        int rightGain = max(0, maxGain(node->right));

        // 以当前节点作为最高点，组成一条完整路径
        int currentPath =
            node->val + leftGain + rightGain;

        // 更新整棵树中的最大路径和
        answer = max(answer, currentPath);

        // 返回给父节点时只能选择左、右中的一条
        return node->val + max(leftGain, rightGain);
    }

public:
    int maxPathSum(TreeNode* root) {
        maxGain(root);
        return answer;
    }
};
```

## ⑤ 关键设计解释

### 1. `maxGain()` 的返回值到底是什么？
```cpp
int maxGain(TreeNode* node)
```
它不是返回当前子树内部的最大路径和。

它返回的是：
> 从当前节点出发，向下只能选择一条分支时，能够提供给父节点的最大路径和。

例如：
```
      20
     /  \
    15   7
```
节点 `20` 内部的完整最大路径是：
```
15 → 20 → 7 = 42
```
但它向父节点返回的是：
```
20 + 15 = 35
```
因为只能选择一条分支。

---
### 2. 为什么完整路径可以同时使用左右两边？
```cpp
int currentPath =
    node->val + leftGain + rightGain;
```
因为这条路径到当前节点为止已经完整结束了：
```
左侧节点 → 当前节点 → 右侧节点
```
它没有继续连接父节点，所以不存在分叉。
当前节点相当于这条路径的最高点或拐点。

---
### 3. 为什么向父节点只能返回一边？
```
return node->val + max(leftGain, rightGain);
```
向父节点延伸时，路径已经包含：
```
父节点 → 当前节点
```
当前节点下面最多只能继续选择一条边：
```
父节点 → 当前节点 → 左子树
```
或者：
```
父节点 → 当前节点 → 右子树
```
不能两边都选，否则会变成树杈，不再是一条路径。

---
### 4. 为什么要写 `max(0, 子树贡献)`？
```
int leftGain = max(0, maxGain(node->left));
```
如果某棵子树的最大贡献是负数，例如：
```
当前节点 10
左子树贡献 -5
```
带上左子树反而会变小：
```
10 + (-5) = 5
```
还不如不要左子树：
```
10
```
所以负贡献直接当作 `0`：
```
负贡献 = 不选择该分支
```
注意，这并不是说树中负节点都不能使用。
假如当前节点本身是负数，我们仍然必须计算它，因为题目要求路径至少包含一个节点。

---
### 5. 为什么 `answer` 不能初始化为 0？

不能写：
```
int answer = 0;
```
因为整棵树可能全是负数，例如：
```
   -3
```
正确答案应该是：
```
-3
```
如果初始化为 `0`，最终会错误返回 `0`，但树中根本不存在值为 `0` 的路径。
所以必须初始化为：
```
int answer = INT_MIN;
```

---
### 6. 为什么需要全局答案？
递归函数返回的只是“向父节点提供的单边贡献”。
但真正的最大路径可能在某个子树内部已经完成，例如：
```
15 → 20 → 7
```
它不会完整地返回到根节点。
因此每个节点都要计算：
```
node->val + leftGain + rightGain
```
并更新全局最大值：
```
answer = max(answer, currentPath);
```

---

## ⑥ 递归三要素

### 1. 递归函数定义
```
maxGain(node)
```
表示：
> 从当前节点 `node` 出发，向下只能选择一条分支时，能够向父节点提供的最大路径和。

这个定义一定要记准确。
不是：
```
当前子树的最大路径和
```
而是：
```
当前节点能够向父节点提供的最大单边贡献
```

---
### 2. 递归终止条件
```
if (node == nullptr) {
    return 0;
}
```
空节点不能提供任何路径贡献，所以返回 `0`。

---
### 3. 当前层做什么
当前节点执行四件事：
```
1. 获得左子树的最大单边贡献。
2. 获得右子树的最大单边贡献。
3. 用左贡献 + 当前值 + 右贡献更新完整路径答案。
4. 选择左右较大的一边返回给父节点。
```
对应代码：
```cpp
int leftGain = max(0, maxGain(node->left));
int rightGain = max(0, maxGain(node->right));

answer = max(
    answer,
    node->val + leftGain + rightGain
);

return node->val + max(leftGain, rightGain);
```
这是典型的后序递归：
```
先获得左右子树结果
再处理当前节点
```

---
## ⑦ 为什么不推荐迭代写法？

迭代可以使用栈模拟后序遍历，但还需要一个哈希表保存：
```
每个节点计算出来的最大单边贡献
```
大致需要：
```
stack<pair<TreeNode*, bool>> st;
unordered_map<TreeNode*, int> gain;
```
还要区分：
```
第一次进入节点
第二次离开节点
```
这样才能保证左右孩子先计算完成。
它并没有降低时间复杂度或空间复杂度，却使代码更复杂。所以本题递归明显更自然，不需要强行学习迭代版本。

## ⑧ 面试追问

### Q1：为什么这题使用后序遍历？

因为当前节点的计算依赖：
```
左子树贡献
右子树贡献
```
必须先获得左右子树结果，再处理当前节点，所以是：
```
左 → 右 → 根
```
即后序遍历思想。

---
### Q2：路径可以只包含一个节点吗？
可以。
题目要求路径至少包含一个节点。
例如：
```
   -3
```
最大路径就是节点 `-3` 本身。

---
### Q3：最大路径必须经过根节点吗？
不需要。
例如示例二的最大路径是：
```
15 → 20 → 7
```
没有经过根节点 `-10`。

---
### Q4：为什么返回值和更新答案的公式不同？
因为两者解决的问题不同：
```
更新全局答案：
允许左 → 当前 → 右
这是一条已经完整结束的路径。

向父节点返回：
只能选择左或右一边
否则连接父节点后会产生分叉。
```
这是本题最常见的面试追问。

---
### Q5：时间复杂度是多少？

每个节点只访问一次：
```
时间复杂度：O(n)
```
递归栈深度等于树高 `h`：
```
空间复杂度：O(h)
```
平衡树中：
```
O(log n)
```
退化成链表时：
```
O(n)
```

---

### 面试表达
> 我使用后序递归。递归函数返回当前节点能够向父节点提供的最大单边路径贡献。对于每个节点，先递归计算左右子树贡献，如果某一边贡献为负就按 0 处理，因为负贡献不如不选。然后使用“当前节点值加左右两边贡献”更新全局最大路径和。但向父节点返回时，只能选择左右贡献中更大的一边，否则路径会产生分叉。每个节点只访问一次，所以时间复杂度为 `O(n)`，递归空间复杂度为 `O(h)`。

```

题型：
二叉树 DFS + 后序递归 + 树形动态规划。

路径特点：
1. 可以从任意节点开始。
2. 可以在任意节点结束。
3. 不一定经过根节点。
4. 同一个节点最多出现一次。
5. 路径必须是一条链，不能分叉。

递归函数：
maxGain(node)

当前节点向父节点能够提供的最大单边贡献。

左右贡献：
leftGain = max(0, maxGain(node->left))
rightGain = max(0, maxGain(node->right))

完整路径：
node->val + leftGain + rightGain

向上返回：
node->val + max(leftGain, rightGain)

全局答案：

因为所有节点可能都是负数。
```

> **当前节点计算答案时可以左右都要；向父节点返回时只能选择一边。**
