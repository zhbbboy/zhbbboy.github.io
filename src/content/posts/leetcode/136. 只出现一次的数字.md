这题看起来可以用 `unordered_map` 统计次数，但题目专门要求：

> **时间复杂度 O(n)，并且只使用常量级额外空间 O(1)。**

所以这题真正想考的是：

> **位运算 XOR（异或）**

核心代码最后甚至只有几行：

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ans = 0;

        for (int num : nums) {
            ans ^= num;
        }

        return ans;
    }
};
```

但这里最重要的不是背代码，而是理解：

> **为什么所有出现两次的数字都会消失，只剩那个出现一次的数字。**

---

## ① 破题：题目真正要求什么

例如：

```
nums = [4,1,2,1,2]
```

其中：

```
4 → 出现1次
1 → 出现2次
2 → 出现2次
```

所以答案：

```
4
```

最容易想到：

```
unordered_map<int, int> mp;
```

统计：

```
4 -> 1
1 -> 2
2 -> 2
```

然后找次数为 1 的。

这样当然可以。

时间：

```
O(n)
```

但额外空间：

```
O(n)
```

不符合题目要求的：

```
常量额外空间 O(1)
```

因此我们需要一个不保存所有数字的方法。

---

# ② 核心技巧：异或 `^`

C++ 中：

```
a ^ b
```

表示：

> 对 `a` 和 `b` 的二进制位逐位进行异或。

异或最简单的规则：

```
相同 → 0
不同 → 1
```

也就是：

```
0 ^ 0 = 0
1 ^ 1 = 0

0 ^ 1 = 1
1 ^ 0 = 1
```

例如：

```
5 = 101
3 = 011
```

那么：

```
  101
^ 011
-----
  110
```

所以：

```
5 ^ 3 == 6
```

不过这题真正重要的不是具体二进制怎么算，而是异或有几个非常关键的性质。

---

# ③ 这题最重要的三个 XOR 性质

### 性质 1：一个数和自己异或，结果是 0

```
x ^ x = 0
```

例如：

```
5 ^ 5 = 0
```

为什么？

假设：

```
5 = 101
```

那么：

```
  101
^ 101
-----
  000
```

所以：

```
5 ^ 5 = 0
```

这正好能消掉：

> **出现两次的数字。**

---

### 性质 2：任何数和 0 异或，还是自己

```
x ^ 0 = x
```

例如：

```
5 ^ 0 = 5
```

二进制：

```
  101
^ 000
-----
  101
```

---

### 性质 3：异或满足交换律和结合律

也就是：

```
a ^ b == b ^ a
```

以及：

```
(a ^ b) ^ c == a ^ (b ^ c)
```

这特别重要。

因为数组可能是：

```
[4,1,2,1,2]
```

相同数字根本不挨着。

但是因为可以随便调整异或顺序：

```
4 ^ 1 ^ 2 ^ 1 ^ 2
```

可以理解成：

```
4 ^ 1 ^ 1 ^ 2 ^ 2
```

然后：

```
1 ^ 1 = 0
2 ^ 2 = 0
```

于是：

```
4 ^ 0 ^ 0
= 4
```

最终只剩：

```
4
```

---

# ④ 图解执行过程

我们完整跑：

```
nums = [4,1,2,1,2]
```

初始化：

```
int ans = 0;
```

所以：

```
ans = 0
```

---

### 读到 4

```
ans = ans ^ 4;
```

也就是：

```
ans = 0 ^ 4
    = 4
```

现在：

```
ans = 4
```

---

### 读到 1

```
ans = 4 ^ 1
```

暂时不用关心具体是多少。

可以记成：

```
ans = 4 ^ 1
```

---

### 读到 2

变成：

```
ans = 4 ^ 1 ^ 2
```

---

### 又读到 1

变成：

```
ans = 4 ^ 1 ^ 2 ^ 1
```

因为异或满足交换律：

```
= 4 ^ 1 ^ 1 ^ 2
```

而：

```
1 ^ 1 = 0
```

所以：

```
= 4 ^ 0 ^ 2
= 4 ^ 2
```

两个 `1` 被消掉了。

---

### 又读到 2

```
ans = 4 ^ 2 ^ 2
```

因为：

```
2 ^ 2 = 0
```

所以：

```
ans = 4 ^ 0
    = 4
```

最终：

```
return 4;
```

---

# ⑤ 为什么初始化 `ans = 0`？

因为我们需要一个初始值开始异或：

```
int ans = 0;
```

而：

```
0 ^ x = x
```

所以第一个数字不会被影响。

例如：

```
nums = [2,2,1]
```

过程：

```
ans = 0

0 ^ 2
= 2

2 ^ 2
= 0

0 ^ 1
= 1
```

最后：

```
1
```

正好是只出现一次的数字。

---

# ⑥ 完整代码

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ans = 0;

        for (int num : nums) {
            ans = ans ^ num;
        }

        return ans;
    }
};
```

还可以简写：

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ans = 0;

        for (int num : nums) {
            ans ^= num;
        }

        return ans;
    }
};
```

这里：

```
ans ^= num;
```

等价于：

```
ans = ans ^ num;
```

和你之前见过的：

```
a += b;
```

等价于：

```
a = a + b;
```

是一个意思。

---

# ⑦ 为什么这个方法一定正确？

假设数组：

```
[a, b, c, b, c]
```

其中：

```
a
```

只出现一次。

所有数字异或：

```
a ^ b ^ c ^ b ^ c
```

由于异或可以交换顺序：

```
a ^ b ^ b ^ c ^ c
```

然后：

```
b ^ b = 0

c ^ c = 0
```

所以：

```
a ^ 0 ^ 0
= a
```

因此：

> **所有成对出现的数字都会互相抵消，最后留下的就是唯一只出现一次的数字。**

这就是整个算法的证明。

---

# ⑧ 为什么不能用加减法？

你可能会想：

> 出现两次的数字，能不能加起来再减？

比如：

```
[4,1,2,1,2]
```

你必须先知道：

```
哪些数字重复
```

那还是需要 `set` 或 `map`。

而异或有个非常漂亮的特点：

> 不需要知道谁和谁是一对。

直接：

```
全部异或
```

相同数字自己就会抵消。

---

# ⑨ `unordered_map` 版本为什么不是最优答案？

可以这样写：

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        unordered_map<int, int> mp;

        for (int num : nums) {
            mp[num]++;
        }

        for (auto& p : mp) {
            if (p.second == 1) {
                return p.first;
            }
        }

        return -1;
    }
};
```

时间：

```
O(n)
```

但是空间：

```
O(n)
```

而异或：

```
int ans = 0;
```

只用了一个变量。

所以：

```
时间 O(n)
空间 O(1)
```

完全符合题意。

---

# ⑩ 递归适合吗？

不适合。

这题没有树、搜索、选择路径之类的结构。

直接：

```
从左到右遍历
+
异或
```

就是最自然的方法。

---

# ⑪ 面试很可能追问：为什么异或可以消掉重复元素？

你可以直接回答：

> 因为异或满足 `x ^ x = 0`、`x ^ 0 = x`，同时满足交换律和结合律。因此数组中每个出现两次的元素都可以配对抵消成 0，最终只剩下那个出现一次的元素。

这句话基本就是这道题的标准面试表达。

---

# ⑫ 一个需要特别区分的问题

这道题成立是因为题目明确说：

> 除一个元素出现一次外，其他元素**恰好出现两次**。

如果题目变成：

```
其他元素出现3次
只有一个出现1次
```

那么简单 XOR 就不能用了。

因为：

```
x ^ x ^ x
```

不是 0，而是：

```
x
```

那就是另一道位运算题了。

所以这里 XOR 能用的关键条件就是：

```
重复元素恰好出现2次
```

这题以后直接记：

异或满足：
交换律、结合律

a ^ b ^ c ^ b ^ c

可以整理为：

a ^ b ^ b ^ c ^ c

= a ^ 0 ^ 0
