这道题最适合使用：
> **递归 + 哈希表 + 下标区间**

递归是主方法，因为一棵树天然可以拆成：
```
根节点
左子树
右子树
```
而前序和中序数组也能按照同样方式被划分。迭代虽然可以实现，但需要手动维护栈和父子关系，逻辑明显更绕，不适合作为这题的首选方法，因此这里不展开迭代代码。

---
## ① 破题：题目真正要求什么

题目给出同一棵二叉树的两种遍历结果：

```
preorder  // 前序遍历
inorder   // 中序遍历
```

要求我们还原原来的二叉树，并返回根节点。

题目保证：

```
所有节点值互不相同
两个数组来自同一棵树
```

节点值互不相同非常重要，因为我们可以在中序数组中唯一确定根节点的位置。

---

### 前序遍历的顺序

```
根 → 左子树 → 右子树
```

所以：

> 前序数组的第一个元素一定是当前树的根节点。

---

### 中序遍历的顺序

```
左子树 → 根 → 右子树
```

所以：

> 在中序数组中找到根节点后，根节点左边属于左子树，右边属于右子树。

这两个性质组合起来，就可以递归还原整棵树。

---
## ② 核心技巧：前序找根，中序划分左右子树
示例：
```
preorder = [3, 9, 20, 15, 7]
inorder  = [9, 3, 15, 20, 7]
```

前序数组第一个元素是：

```
3
```

所以根节点是 `3`。

在中序数组中找到 `3`：

```
[9, 3, 15, 20, 7]
    ↑
   根节点
```

那么：

```
3 左边：[9]          是左子树
3 右边：[15,20,7]    是右子树
```

因此整棵树目前可以确定为：
```
        3
       / \
  [9]     [15,20,7]
```

然后再对左半部分和右半部分执行同样的过程。
这就是递归。
## 用下标区间表示递归

实际代码不会每次创建新的数组，因为复制数组会增加开销。
我们用四个下标表示当前处理范围：
```cpp
build(
    preorder,
    preLeft,
    preRight,
    inLeft,
    inRight
)
```

它表示：
> 使用 `preorder[preLeft...preRight]` 和  
> `inorder[inLeft...inRight]` 构造当前子树，并返回根节点。

---
### 当前根节点
前序遍历第一个元素是根：
```cpp
int rootValue = preorder[preLeft];
```

---
### 根节点在中序数组中的位置
```cpp
int rootIndex = index[rootValue];
```

---
### 左子树节点数量
根节点左边都是左子树：
```cpp
int leftSize = rootIndex - inLeft;
```
假设：
```
inorder = [9, 3, 15, 20, 7]
范围       0              4
rootIndex = 1
inLeft = 0
```
那么：
```cpp
leftSize = 1 - 0 = 1
```
左子树有一个节点。

---
### 左子树区间
中序数组：
```cpp
[inLeft, rootIndex - 1]
```
前序数组中，根节点后面的 `leftSize` 个元素属于左子树：
```cpp
[preLeft + 1, preLeft + leftSize]
```

---
### 右子树区间
中序数组：
```cpp
[rootIndex + 1, inRight]
```
前序数组：
```cpp
[preLeft + leftSize + 1, preRight]
```

---
## ④ 完整代码：递归区间写法
```cpp
class Solution {
private:
    // 记录每个节点值在 inorder 中的下标
    unordered_map<int, int> inorderIndex;

    TreeNode* build(
        vector<int>& preorder,
        int preLeft,
        int preRight,
        int inLeft,
        int inRight
    ) {
        // 当前区间没有节点
        if (preLeft > preRight || inLeft > inRight) {
            return nullptr;
        }

        // 前序遍历第一个节点是当前子树的根
        int rootValue = preorder[preLeft];
        TreeNode* root = new TreeNode(rootValue);

        // 找到根节点在中序数组中的位置
        int rootIndex = inorderIndex[rootValue];

        // 根节点左侧的元素数量，就是左子树节点数
        int leftSize = rootIndex - inLeft;

        // 构造左子树
        root->left = build(
            preorder,
            preLeft + 1,
            preLeft + leftSize,
            inLeft,
            rootIndex - 1
        );

        // 构造右子树
        root->right = build(
            preorder,
            preLeft + leftSize + 1,
            preRight,
            rootIndex + 1,
            inRight
        );

        return root;
    }

public:
    TreeNode* buildTree(
        vector<int>& preorder,
        vector<int>& inorder
    ) {
        // 建立：节点值 -> 中序下标
        for (int i = 0; i < inorder.size(); ++i) {
            inorderIndex[inorder[i]] = i;
        }

        int n = preorder.size();

        return build(
            preorder,
            0,
            n - 1,
            0,
            n - 1
        );
    }
};
```

---
## ⑤ 关键设计解释

### 1. 为什么根节点是 `preorder[preLeft]`？
因为当前递归处理的是：
```
preorder[preLeft...preRight]
```
前序遍历顺序是：
```
根 → 左 → 右
```
所以当前区间第一个元素：
```
preorder[preLeft]
```
一定是当前子树的根。

注意，不是永远使用：
```
preorder[0]
```
只有构造整棵树时根节点才是 `preorder[0]`。递归到子树后，要使用当前区间的第一个元素 `preorder[preLeft]`。

---
### 2. 为什么需要哈希表？
每次拿到根节点值后，都要在中序数组中找到它的位置。
假如每次都线性查找：
```
for (int i = inLeft; i <= inRight; ++i)
```
每层递归都可能扫描一段数组，最坏时间复杂度会达到：
```
O(n²)
```
因此先建立哈希表：
```
unordered_map<int, int> inorderIndex;
```
含义是：
```
inorderIndex[节点值] = 该节点在中序数组中的下标
```
例如：
```
inorder = [9,3,15,20,7]
```
哈希表保存：
```
9  -> 0
3  -> 1
15 -> 2
20 -> 3
7  -> 4
```
之后查找根节点下标只需要平均：
```
O(1)
```

---
### 3. 为什么只需要用中序数组计算左子树长度？
中序数组能够明确区分：
```
左子树 | 根 | 右子树
```
所以：
```
int leftSize = rootIndex - inLeft;
```
得到左子树有多少个节点。

前序数组虽然排列为：
```
根 | 左子树 | 右子树
```
但仅看前序数组，并不知道左子树在哪里结束。
有了 `leftSize`，才能准确切分前序区间。

---
### 4. 左子树前序区间为什么是这个？
```
preLeft + 1
```
跳过当前根节点。
左子树有 `leftSize` 个节点，所以终点是：
```
preLeft + leftSize
```
因此：
```
左子树前序区间：

[preLeft + 1, preLeft + leftSize]
```
例如：
```
preorder = [3, 9, 20, 15, 7]
            0  1   2   3   4

preLeft = 0
leftSize = 1
```
左子树区间：
```
[0 + 1, 0 + 1] = [1,1]
```
也就是：
```
[9]
```

---
### 5. 右子树为什么从这里开始？

左子树结束位置是：
```
preLeft + leftSize
```
所以下一个位置：
```
preLeft + leftSize + 1
```
就是右子树开始位置。
例如：
```
根节点下标：0
左子树范围：1...1
右子树从：2 开始
```
对应：
```
[20,15,7]
```

---
### 6. 为什么题目必须保证没有重复元素？

如果中序数组存在重复值：
```
[2, 1, 2]
```
拿到根节点值 `2` 时，无法确定它对应左边的 `2`，还是右边的 `2`。
哈希表也无法唯一保存位置。
因此，前序和中序遍历要唯一确定一棵树，通常需要节点值互不相同。

---
## ⑥ 递归三要素

这题非常适合使用递归。
### 1. 递归函数的定义

```
build(preorder, preLeft, preRight, inLeft, inRight)
```
表示：
> 根据当前前序区间和中序区间构造一棵二叉树，并返回它的根节点。

---
### 2. 递归终止条件

```
if (preLeft > preRight || inLeft > inRight) {
    return nullptr;
}
```
表示当前区间里已经没有节点。
例如构造叶子节点 `9` 时，它的左子树区间可能变成：
```
preLeft = 2
preRight = 1
```
左边界超过右边界，说明没有左子树，返回 `nullptr`。

---
### 3. 当前层做什么
当前递归层只处理四件事：
```
1. preorder 当前区间第一个值作为根节点
2. 在 inorder 中找到根的位置
3. 递归构造左子树
4. 递归构造右子树
```
代码对应：
```cpp
int rootValue = preorder[preLeft];
TreeNode* root = new TreeNode(rootValue);

int rootIndex = inorderIndex[rootValue];
int leftSize = rootIndex - inLeft;

root->left = build(...);
root->right = build(...);

return root;
```
可以把它记成：
> 当前层负责创建根节点，左右子树交给递归。

---
## ⑦ 为什么本题不推荐迭代作为主方法？
迭代也能构造，但需要：
```
栈
前序指针
中序指针
判断当前节点何时结束左子树
判断何时回退并连接右子树
```
它利用的是：
- 前序遍历决定节点创建顺序；
- 中序遍历决定何时完成左子树并回退。
这种写法状态较多，代码可读性不如递归，而且没有改善时间复杂度。

本题的结构本身就是：
```
构造根
递归构造左子树
递归构造右子树
```
所以递归最符合问题结构，也是面试中最推荐的解法。

## ⑧ 面试追问

### Q1：为什么仅有前序遍历不能唯一构造二叉树？
例如前序遍历：
```
[1,2]
```
可能对应：
```
  1
 /
2
```
也可能对应：
```
1
 \
  2
```
前序结果都是：
```
1,2
```

因此只靠前序遍历无法区分左右子树。
中序遍历提供了左右子树的分界。

---

### Q2：为什么前序加中序可以构造？
因为：
```
前序遍历第一个元素确定根节点
中序遍历中根的位置确定左右子树
```
划分左右子树之后，对左右部分重复同样过程即可。

---

### Q3：后序加中序能否构造？

可以。
后序遍历顺序是：
```
左 → 右 → 根
```
因此后序数组最后一个元素是根节点。
之后仍然通过中序数组划分左右子树。

---
### Q4：前序加后序可以唯一构造吗？

一般不能。
因为缺少中序遍历提供的左右子树边界。
在某些特殊条件下，例如树是满二叉树，才有可能唯一确定。

---
### Q5：复杂度是多少？

建立哈希表需要：
```
O(n)
```
每个节点只创建一次，每次查询中序位置平均是 `O(1)`：
```
总时间复杂度：O(n)
```
哈希表需要：
```
O(n)
```
递归调用栈需要：
```
O(h)
```
其中 `h` 是树高。
所以额外空间整体为：
```
O(n)
```

---
### Q6：为什么不直接切割 vector？
例如写成：
```
vector<int> leftPreorder(...);
vector<int> rightPreorder(...);
```
每次递归都复制新数组，会产生额外时间和空间开销。
树退化时，累计复制量可能接近：
```
O(n²)
```
所以更推荐只传递下标区间，不复制数组。

---
### 面试表达

> 前序遍历的第一个元素是当前子树根节点，而中序遍历中根节点左边属于左子树、右边属于右子树。因此我先用哈希表记录每个节点在中序数组中的下标。递归过程中，用前序区间的第一个元素创建根节点，在中序数组中找到根的位置，并计算左子树节点数量，据此切分前序和中序区间，再递归构造左右子树。每个节点只处理一次，所以时间复杂度为 `O(n)`，额外空间复杂度为 `O(n)`。

## ⑨ 复习总结

```
105. 从前序与中序遍历序列构造二叉树

题型：
二叉树构造 + 递归 + 区间划分。

核心性质：
前序：根 → 左 → 右
中序：左 → 根 → 右

解题过程：
1. 前序区间第一个元素是当前根节点。
2. 在中序数组中找到根节点的位置。
3. 中序根节点左边是左子树，右边是右子树。
4. 计算左子树节点数 leftSize。
5. 根据 leftSize 划分前序区间。
6. 递归构造左子树和右子树。
7. 返回当前根节点。

关键区间：
左子树前序：
[preLeft + 1, preLeft + leftSize]

右子树前序：
[preLeft + leftSize + 1, preRight]

左子树中序：
[inLeft, rootIndex - 1]

右子树中序：
[rootIndex + 1, inRight]
```

一句话记忆：
> **前序第一个找根，中序根位置分左右，左子树长度负责同步切分前序数组。**
