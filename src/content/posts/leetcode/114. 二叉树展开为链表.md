这题推荐的主方法是：
> **原地迭代修改指针，额外空间 `O(1)`。**

原因是题目本身要求在原二叉树上修改，而且进阶明确询问能否使用 `O(1)` 额外空间。递归虽然能做，但需要递归调用栈，并且常见的“反向先序遍历”写法比较绕，所以不作为这题的主学习方法。

---
## ① 破题：题目真正要求什么
给你一棵二叉树：
```
        1
       / \
      2   5
     / \   \
    3   4   6
```
要求把它修改成：
```
1
 \
  2
   \
    3
     \
      4
       \
        5
         \
          6
```
最终必须满足：
```
1. 所有节点的 left 都是 nullptr
2. 所有节点通过 right 串成一条链
3. 链表顺序与二叉树先序遍历相同
```
原树的先序遍历是：
```
根 → 左 → 右

1, 2, 3, 4, 5, 6
```
所以展开后的链表也必须是：
```
1 → 2 → 3 → 4 → 5 → 6
```
注意：题目不是让我们创建新链表，而是要修改原来的节点指针。
## 解题思路
1. 我吗需要将每一个cur节点的左孩子得移到左边去，所以得用上while循环，循环条件也是当前的cur不能为空
2. 首先得将cur指向root节点，然后开始进入循环，如果cur有左孩子，那么的将他的左孩子移到cur的右孩子节点上，那右孩子节点呢，因为得是跟先序遍历的顺序相同，所以要将cur左子树做后被遍历到的节点也就是在cur左子树最右边的节点接上cur节点右孩子，然后再将cur左子树移到cur的右子指针上，然后将cur的左子指针设为nullptr，然后再向下继续迭代，最后能将所有的节点全部移到右子指针上并且还与二叉树 先序遍历 顺序相同
## ② 核心技巧：把左子树插入当前节点和右子树之间

对于任意一个当前节点 `cur`，先序遍历顺序应该是：

```
当前节点 → 左子树 → 右子树
```

假设当前结构是：

```
       cur
       / \
   左子树  右子树
```

而最终只能使用 `right` 指针，所以我们希望改造成：

```
cur → 左子树 → 右子树
```

问题是：

> 把左子树移动到右边之后，原来的右子树接在哪里？

答案是：

> 接到左子树中沿着 `right` 指针能找到的最右节点后面。

整体操作：

```
1. 找到左子树的最右节点 predecessor
2. predecessor->right 指向原来的右子树
3. 当前节点的 right 指向原来的左子树
4. 当前节点的 left 设置为 nullptr
```

代码结构就是：

```cpp
predecessor->right = cur->right;
cur->right = cur->left;
cur->left = nullptr;
```
## ④ 完整代码：推荐的原地迭代写法

```cpp
class Solution {
public:
    void flatten(TreeNode* root) {
        TreeNode* cur = root;

        while (cur != nullptr) {
            // 只有存在左子树时，才需要重新连接
            if (cur->left != nullptr) {
                // 找到当前左子树中沿 right 方向的最右节点
                TreeNode* predecessor = cur->left;

                while (predecessor->right != nullptr) {
                    predecessor = predecessor->right;
                }

                // 将原来的右子树接到左子树后面
                predecessor->right = cur->right;

                // 将左子树整体移动到右边
                cur->right = cur->left;
                cur->left = nullptr;
            }

            // 继续处理链表中的下一个节点
            cur = cur->right;
        }
    }
};
```

## ⑤ 关键设计解释

### 1. 为什么要找左子树的最右节点？

先序遍历顺序是：

```
当前节点 → 整棵左子树 → 整棵右子树
```

我们把左子树移动到 `cur->right` 后，原来的右子树必须接在左子树处理完成之后。

所以需要找到一个连接位置，把原右子树暂时接上：

```
predecessor->right = cur->right;
```

这个 `predecessor` 就是当前左子树中沿 `right` 指针能够到达的最右节点。

---

### 2. 为什么连接顺序不能反？

必须先保存原来的右子树：

```
predecessor->right = cur->right;
```

再执行：

```
cur->right = cur->left;
```

假如先修改：

```
cur->right = cur->left;
```

那么原来的右子树入口就丢失了。

例如节点 `1` 原来的右子树是 `5`，如果不先保存，就再也找不到节点 `5、6`。

---

### 4. 为什么最后执行 `cur = cur->right`？

每处理完当前节点后，它的右指针已经指向先序遍历中的下一个节点。

所以：

```
cur = cur->right;
```

就是按照展开后的链表顺序继续处理：

```
1 → 2 → 3 → 4 → 5 → 6
```

---

### 5. 会不会出现环？

不会。

我们把原来的右子树接到左子树后面，然后把左子树移动到右边：

```
cur
  \
   原左子树 → 原右子树
```

同时断开：

```
cur->left = nullptr;
```

没有任何指针重新指向当前节点或祖先节点，因此不会形成环。

---

## ⑥ 为什么这题不把递归作为主方法？

递归当然可以做，常见思路是按照：

```
右子树 → 左子树 → 当前节点
```

的顺序反向处理，并使用一个 `prev` 记录已经展开好的链表头。

代码很短：

```cpp
class Solution {
private:
    TreeNode* prev = nullptr;

public:
    void flatten(TreeNode* root) {
        if (root == nullptr) {
            return;
        }

        flatten(root->right);
        flatten(root->left);

        root->right = prev;
        root->left = nullptr;
        prev = root;
    }
};
```

但它的思考顺序是：

```
右 → 左 → 根
```

和题目要求的先序顺序：

```
根 → 左 → 右
```

刚好相反。

原因是它从链表尾部向前构造：

```
先处理 6
再让 5 指向 6
再让 4 指向 5
……
最后让 1 指向 2
```

这对初学者比较绕，而且递归调用栈需要 `O(h)` 空间。因此本题优先掌握原地迭代方法。

如果面试官只要求普通解法，递归也完全正确；如果追问 `O(1)` 额外空间，则使用前面的原地迭代写法。

## ⑦ 基础栈写法：更接近普通先序遍历

还有一种更容易由先序遍历想到的方法：使用栈进行先序遍历，然后把上一个节点连接到当前节点。

```cpp
class Solution {
public:
    void flatten(TreeNode* root) {
        if (root == nullptr) {
            return;
        }

        stack<TreeNode*> st;
        st.push(root);

        TreeNode* prev = nullptr;

        while (!st.empty()) {
            TreeNode* node = st.top();
            st.pop();

            if (prev != nullptr) {
                prev->left = nullptr;
                prev->right = node;
            }

            // 先压右，再压左，保证左子树先被处理
            if (node->right != nullptr) {
                st.push(node->right);
            }

            if (node->left != nullptr) {
                st.push(node->left);
            }

            prev = node;
        }

        // 最后一个节点彻底断开孩子
        prev->left = nullptr;
        prev->right = nullptr;
    }
};
```

它的思路很直接：

```
按照先序顺序访问节点：
1, 2, 3, 4, 5, 6

每访问一个节点：
让前一个节点的 right 指向它。
```

但是栈最坏需要 `O(n)` 额外空间，所以不如原地方法。

推荐顺序是：

```
先理解栈方法如何按照先序遍历连接节点；
重点掌握 O(1) 原地指针重排方法。
```

## ⑧ 面试追问

### Q1：为什么先序遍历要先压右孩子，再压左孩子？

栈是后进先出。

我们希望访问顺序是：

```
根 → 左 → 右
```

所以要：

```
st.push(node->right);
st.push(node->left);
```

左孩子后入栈，却会先出栈。

---

### Q2：原地方法的时间复杂度是多少？

时间复杂度：

```
O(n)
```

每个节点都会被处理，寻找前驱节点时，每条相关指针不会被无限重复扫描。

空间复杂度：

```
O(1)
```

只使用了：

```
cur
predecessor
```

两个指针，没有使用栈、队列或新节点。

---

### Q3：能不能先把先序遍历结果保存到数组，再重新连接？

可以：

```
1. 先序遍历得到所有节点
2. 按数组顺序修改 right
3. 所有 left 置空
```

但是需要：

```
O(n)
```

额外空间，不符合进阶的 `O(1)` 要求。

---

### Q4：原地展开后还是二叉树吗？

从节点类型上看仍然使用 `TreeNode`，但结构已经退化成只使用右指针的单链表：

```
left 全部为空
right 指向下一个节点
```

---

### 面试表达

> 先序遍历的顺序是根、左子树、右子树。对于当前节点，如果它存在左子树，我找到左子树中沿右指针到达的最右节点，将当前节点原来的右子树接到该节点后面；然后把左子树移动到当前节点的右边，并将左指针置空。之后继续处理当前节点的右孩子。这样可以在原树上完成指针重排，时间复杂度为 `O(n)`，额外空间复杂度为 `O(1)`。

## ⑨ 复习总结

```
114. 二叉树展开为链表

题型：
二叉树指针重排 + 先序遍历。

题目要求：
1. 使用原来的 TreeNode。
2. right 指向链表下一个节点。
3. left 全部为 nullptr。
4. 节点顺序与先序遍历相同。

推荐方法：
O(1) 原地迭代。

处理当前节点 cur：
1. 如果 cur 没有左子树，直接 cur = cur->right。
2. 如果 cur 有左子树：
   - 找到左子树中沿 right 方向的最右节点 predecessor；
   - predecessor->right = cur->right；
   - cur->right = cur->left；
   - cur->left = nullptr。
3. 继续处理 cur->right。

复杂度：
时间 O(n)
额外空间 O(1)
```

一句话记忆：

> **把左子树搬到右边，把原右子树接到左子树后面，然后继续沿右指针处理。**
