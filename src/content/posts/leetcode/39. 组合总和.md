# 解题思路

这道题最适合使用：
> **回溯 + `startIndex` + 剩余目标值 `remain`**

它和你刚学的 **78. 子集** 很像，但有一个非常关键的区别：
> **子集：一个元素只能选一次，所以递归传 `i + 1`。**  
> **组合总和：同一个元素可以无限重复选择，所以递归传 `i`。**

这正是这道题最值得掌握的地方。

---

# ① 破题：题目真正要求什么
例如：
```cpp
candidates = [2,3,6,7]
target = 7
```
你需要寻找所有和为 `7` 的组合。

可以得到：
```text
[2,2,3]
[7]
```
注意：
```text
2 可以重复使用
```
所以：
```text
2 + 2 + 3 = 7
```
是合法的。

但是：
```text
[2,2,3]
[2,3,2]
[3,2,2]
```

虽然顺序不同，但本质是同一个组合，只能保留一次。

因此我们同时要解决两个问题：

```text
① 元素可以重复使用
② 不能产生排列顺序导致的重复答案
```

---

# ② 核心技巧

我们继续使用回溯：
```text
选择一个数字
→ 加入 path
→ 更新剩余目标值
→ 递归
→ 回溯
→ 尝试其他数字
```
例如：
```cpp
target = 7
```
选择 `2`：
```text
path = [2]
remain = 7 - 2 = 5
```
再选择 `2`：
```text
path = [2,2]
remain = 3
```
再选择 `3`：
```text
path = [2,2,3]
remain = 0
```
说明找到一个答案。

---

## 为什么使用 `remain`？

我们可以维护：
```cpp
int remain;
```
表示：
> 当前还差多少才能达到 `target`。

初始：
```text
remain = target = 7
```
每选择一个数字：
```cpp
remain -= candidates[i];
```
当：
```text
remain == 0
```
就找到了合法组合。
如果：
```text
remain < 0
```
说明已经超过目标，不需要继续往下搜索。

# ④ 完整代码

我推荐先排序，这样可以提前剪枝。
```cpp
class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;

    void backtrack(vector<int>& candidates,
                   int remain,
                   int startIndex) {
        // 找到一个合法组合
        if (remain == 0) {
            result.push_back(path);
            return;
        }

        for (int i = startIndex; i < candidates.size(); ++i) {
            // candidates 已经排序
            // 当前数字都已经大于 remain，
            // 后面的数字更大，不需要继续搜索
            if (candidates[i] > remain) {
                break;
            }

            // 1. 做选择
            path.push_back(candidates[i]);

            // 2. 递归
            // 注意这里传 i，不是 i + 1
            // 因为当前数字可以重复使用
            backtrack(
                candidates,
                remain - candidates[i],
                i
            );

            // 3. 回溯
            path.pop_back();
        }
    }

public:
    vector<vector<int>> combinationSum(
        vector<int>& candidates,
        int target
    ) {
        sort(candidates.begin(), candidates.end());

        backtrack(candidates, target, 0);

        return result;
    }
};
```

---

# ⑤ 关键设计解释

## 1. `path` 是什么？

```cpp
vector<int> path;
```

表示当前正在构造的组合。

例如：

```text
[]
[2]
[2,2]
[2,2,3]
```

当：

```text
remain == 0
```

当前 `path` 就是一个合法答案。

---

## 2. `startIndex` 为什么还需要？

你可能会想：

> 既然数字可以重复使用，为什么还要 `startIndex`？

因为虽然：

```text
同一个数字可以重复选
```

但是我们不能产生不同顺序的重复组合。

例如：

```text
[2,2,3]
[2,3,2]
[3,2,2]
```

题目认为它们是同一个组合。

所以我们规定：

> 组合中的元素只能按照 candidates 的下标从前往后选择，不能回头。

例如已经选择 `3`：

```text
[3]
```

之后只能继续考虑：

```text
3、6、7
```

不能重新选择前面的 `2`。

这样：

```text
[2,3]
```

会生成。

但：

```text
[3,2]
```

不会生成。

因此自然消除了顺序重复。

---

# ⑥ 最关键：为什么递归传 `i`，不是 `i + 1`？

这一点必须记牢。

上一题子集：

```cpp
backtrack(nums, i + 1);
```

因为一个数字使用之后不能再次使用。

但是本题明确说：

> candidates 中同一个数字可以无限重复选择。

假设：

```cpp
candidates = [2,3]
target = 7
```

我们第一次选择 `2`：

```text
path = [2]
```

下一层仍然必须允许再次选择 `2`，否则永远无法生成：

```text
[2,2,3]
```

所以递归：

```cpp
backtrack(candidates, remain - candidates[i], i);
```

注意：

```text
传 i：
当前数字还能继续选择。

传 i + 1：
当前数字以后不能再选。
```

这是这题和“子集”“组合”题最大的区别之一。

## 对比一下

### 78. 子集

```cpp
path.push_back(nums[i]);

backtrack(nums, i + 1);

path.pop_back();
```

因为：

```text
一个元素只能使用一次
```

---

### 39. 组合总和

```cpp
path.push_back(candidates[i]);

backtrack(candidates, remain - candidates[i], i);

path.pop_back();
```

因为：

```text
当前元素可以继续重复使用
```

这一个字符的区别：

```text
i + 1
vs
i
```

实际上代表的是题目完全不同的选择规则。

# ⑦ 为什么要排序？

```cpp
sort(candidates.begin(), candidates.end());
```

主要是为了剪枝。

假设：

```text
candidates = [2,3,6,7]
remain = 5
```

遍历：

```text
2 可以
3 可以
6 > 5
```

因为数组已经排序：

```text
6 后面的 7 肯定也 > 5
```

所以直接：

```cpp
break;
```

而不是：

```cpp
continue;
```

因为后面的数字全部不可能使用。

---

## `break` 和 `continue` 的区别

这里非常值得注意。

```cpp
if (candidates[i] > remain) {
    break;
}
```

为什么可以 `break`？

因为已经排序：

```text
当前数字 > remain
后面所有数字 >= 当前数字
```

所以后面全部没必要尝试。

如果数组没有排序，就只能：

```cpp
if (candidates[i] > remain) {
    continue;
}
```

因为后面可能还有更小的数字。

---

# ⑧ 递归三要素

这题非常适合递归回溯。

## 1. 递归函数定义

```cpp
backtrack(candidates, remain, startIndex)
```

表示：

> 当前还差 `remain` 才能达到 target，从 `startIndex` 开始继续选择数字，寻找所有合法组合。

---

## 2. 终止条件

```cpp
if (remain == 0) {
    result.push_back(path);
    return;
}
```

说明当前组合之和正好达到目标。

如果没排序，也通常需要：

```cpp
if (remain < 0) {
    return;
}
```

但我们排序之后通过：

```cpp
if (candidates[i] > remain) {
    break;
}
```

已经提前阻止 `remain` 变成负数，所以不必额外判断。

---

## 3. 当前层做什么？

当前层的任务是：

> 从 `[startIndex, end)` 中选择一个数字作为组合的下一个元素。

流程：

```text
1. 从 startIndex 开始遍历。
2. 当前数字大于 remain，直接 break。
3. 将 candidates[i] 加入 path。
4. remain 减去 candidates[i]。
5. 递归时仍然传 i，因为可以重复使用。
6. path.pop_back() 回溯。
7. 尝试下一个数字。
```

---

# ⑨ 为什么这题不推荐普通迭代法？

理论上可以用栈手动模拟：

```text
当前 path
当前 remain
当前候选下标
```

但这些恰好就是递归调用栈自然帮我们保存的状态。

迭代写法需要自己维护：

```cpp
stack<State>
```

反而更复杂。

而且本题是非常典型的回溯模板：

```text
选择
→ 递归
→ 撤销
```

因此重点学习递归回溯即可。

# ⑩ 面试追问

### Q1：为什么不能每次都从 `0` 开始选？

如果每层都从 `0` 开始：

```cpp
for (int i = 0; i < candidates.size(); ++i)
```

会产生：

```text
[2,2,3]
[2,3,2]
[3,2,2]
```

这些实际上是同一个组合。

所以使用：

```cpp
startIndex
```

规定下标只能向后。

---

### Q2：为什么不用 `used`？

因为我们不是要禁止数字重复使用。

恰恰相反：

```text
同一个数字允许重复选择
```

因此 `used` 不适合。

我们真正要避免的是：

```text
排列顺序导致的重复组合
```

所以使用 `startIndex`。

---

### Q3：为什么这题没有固定 `path.size()`？

因为每种组合长度不固定。

例如：

```cpp
candidates = [2,3,6,7]
target = 7
```

答案：

```text
[7]       长度 1
[2,2,3]   长度 3
```

所以不能根据 `path.size()` 判断结束。

必须根据：

```cpp
remain == 0
```

判断。

---

### Q4：如果每个数字只能使用一次怎么办？

递归改成：

```cpp
backtrack(
    candidates,
    remain - candidates[i],
    i + 1
);
```

因为当前数字用完以后不能再次使用。

如果数组本身还有重复值，还需要进行同层去重。

这就是 LeetCode 40“组合总和 II”的核心区别。

---

### Q5：复杂度是多少？

回溯题的复杂度取决于搜索树大小，很难像线性算法那样简单表示。

粗略可以认为递归深度最多为：

```text
target / min(candidates)
```

而每一层又会尝试多个候选数字，因此最坏情况是指数级搜索。

面试重点通常不在精确公式，而是说明：

> 这是指数级回溯搜索，通过排序和 `candidates[i] > remain` 进行剪枝。

# ⑫ 复习总结

```text
39. 组合总和

题型：
回溯 + 组合问题 + 元素可以重复使用。

核心变量：
result：保存所有答案。
path：当前组合。
startIndex：当前从哪个位置开始选择。
remain：距离 target 还差多少。

流程：
1. remain == 0：
   保存 path。

2. 从 startIndex 开始遍历 candidates。

3. 如果 candidates[i] > remain：
   break。

4. 做选择：
   path.push_back(candidates[i])

5. 递归：
   backtrack(
       candidates,
       remain - candidates[i],
       i
   )

6. 为什么传 i？
   因为当前元素可以重复使用。

7. 回溯：
   path.pop_back()
```

一句话记忆：

> **组合总和 = `startIndex` 防止排列重复，`remain` 判断是否达到目标，递归传 `i` 允许当前数字重复使用。**
