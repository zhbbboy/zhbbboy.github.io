这题非常适合接着你刚学的 **栈** 来做。

我推荐你主学：

> **两个栈 + 从左到右扫描字符串。**

一个栈保存重复次数，一个栈保存进入 `[` 之前已经得到的字符串。

递归也能做，而且嵌套结构天然适合递归，但这题面试里用栈写更直观，所以主讲栈。

---

# ① 破题：题目真正要求什么

例如：

```
s = "3[a2[c]]"
```

规则：

```
k[字符串]
```

表示括号里的字符串重复 `k` 次。

因此先处理里面：

```
2[c]
→ cc
```

原字符串变成：

```
3[acc]
```

然后：

```
acc 重复 3 次
```

得到：

```
accaccacc
```

所以这题真正麻烦的不是普通的：

```
3[a]
```

而是：

```
3[a2[c]]
  ↑
存在嵌套
```

而这种“进入一层 → 保存上一层 → 处理里面 → 再回来”的结构，就特别适合栈。

---

# ② 核心技巧：两个栈 + 两个当前变量

我们准备：

```
stack<int> nums;
stack<string> strs;

int num = 0;
string cur = "";
```

它们分别表示：

```
nums
保存每一层的重复次数

strs
保存进入 [ 之前已经得到的字符串

num
当前正在读取的数字

cur
当前这一层已经得到的字符串
```

例如：

```
3[a2[c]]
```

当我们读到：

```
3[
```

就要记住：

```
这一层重复 3 次
```

然后进入括号内部处理：

```
a2[c]
```

所以把 `3` 压入 `nums`。

# ③ 图解执行过程

重点跑：

```
s = "3[a2[c]]"
```

初始：

```
nums = []

strs = []

num = 0

cur = ""
```

---

## 遇到 `'3'`

这是数字。

所以：

```
num = 3;
```

状态：

```
num = 3
cur = ""
```

---

## 遇到 `'['`

这意味着：

> 接下来要进入一层新的括号。

但是进入之前，我们必须记住当前状态。

所以：

```
nums.push(num);
strs.push(cur);
```

现在：

```
nums：
3

strs：
""
```

然后开始处理括号里面，所以：

```
num = 0;
cur = "";
```

为什么一定要清空？

因为接下来：

```
a2[c]
```

属于新的这一层。

---

## 遇到 `'a'`

普通字母：

```
cur += 'a';
```

现在：

```
cur = "a"
```

---

## 遇到 `'2'`

说明后面：

```
2[...]
```

所以：

```
num = 2;
```

---

## 又遇到 `'['`

说明又进入新的一层。

当前：

```
num = 2
cur = "a"
```

必须保存：

```
nums.push(2);
strs.push("a");
```

现在：

```
nums：

3
2  ← top
```

字符串栈：

```
strs：

""
"a" ← top
```

然后重新：

```
num = 0;
cur = "";
```

---

## 遇到 `'c'`

```
cur += 'c';
```

所以：

```
cur = "c"
```

---

# 遇到第一个 `']'`

这是最关键的地方。

它表示：

> 当前这一层处理结束，现在要把这一层解码，然后返回上一层。

此时：

```
cur = "c"
```

栈顶重复次数：

```
2
```

所以：

```
"c" 重复 2 次
→ "cc"
```

但是别忘了，在进入这一层之前：

```
strs.top() = "a"
```

所以回来以后应该得到：

```
"a" + "cc"
= "acc"
```

于是：

```
cur = "acc"
```

然后这一层的：

```
2
"a"
```

都已经用完，要弹出。

---

# 遇到第二个 `']'`

现在：

```
cur = "acc"
```

栈里还剩：

```
nums.top() = 3
strs.top() = ""
```

所以：

```
"acc" 重复 3 次
```

得到：

```
accaccacc
```

加上上一层之前的：

```
""
```

最终：

```
cur = "accaccacc"
```

返回即可。

# ④ 完整代码

我推荐你掌握这个版本：

```cpp
class Solution {
public:
    string decodeString(string s) {
        stack<int> nums;
        stack<string> strs;

        int num = 0;
        string cur = "";

        for (char ch : s) {

            // 1. 数字
            if (isdigit(ch)) {
                num = num * 10 + (ch - '0');
            }

            // 2. 进入新的一层
            else if (ch == '[') {
                nums.push(num);
                strs.push(cur);

                num = 0;
                cur = "";
            }

            // 3. 当前这一层结束
            else if (ch == ']') {
                int repeat = nums.top();
                nums.pop();

                string prev = strs.top();
                strs.pop();

                string temp = "";

                for (int i = 0; i < repeat; ++i) {
                    temp += cur;
                }

                cur = prev + temp;
            }

            // 4. 普通字母
            else {
                cur += ch;
            }
        }

        return cur;
    }
};
```

# ⑤ 关键设计解释

## 为什么数字不能直接写：

```
num = ch - '0';
```

因为重复次数可能不是一位数。

例如：

```
12[a]
```

读取 `'1'`：

```
num = 0 * 10 + 1
= 1
```

再读取 `'2'`：

```
num = 1 * 10 + 2
= 12
```

所以：

```
num = num * 10 + (ch - '0');
```

这是处理多位数字的标准写法。

---

## 为什么遇到 `[` 要保存 `cur`？

例如：

```
3[a2[c]]
```

处理到：

```
3[a2[
```

此时：

```
cur = "a"
```

接下来我们要处理新的括号：

```
[c]
```

如果直接：

```
cur = "";
```

却没保存 `"a"`，那出来以后你就不知道前面还有一个：

```
a
```

了。

所以：

```
strs.push(cur);
```

实际上是在保存：

> **进入下一层之前，上一层已经处理好的字符串。**

---

## 为什么遇到 `[` 后 `num` 要重新变成 0？

例如：

```
3[a2[c]]
```

处理：

```
3[
```

以后，`3` 已经被存入：

```
nums
```

它的任务结束了。

后面又会读取：

```
2[
```

所以必须：

```
num = 0;
```

否则数字会串在一起。

---

## 为什么 `]` 时要：

```
cur = prev + temp;
```

而不是：

```
cur = temp;
```

还是看：

```
3[a2[c]]
```

处理内部：

```
2[c]
```

得到：

```
cc
```

但这一层在进入 `2[c]` 之前已经有：

```
a
```

所以真正结果：

```
a + cc
= acc
```

因此必须把上一层保存的：

```
prev
```

接回来。

---

# ⑥ 为什么这题也可以递归？

因为括号本身就是嵌套结构：

```
3[
    a
    2[
        c
    ]
]
```

可以理解成：

```
处理当前层
    ↓
遇到 [
    ↓
递归处理下一层
    ↓
遇到 ]
    ↓
返回上一层
```

所以递归是适用的。

但是这题如果你的目标是练栈，我更建议优先掌握刚才的栈版本，因为：

> **栈实际上是在手动保存每一层递归需要记住的状态。**

这里保存的就是：

```
上一层的字符串
上一层的重复次数
```

---

# ⑦ 为什么栈特别适合这题？

例如：

```
3[a2[c]]
```

进入顺序：

```
先进入 3[...]
再进入 2[...]
```

出来顺序却是：

```
先处理 2[...]
再处理 3[...]
```

也就是：

```
最后进入的
最先结束
```

正好：

```
LIFO
后进先出
```

所以天然适合栈。

这一点和你刚学的括号匹配非常像。

# ⑧ 面试追问

一个高频问题是：

**两个栈分别存什么？**

可以回答：

> 数字栈保存每一层的重复次数，字符串栈保存进入当前括号之前上一层已经构造好的字符串。遇到 `[` 时保存现场并进入下一层，遇到 `]` 时取出重复次数和上一层字符串，将当前字符串重复后拼接回去。

时间复杂度大体与最终生成字符串长度相关，可以理解为至少需要 O(输出字符串长度)；辅助空间来自栈和构造中的字符串。

→ 保存每层重复次数

→ 当前层字符串

这题最重要的一句话是：

> **遇到 `[` 就“保存上一层现场并进入下一层”；遇到 `]` 就“解码当前层并恢复上一层”。两个栈保存的就是每一层的重复次数和进入括号前的字符串。**
