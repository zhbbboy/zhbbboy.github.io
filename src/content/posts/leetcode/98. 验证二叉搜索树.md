## 解题思路
1. 首先得写一个`check(TreeNode* node,long long min,long long max)`函数，它的含义就是判断这颗node子树是否是有效的二叉搜索树，并且node->val必须严格位于（min，max）中。
2. 终止条件，当遍历的节点是空节点的时候，那么他一定是二叉搜索树所以返回true。
3. 内部判断，如果node节点的值不是在所规范的区间，那么返回false
4. 然后再检查左子树再检查右子树，将其结果返回。



# 98. 验证二叉搜索树

## ① 破题：什么是有效的二叉搜索树？

二叉搜索树 BST 要满足：

```text
左子树中所有节点 < 当前节点
右子树中所有节点 > 当前节点
左右子树本身也必须是二叉搜索树
```

注意关键词是：

> 左右子树中的**所有节点**，不只是左右孩子。

例如：

```text
        5
       / \
      1   7
         / \
        6   8
```

这是有效 BST，因为：

```text
左子树所有值 < 5
右子树所有值 > 5

6 < 7 < 8
```

---

# ② 最容易犯的错误：只比较父节点和孩子

很多人会这样判断：

```cpp
if (root->left && root->left->val >= root->val) {
    return false;
}

if (root->right && root->right->val <= root->val) {
    return false;
}
```

这个写法不够。

看题目中的错误示例：

```text
        5
       / \
      1   4
         / \
        3   6
```

只看局部关系：

```text
1 < 5        正确
4 < 6        正确
3 < 4        正确
```

但整棵树仍然不是 BST。

为什么？

因为节点 `4` 在根节点 `5` 的右子树中，所以它必须满足：

```text
4 > 5
```

但实际上：

```text
4 < 5
```

因此无效。

所以不能只判断：

```text
左孩子 < 父节点 < 右孩子
```

而要判断：

```text
当前节点是否满足祖先节点传下来的取值范围
```

---

# ③ 核心技巧：给每个节点规定合法范围

我们定义递归函数：

```cpp
check(node, lower, upper)
```

它表示：

> 判断以 `node` 为根的子树是否为有效 BST，并且要求当前节点值必须处于 `(lower, upper)` 这个开区间中。

为什么是开区间？

因为 BST 要求严格小于、严格大于，不允许相等。

---

## 根节点的范围

对于整棵树的根节点，还没有任何限制：

```text
(-∞, +∞)
```

---

## 进入左子树

假设当前节点值是 `5`。

左子树所有节点必须：

```text
小于 5
```

因此左子树范围变成：

```text
(lower, 5)
```

代码：

```cpp
check(node->left, lower, node->val);
```

---

## 进入右子树

右子树所有节点必须：

```text
大于 5
```

因此右子树范围变成：

```text
(5, upper)
```

代码：

```cpp
check(node->right, node->val, upper);
```

---

# ④ 用正确示例走一遍

树：

```text
        2
       / \
      1   3
```

最开始：

```text
节点 2 的合法范围：(-∞, +∞)
```

`2` 合法。

递归检查左子树：

```text
节点 1 的合法范围：(-∞, 2)
```

因为：

```text
1 < 2
```

合法。

递归检查右子树：

```text
节点 3 的合法范围：(2, +∞)
```

因为：

```text
3 > 2
```

合法。

所有节点均合法，返回：

```cpp
true
```

# ⑤ 用错误示例走一遍

树：

```text
        5
       / \
      1   4
         / \
        3   6
```

## 检查根节点 5

```text
合法范围：(-∞, +∞)
```

`5` 合法。

---

## 检查右子树根节点 4

因为 `4` 位于 `5` 的右子树中，所以合法范围是：

```text
(5, +∞)
```

但：

```text
4 <= 5
```

不满足范围，直接返回：

```cpp
false
```

这里不需要再检查 `4` 的孩子，整棵树已经无效。

这就是范围法能发现“跨层级错误”的原因。

---

# ⑥ 完整 C++ 代码

```cpp
class Solution {
public:
    bool isValidBST(TreeNode* root) {
        return check(root, LLONG_MIN, LLONG_MAX);
    }

private:
    bool check(TreeNode* node, long long lower, long long upper) {
        // 空树可以认为是有效 BST
        if (node == nullptr) {
            return true;
        }

        // 当前节点必须严格处于合法范围内
        if (node->val <= lower || node->val >= upper) {
            return false;
        }

        // 左子树范围：(lower, node->val)
        // 右子树范围：(node->val, upper)
        return check(node->left, lower, node->val) &&
               check(node->right, node->val, upper);
    }
};
```

---

# ⑦ 代码逐行解释

## 主函数

```cpp
bool isValidBST(TreeNode* root) {
    return check(root, LLONG_MIN, LLONG_MAX);
}
```

根节点一开始没有上下界限制，所以给它：

```text
下界：LLONG_MIN
上界：LLONG_MAX
```

相当于：

```text
(-∞, +∞)
```

---

## 递归函数定义

```cpp
bool check(TreeNode* node, long long lower, long long upper)
```

它表示：

> 判断 `node` 这棵子树是否有效，并且 `node->val` 必须严格位于 `(lower, upper)` 中。

---

## 终止条件

```cpp
if (node == nullptr) {
    return true;
}
```

递归走到空节点，说明这条分支没有违反规则。

因此空节点返回 `true`。

---

## 检查当前节点

```cpp
if (node->val <= lower || node->val >= upper) {
    return false;
}
```

当前值必须满足：

```text
lower < node->val < upper
```

注意必须严格比较。

如果等于上下界，同样无效，因为 BST 不允许重复值。

---

## 检查左子树

```cpp
check(node->left, lower, node->val)
```

左子树中所有节点必须：

```text
小于当前节点
```

所以上界更新为：

```cpp
node->val
```

原来的下界保持不变。

---

## 检查右子树

```cpp
check(node->right, node->val, upper)
```

右子树中所有节点必须：

```text
大于当前节点
```

所以下界更新为：

```cpp
node->val
```

原来的上界保持不变。

---

## 为什么用 `&&`？

```cpp
return check(node->left, lower, node->val) &&
       check(node->right, node->val, upper);
```

只有：

```text
左子树有效
并且
右子树有效
```

当前子树才有效。

只要有一边返回 `false`，整个结果就是 `false`。

---

# ⑧ 递归三要素套进这道题

## 1. 递归函数的定义

```cpp
check(node, lower, upper)
```

表示：

> 判断以 `node` 为根的树是否为有效 BST，同时要求节点值处于 `(lower, upper)` 中。

---

## 2. 递归终止条件

```cpp
if (node == nullptr) {
    return true;
}
```

空树不会违反 BST 规则。

---

## 3. 当前层做什么？

当前层做三件事：

```text
1. 检查当前节点是否在合法范围内
2. 给左子树传递更小的上界
3. 给右子树传递更大的下界
```

代码：

```cpp
if (node->val <= lower || node->val >= upper) {
    return false;
}

return check(node->left, lower, node->val) &&
       check(node->right, node->val, upper);
```

---

# ⑨ 为什么使用 `long long`？

节点值范围可能包括：

```cpp
INT_MIN
INT_MAX
```

假如我们使用：

```cpp
int lower = INT_MIN;
int upper = INT_MAX;
```

那么当节点值本身等于 `INT_MIN` 或 `INT_MAX` 时，会不好表示比它更小或更大的初始边界。

所以使用范围更大的：

```cpp
long long
```

初始边界：

```cpp
LLONG_MIN
LLONG_MAX
```

这样可以安全覆盖所有 `int` 节点值。

---

# ⑩ 另一种方法：中序遍历

二叉搜索树还有一个重要性质：

> BST 的中序遍历结果必须严格递增。

例如：

```text
        2
       / \
      1   3
```

中序遍历：

```text
1, 2, 3
```

严格递增，所以有效。

可以这样写：

```cpp
class Solution {
private:
    long long prev = LLONG_MIN;

public:
    bool isValidBST(TreeNode* root) {
        if (root == nullptr) {
            return true;
        }

        if (!isValidBST(root->left)) {
            return false;
        }

        if (root->val <= prev) {
            return false;
        }

        prev = root->val;

        return isValidBST(root->right);
    }
};
```

不过你现在刚学习二叉树递归，我建议先掌握**上下界法**，它更直接体现 BST 的定义。

# ⑪ 复杂度分析

时间复杂度：

```text
O(n)
```

每个节点最多检查一次。

空间复杂度：

```text
O(h)
```

`h` 是树的高度，来自递归调用栈。

平衡树中：

```text
O(log n)
```

极端退化成链表时：

```text
O(n)
```

# ⑫ 面试时怎么讲？

你可以这样回答：

> 不能只比较节点和它的直接左右孩子，因为二叉搜索树要求左子树所有节点都小于根，右子树所有节点都大于根。  
> 我使用递归上下界法。递归函数接收当前节点允许的最小值和最大值，当前节点必须严格位于这个范围内。进入左子树时，将当前节点值作为新的上界；进入右子树时，将当前节点值作为新的下界。只要某个节点超出范围，就返回 false。  
> 每个节点只访问一次，因此时间复杂度是 O(n)，递归栈空间复杂度是 O(h)。
