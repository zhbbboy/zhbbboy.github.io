# 🐉版
## 包装器

### function包装器
#### function包装器介绍
function是一种函数包装器，也叫做适配器。它可以对可调用对象进行包装，C++中的function本质就是一个类模板。

function类模板的原型如下：
```cpp
template <class T> function;     // undefined
template <class Ret, class... Args>
class function<Ret(Args...)>;
```
模板参数说明：
- `Ret`：被包装的可调用对象的返回值类型。
- `Args...`：被包装的可调用对象的形参类型。

**包装示例**
function包装器可以对可调用对象进行包装，包括函数指针（函数名）、仿函数（函数对象）、lambda表达式、类的成员函数。比如：
```cpp
int f(int a, int b)
{
	return a + b;
}
struct Functor
{
public:
	int operator()(int a, int b)
	{
		return a + b;
	}
};
class Plus
{
public:
	static int plusi(int a, int b)
	{
		return a + b;
	}
	double plusd(double a, double b)
	{
		return a + b;
	}
};
int main()
{
	//1、包装函数指针（函数名）
	function<int(int, int)> func1 = f;
	cout << func1(1, 2) << endl;

	//2、包装仿函数（函数对象）
	function<int(int, int)> func2 = Functor();
	cout << func2(1, 2) << endl;

	//3、包装lambda表达式
	function<int(int, int)> func3 = [](int a, int b){return a + b; };
	cout << func3(1, 2) << endl;

	//4、类的静态成员函数
	//function<int(int, int)> func4 = Plus::plusi;
	function<int(int, int)> func4 = &Plus::plusi; //&可省略
	cout << func4(1, 2) << endl;

	//5、类的非静态成员函数
	function<double(Plus, double, double)> func5 = &Plus::plusd; //&不可省略
	cout << func5(Plus(), 1.1, 2.2) << endl;
	return 0;
}
```
注意事项：
包装时指明返回值类型和各形参类型，然后将可调用对象赋值给function包装器即可，包装后function对象就可以像普通函数一样使用了。
取静态成员函数的地址可以不用取地址运算符“&”，但取非静态成员函数的地址必须使用取地址运算符“&”。
包装非静态的成员函数时需要注意，非静态成员函数的第一个参数是隐藏this指针，因此在包装时需要指明第一个形参的类型为类的类型。
#### function包装器统一类型
对于以下函数模板useF：
- 传入该函数模板的第一个参数可以是任意的可调用对象，比如函数指针、仿函数、lambda表达式等。
- useF中定义了静态变量count，并在每次调用时将count的值和地址进行了打印，可判断多次调用时调用的是否是同一个useF函数。
代码如下：
```cpp
template<class F, class T>
T useF(F f, T x)
{
	static int count = 0;
	cout << "count: " << ++count << endl;
	cout << "count: " << &count << endl;

	return f(x);
}
```
在传入第二个参数类型相同的情况下，如果传入的可调用对象的类型是不同的，那么在编译阶段该函数模板就会被实例化多次。比如：
```cpp
double f(double i)
{
	return i / 2;
}
struct Functor
{
	double operator()(double d)
	{
		return d / 3;
	}
};
int main()
{
	//函数指针
	cout << useF(f, 11.11) << endl;

	//仿函数
	cout << useF(Functor(), 11.11) << endl;

	//lambda表达式
	cout << useF([](double d)->double{return d / 4; }, 11.11) << endl;
	return 0;
}
```
由于函数指针、仿函数、lambda表达式是不同的类型，因此useF函数会被实例化出三份，三次调用useF函数所打印count的地址也是不同的。
- 但实际这里根本没有必要实例化出三份useF函数，因为三次调用useF函数时传入的可调用对象虽然是不同类型的，但这三个可调用对象的返回值和形参类型都是相同的。
- 这时就可以用包装器分别对着三个可调用对象进行包装，然后再用这三个包装后的可调用对象来调用useF函数，这时就只会实例化出一份useF函数。
- 根本原因就是因为包装后，这三个可调用对象都是相同的function类型，因此最终只会实例化出一份useF函数，该函数的第一个模板参数的类型就是function类型的。
代码如下：
```cpp
int main()
{
	//函数名
	function<double(double)> func1 = func;
	cout << useF(func1, 11.11) << endl;

	//函数对象
	function<double(double)> func2 = Functor();
	cout << useF(func2, 11.11) << endl;

	//lambda表达式
	function<double(double)> func3 = [](double d)->double{return d / 4; };
	cout << useF(func3, 11.11) << endl;
	return 0;
}
```
这时三次调用useF函数所打印count的地址就是相同的，并且count在三次调用后会被累加到3，表示这一个useF函数被调用了三次。

#### function包装器简化代码
求解逆波兰表达式的步骤如下：
- 定义一个栈，依次遍历所给字符串。
- 如果遍历到的字符串是数字则直接入栈。
- 如果遍历到的字符串是加减乘除运算符，则从栈定抛出两个数字进行对应的运算，并将运算后得到的结果压入栈中。
- 所给字符串遍历完毕后，栈顶的数字就是逆波兰表达式的计算结果。

代码如下：
```cpp
class Solution {
public:
	int evalRPN(vector<string>& tokens) {
		stack<int> st;
		for (const auto& str : tokens)
		{
			int left, right;
			if (str == "+" || str == "-" || str == "*" || str == "/")
			{
				right = st.top();
				st.pop();
				left = st.top();
				st.pop();
				switch (str[0])
				{
				case '+':
					st.push(left + right);
					break;
				case '-':
					st.push(left - right);
					break;
				case '*':
					st.push(left * right);
					break;
				case '/':
					st.push(left / right);
					break;
				default:
					break;
				}
			}
			else
			{
				st.push(stoi(str));
			}
		}
		return st.top();
	}
};
```
在上述代码中，我们通过switch语句来判断本次需要进行哪种运算，如果运算类型增加了，比如增加了求余、幂、对数等运算，那么就需要在switch语句的后面中继续增加case语句。

这种情况可以用包装器来简化代码。
- 建立各个运算符与其对应需要执行的函数之间的映射关系，当需要执行某一运算时就可以直接通过运算符找到对应的函数进行执行。
- 当运算类型增加时，就只需要建立新增运算符与其对应函数之间的映射关系即可。

代码如下：
```cpp
class Solution {
public:
	int evalRPN(vector<string>& tokens) {
		stack<int> st;
		unordered_map<string, function<int(int, int)>> opMap = {
			{ "+", [](int a, int b){return a + b; } },
			{ "-", [](int a, int b){return a - b; } },
			{ "*", [](int a, int b){return a * b; } },
			{ "/", [](int a, int b){return a / b; } }
		};
		for (const auto& str : tokens)
		{
			int left, right;
			if (str == "+" || str == "-" || str == "*" || str == "/")
			{
				right = st.top();
				st.pop();
				left = st.top();
				st.pop();
				st.push(opMap[str](left, right));
			}
			else
			{
				st.push(stoi(str));
			}
		}
		return st.top();
	}
};
```
需要注意的是，这里建立的是运算符与function类型之间的映射关系，因此无论是函数指针、仿函数还是lambda表达式都可以在包装后与对应的运算符进行绑定。
#### function包装器的意义
- 将可调用对象的类型进行统一，便于我们对其进行统一化管理。
- 包装后明确了可调用对象的返回值和形参类型，更加方便使用者使用。

### bind包装器

#### bind包装器介绍
bind也是一种函数包装器，也叫做适配器。它可以接受一个可调用对象，生成一个新的可调用对象来“适应”原对象的参数列表，C++中的bind本质是一个函数模板。

bind函数模板的原型如下：
```cpp
template <class Fn, class... Args>
/* unspecified */ bind(Fn&& fn, Args&&... args);
template <class Ret, class Fn, class... Args>
/* unspecified */ bind(Fn&& fn, Args&&... args);
```
模板参数说明：
- `fn`：可调用对象。
- `args...`：要绑定的参数列表：值或占位符。

**调用bind的一般形式**
调用bind的一般形式为：`auto newCallable = bind(callable, arg_list);`

**解释说明：**
- `callable`：需要包装的可调用对象。
- `newCallable`：生成的新的可调用对象。
- `arg_list`：逗号分隔的参数列表，对应给定的callable的参数。当调用newCallable时，newCallable会调用callable，并传给它arg_list中的参数。

arg_list中的参数可能包含形如_n的名字，其中n是一个整数，这些参数是“占位符”，表示newCallable的参数，它们占据了传递给newCallable的参数的“位置”。数值n表示生成的可调用对象中参数的位置，比如_1为newCallable的第一个参数，_ 2为第二个参数，以此类推。

此外，除了用auto接收包装后的可调用对象，也可以用function类型指明返回值和形参类型后接收包装后的可调用对象。

#### bind包装器绑定固定参数

 **无意义的绑定**
 下面这种绑定就是无意义的绑定：
 ```cpp
 int Plus(int a, int b)
{
	return a + b;
}
int main()
{
	//无意义的绑定
	function<int(int, int)> func = bind(Plus, placeholders::_1, placeholders::_2);
	cout << func(1, 2) << endl; //3
	return 0;
}
 ```
 绑定时第一个参数传入函数指针这个可调用对象，但后续传入的要绑定的参数列表依次是placeholders::_ 1和placeholders::_ 2，表示后续调用新生成的可调用对象时，传入的第一个参数传给placeholders::_ 1，传入的第二个参数传给placeholders::_ 2。此时绑定后生成的新的可调用对象的传参方式，和原来没有绑定的可调用对象是一样的，所以说这是一个无意义的绑定。

**绑定固定参数**
如果想把Plus函数的第二个参数固定绑定为10，可以在绑定时将参数列表的placeholders::_ 2设置为10。比如：
```cpp
int Plus(int a, int b)
{
	return a + b;
}
int main()
{
	//绑定固定参数
	function<int(int)> func = bind(Plus, placeholders::_1, 10);
	cout << func(2) << endl; //12
	return 0;
}
```
此时调用绑定后新生成的可调用对象时就只需要传入一个参数，它会将该值与10相加后的结果进行返回。

#### bind包装器调整传参顺序

 **调整传参顺序**
 对于下面Sub类中的sub成员函数，sub成员函数的第一个参数是隐藏的this指针，如果想要在调用sub成员函数时不用对象进行调用，那么可以将sub成员函数的第一个参数固定绑定为一个Sub对象。比如：
 ```cpp
 class Sub
{
public:
	int sub(int a, int b)
	{
		return a - b;
	}
};
int main()
{
	//绑定固定参数
	function<int(int, int)> func = bind(&Sub::sub, Sub(), placeholders::_1, placeholders::_2);
	cout << func(1, 2) << endl; //-1
	return 0;
}
 ```
 此时调用绑定后生成的可调用对象时，就只需要传入用于相减的两个参数了，因为在调用时会固定帮我们传入一个匿名对象给this指针。

如果想要将sub成员函数用于相减的两个参数的顺序交换，那么直接在绑定时将placeholders::_ 1和placeholders::_ 2的位置交换一下就行了。比如：
```cpp
class Sub
{
public:
	int sub(int a, int b)
	{
		return a - b;
	}
};
int main()
{
	//调整传参顺序
	function<int(int, int)> func = bind(&Sub::sub, Sub(), placeholders::_2, placeholders::_1);
	cout << func(1, 2) << endl; //1
	return 0;
}
```
根本原因就是因为，后续调用新生成的可调用对象时，传入的第一个参数会传给placeholders::_ 1，传入的第二个参数会传给placeholders::_ 2，因此可以在绑定时通过控制placeholders::_ n的位置，来控制第n个参数的传递位置。

#### bind包装器的意义
- 将一个函数的某些参数绑定为固定的值，让我们在调用时可以不用传递某些参数。
- 可以对函数参数的顺序进行灵活调整。


# AI讲解版
“包装器”重点指：
> **`std::function` 函数包装器，以及 `std::bind` 绑定器。**

这两个是校招面试里比较常见的一组知识点。
## 1. 什么是函数包装器 `std::function`

`std::function` 是 C++11 提供的一个：
> **通用可调用对象包装器。**
头文件：
```cpp
#include <functional>
```
它可以统一保存各种“可以被调用的东西”。
例如：
```cpp
std::function<int(int, int)> func;
```
表示：
```text
func 可以保存：
接收两个 int
返回一个 int
的可调用对象
```

---
## 2. `std::function` 的基本语法

```cpp
std::function<返回类型(参数类型...)>
```
例如：
```cpp
std::function<int(int, int)> func;
```
含义：
```text
返回类型：int
参数：int, int
```
所以可以：
```cpp
int result = func(10, 20);
```
前提是 `func` 已经绑定了具体可调用对象。

---
## 3. 它可以包装普通函数

普通函数：
```cpp
int Add(int a, int b)
{
    return a + b;
}
```
包装：
```cpp
std::function<int(int, int)> func = Add;
```
调用：
```cpp
std::cout << func(10, 20);
```
输出：
```text
30
```

```text
普通函数
        ↓
std::function
        ↓
统一调用
```

---
## 4. 可以包装 Lambda

```cpp
std::function<int(int, int)> func =
    [](int a, int b)
    {
        return a + b;
    };
```
然后：
```cpp
func(10, 20);
```
这也是为什么 `std::function` 经常和 Lambda 一起使用。

---
## 5. 有捕获 Lambda 也能保存
```cpp
int base = 100;

std::function<int(int)> func =
    [base](int value)
    {
        return base + value;
    };
```
调用：
```cpp
std::cout << func(20);
```
输出：
```text
120
```
这一点比普通函数指针强。

因为普通函数指针：
```cpp
int (*func)(int);
```
不能保存一个有捕获状态的 Lambda。

---
## 6. 可以包装函数对象

我们之前讲 Lambda 时提到函数对象：
```cpp
struct Add
{
    int operator()(int a, int b) const
    {
        return a + b;
    }
};
```
可以：
```cpp
std::function<int(int, int)> func = Add{};
```
调用：
```cpp
func(10, 20);
```
所以 `std::function` 可以统一：
```text
普通函数
函数指针
Lambda
函数对象
std::bind 结果
```

---
## 7. 为什么需要 `std::function`

假设我们想实现一个回调：
```cpp
void Execute(??? callback)
{
    callback();
}
```
问题是调用对象可能有很多种：
```cpp
普通函数
Lambda
函数对象
```
如果使用 `std::function`：
```cpp
void Execute(const std::function<void()>& callback)
{
    callback();
}
```
调用者可以传：
```cpp
Execute([]()
{
    std::cout << "Lambda\n";
});
```
也可以传普通函数：
```cpp
void Task()
{
}

Execute(Task);
```
于是调用接口被统一了。

---
## 8. `std::function` 的本质：类型擦除

这是面试比较重要的一点。

假设：
```cpp
void Func();
```
和：
```cpp
struct Functor
{
    void operator()() const;
};
```
以及：
```cpp
[]() {};
```
这三个对象的类型完全不同。

但是都可以放进：
```cpp
std::function<void()>
```
原因是 `std::function` 使用了：
> **类型擦除 Type Erasure。**

简单理解：
```text
原来：
普通函数     → 类型 A
Lambda       → 类型 B
函数对象     → 类型 C

经过 std::function：

全部统一表现为：

std::function<void()>
```
调用者不再关心里面真实是什么类型。

---
## 9. 类型擦除不是类型丢失

类型擦除不是说底层真实对象消失了。
而是：
> 对外隐藏具体类型，只暴露统一接口。

类似：
```text
里面到底是 Lambda？
函数对象？
普通函数？

调用者不用知道。

只要知道：
func()
可以调用。
```
这是一种运行时多态式设计，但不要求这些对象继承同一个基类。

---
## 10. `std::function` 和函数指针区别

函数指针：
```cpp
int (*func)(int, int);
```
只能主要保存兼容的普通函数地址或无捕获 Lambda。

而：
```cpp
std::function<int(int, int)>
```

可以保存：
- 普通函数；
- 无捕获 Lambda；
- 有捕获 Lambda；
- 函数对象；
- `std::bind` 结果。
所以 `std::function` 更通用。

对比：

|特点|函数指针|`std::function`|
|---|---|---|
|普通函数|可以|可以|
|无捕获 Lambda|可以|可以|
|有捕获 Lambda|不可以直接|可以|
|函数对象|不可以直接|可以|
|是否保存状态|不行|可以|
|开销|较低|相对更高|

---
## 11. `std::function` 有性能开销

因为它要实现类型擦除。
可能涉及：
```text
间接调用
额外对象管理
可能的动态内存分配
类型擦除开销
```
所以局部 Lambda 一般更推荐：
```cpp
auto func = []()
{
};
```
而不是无脑：
```cpp
std::function<void()> func = []()
{
};
```
如果根本不需要统一类型，`auto` 通常更高效。

---
## 12. 什么时候使用 `auto`，什么时候使用 `std::function`

局部使用 Lambda：
```cpp
auto func = []()
{
};
```
通常优先 `auto`。

但如果你需要：
```text
把回调保存成类成员
作为统一函数参数
放进同一个容器
运行时替换不同回调
```
就适合：
```cpp
std::function
```
例如：
```cpp
class Button
{
private:
    std::function<void()> onClick;

public:
    void SetCallback(std::function<void()> callback)
    {
        onClick = std::move(callback);
    }
};
```
这是典型回调系统。

---
## 13. `std::function` 可以为空
```cpp
std::function<void()> func;
```
此时里面没有保存任何可调用对象。

可以检查：
```cpp
if (func)
{
    func();
}
```
不能直接无脑调用空的 `std::function`：
```cpp
func();
```
会抛出：
```cpp
std::bad_function_call
```
所以回调场景经常这样写：
```cpp
if (callback)
{
    callback();
}
```

---
## 14. 什么是 `std::bind`

`std::bind` 也是 C++11 提供的工具。

它的作用是：
> **把一个可调用对象和部分参数提前绑定，生成一个新的可调用对象。**

头文件同样是：
```cpp
#include <functional>
```
例如：
```cpp
int Add(int a, int b)
{
    return a + b;
}
```
我们可以：
```cpp
auto func = std::bind(Add, 10, 20);
```
然后：
```cpp
func();
```
实际上相当于：
```cpp
Add(10, 20);
```
也就是说参数：
```cpp
10
20
```
已经提前绑定好了。

---
## 15. `std::bind` 可以绑定部分参数

例如：

```cpp
int Add(int a, int b)
{
    return a + b;
}
```
现在希望固定：
```cpp
a = 10
```
而 `b` 调用时再传。

可以：
```cpp
using namespace std::placeholders;

auto func = std::bind(Add, 10, _1);
```
调用：
```cpp
func(20);
```
等价于：
```cpp
Add(10, 20);
```
输出：
```text
30
```
这里：
```cpp
_1
```
叫：
> 占位符 placeholder。

---
## 16. `_1`、`_2` 是什么意思

需要：
```cpp
using namespace std::placeholders;
```
或者：
```cpp
std::placeholders::_1
```
例如：
```cpp
auto func = std::bind(Add, _1, _2);
```
调用：
```cpp
func(10, 20);
```
会展开：
```cpp
Add(10, 20);
```
如果写：
```cpp
auto func = std::bind(Add, _2, _1);
```
调用：
```cpp
func(10, 20);
```
实际变成：
```cpp
Add(20, 10);
```
所以占位符还可以改变参数顺序。

---
## 17. `std::bind` 默认按值保存绑定参数

这是非常重要的生命周期问题。
例如：
```cpp
void Print(int& value)
{
    value++;
}
```
如果：
```cpp
int value = 10;

auto func = std::bind(Print, value);
```
`std::bind` 默认会保存 `value` 的副本。

如果希望绑定原变量引用，需要：
```cpp
auto func = std::bind(
    Print,
    std::ref(value)
);
```
调用：
```cpp
func();
```
才能真正修改外部：
```cpp
value
```

---
## 18. `std::ref` 和 `std::cref`

`std::ref`：
```cpp
std::ref(value)
```
表示：
> 用引用方式包装对象。

例如：
```cpp
void Increase(int& value)
{
    ++value;
}

int value = 10;

auto func =
    std::bind(Increase, std::ref(value));

func();
```
此时：
```cpp
value == 11
```
只读引用可以使用：
```cpp
std::cref(value)
```
表示：
```text
const 引用包装
```
这类对象叫：
```cpp
std::reference_wrapper
```

---
## 19. `std::bind` 与成员函数

这是一个高频使用点。

假设：
```cpp
class Player
{
public:
    void Attack(int damage)
    {
        std::cout << damage << '\n';
    }
};
```
成员函数不能像普通函数一样简单：
```cpp
Player::Attack
```
调用必须有对象。

可以：
```cpp
Player player;

using namespace std::placeholders;

auto func =
    std::bind(
        &Player::Attack,
        &player,
        _1
    );
```
调用：
```cpp
func(100);
```
等价于：
```cpp
player.Attack(100);
```
这里：
```cpp
&Player::Attack
```
是成员函数指针；
```cpp
&player
```
提供调用对象；
```cpp
_1
```
表示未来传入的 `damage`。

---
## 20. `std::bind` 与 Lambda 谁更推荐？

现代 C++ 通常：

> **能用 Lambda，就优先使用 Lambda。**

例如：
```cpp
auto func = std::bind(
    &Player::Attack,
    &player,
    std::placeholders::_1
);
```
可以直接写成：
```cpp
auto func = [&player](int damage)
{
    player.Attack(damage);
};
```

Lambda 的优点：
- 可读性更强；
- 类型推导更直观；
- 更容易调试；
- 捕获规则更明确；
- 更容易被编译器优化；
- 不需要 `_1`、`_2` 这种占位符。

所以现在实际开发里 `std::bind` 使用频率已经下降。

## 重要的关系图

你可以把它们放在一起理解：
```text
各种可调用对象
│
├── 普通函数
├── 函数指针
├── Lambda
├── 函数对象 operator()
└── std::bind 生成对象
        ↓
std::function
        ↓
统一包装
        ↓
统一调用 func()
```
其中：
```text
std::bind
作用：
重新绑定参数，生成新的可调用对象

std::function
作用：
把不同类型的可调用对象统一成一种类型
```
这两个不要混淆。

# 面试高频问法

面试官问：
> `std::function` 是什么？

可以回答：
`std::function` 是 C++11 提供的通用可调用对象包装器，通过类型擦除可以统一保存普通函数、函数指针、Lambda、函数对象以及 `std::bind` 生成的对象，只要它们的调用签名兼容。它常用于回调、事件和统一存储可调用对象，但由于类型擦除和间接调用，会有一定运行时开销，因此如果只是局部使用 Lambda，通常更推荐直接使用 `auto` 保存具体闭包类型。

面试官继续问：
> `std::bind` 是什么？

回答：
`std::bind` 可以对一个可调用对象进行参数绑定和参数重排，生成一个新的可调用对象。可以使用 `_1`、`_2` 等占位符表示调用新对象时传入的参数。绑定参数默认按值保存，如果需要引用语义，可以配合 `std::ref` 或 `std::cref`。

# 最后压缩成 8 个必须记住的点

1. `std::function<R(Args...)>` 是通用可调用对象包装器。
    
2. 它可以包装普通函数、Lambda、函数对象、`bind` 结果。
    
3. 它底层核心思想是**类型擦除**。
    
4. 相比函数指针，`std::function` 可以保存带状态的 Lambda。
    
5. `std::function` 有额外开销，局部 Lambda 优先使用 `auto`。
    
6. `std::bind` 用于提前绑定参数、改变参数顺序。
    
7. `_1`、`_2` 是调用时参数占位符。
    
8. `bind` 默认按值保存参数，需要引用时使用 `std::ref`；现代 C++ 中通常优先 Lambda 而不是 `std::bind`。

最核心区别：

> **`std::function` 是“把不同可调用对象统一包装起来”，`std::bind` 是“重新绑定参数生成一个新的可调用对象”。**
