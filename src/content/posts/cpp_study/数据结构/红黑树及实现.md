# 红黑树的插入操作的实现

## 前言

红黑树是一种自平衡二叉搜索树，它的每个结点都带有颜色属性的二叉搜索树，颜色为红色或黑色。通过对任何⼀条从根到叶子的路径上各个结点的颜色进行约束，确保其没有⼀条路径会比其他路径大2倍，从而接近平衡。

红黑树是一种 AVL 的变体，它的左右子树高差有可能大于 1，所以红黑树不是严格意义上的 AVL树，但其进行平衡的代价较低， 平均统计性能要强于 AVL 树。

由于每一棵红黑树都是一颗二叉排序树，因此，在对红黑树进行查找时，可以采用运用于普通二叉排序树上的查找算法，在查找过程中不需要颜色信息。

## 红黑树的规则
1. 每个结点不是红色就是黑色。
2. 根结点是黑色的。
3. 如果⼀个结点是红色的，则它的两个孩⼦结点必须是黑色的，也就是说任意⼀条路径不会有连续的红色结点。
4. 对于任意⼀个结点，从该结点到其所有NULL结点的简单路径上，均包含相同数量的黑色结点。
5. 每个叶子结点 ( NILL ) 都是黑色，这里的叶子指的是空结点。
![](../../_Pasted_Image/Pasted%20image%2020260905194257.png)

红⿊树通过这 4 条规则，间接的实现了近似平衡。设最短路径为 h ，则红黑树将高度控制在 h ~ 2 * h 之间，也就是说红黑树确保最长路径不超过最短路径的2倍。

在极端情况下，由于红黑树的规则，最短路径必定是由全黑色结点组成的 ( 最短路径 = h )。

由于红黑树的规则，任意一条路径不会有连续的红色结点，那在极端情况下，最长路径一定是一红一黑间隔组成的 ( 最长路径 = 2 * h )。

## 红黑树的插入

红黑树首先是一个二叉搜索树，要先根据二叉搜索树的规则找到合适的位置进行插入。

### 对新插入结点的考虑
找到合适的插入位置后，就要考虑插入结点的颜色问题：

1. 如果插入结点定义为黑色，那么其必定违反红黑树的第四条规则 ( 对于任意⼀个结点，从该结点到其所有NULL结点的简单路径上，均包含相同数量的黑色结点 ) 。
![](../../_Pasted_Image/Pasted%20image%2020260905194629.png)

2. 如果插入结点定义为红色，其可能会违反红黑树的规则。
![](../../_Pasted_Image/Pasted%20image%2020260905194638.png)
所以，对新插入结点设置为红色最好，设置为黑色必定要调整，设置为红色可能需要调整。

但还要考虑 _ root 为空的情况，此时新插入结点直接设置为黑色即可。
```cpp
bool insert(const pair<K, V>& kv)
{
	if (_root == nullptr)
	{
		_root = new Node(kv);
		_root->_color = BLACK;
 
		return true;
	}
 
	Node* parent = _root;
	Node* cur = _root;
 
	while (cur)
	{
		if (cur->_kv.first > kv.first)
		{
			parent = cur;
			cur = cur->_left;
		}
		else if (cur->_kv.first < kv.first)
		{
			parent = cur;
			cur = cur->_right;
		}
		else
		{
			return false;
		}
	}
 
	cur = new Node(kv);
	cur->_color = RED;
 
	if (parent->_kv.first < kv.first)
	{
		parent->_right = cur;
	}
	else
	{
		parent->_left = cur;
	}
 
	cur->_parent = parent;
 
	// 对红黑树进行调整
 
 
	return true;
}
```

这种情况下需要进行旋转，但无论那种旋转，旋转后都已符合红黑树的规则，不必向上调整。
##### 1.2.1 新增节点为 parent 的左子树

此时需要对 grandparent 右单旋，旋转之后，parent 替代了 grandparent 原来的位置，所以将 parent 置为黑， grandparent 置为红色即可。
```cpp

{
	// 右单旋+变色
	RotateR(grandfather);
 
	parent->_color = BLACK;
	grandfather->_color = RED;
}
```

和 AVL 树相同，仅仅右单旋无法让红黑树符合规则，所以需要左右双旋：先对 parent 进行左单旋，再对 grandparent 进行右单旋，旋转后 cur 替代了原来 grandparent 的位置，所以，将 cur 结点置为黑色，grandparent 置为红色。
```cpp

{
	// 左右双旋+变色
	RotateL(parent);
	RotateR(grandfather);
 
	cur->_color = BLACK;
	grandfather->_color = RED;
}
```

## 插入操作完整代码
```cpp
enum Color
{
	RED,
	BLACK
};
 
template<class K, class V>
struct RBTreeNode
{
	RBTreeNode(const pair<K, V>& kv)
		:_kv(kv)
		, _left(nullptr)
		, _right(nullptr)
		, _parent(nullptr)
	{}
 
	pair<K, V> _kv;
 
	RBTreeNode<K, V>* _left;
	RBTreeNode<K, V>* _right;
	RBTreeNode<K, V>* _parent;
 
	Color _color;
};
 
template<class K, class V>
class RBTree
{
	typedef RBTreeNode<K, V> Node;
public:
	bool insert(const pair<K, V>& kv)
	{
		if (_root == nullptr)
		{
			_root = new Node(kv);
			_root->_color = BLACK;
 
			return true;
		}
 
		Node* parent = _root;
		Node* cur = _root;
 
		while (cur)
		{
			if (cur->_kv.first > kv.first)
			{
				parent = cur;
				cur = cur->_left;
			}
			else if (cur->_kv.first < kv.first)
			{
				parent = cur;
				cur = cur->_right;
			}
			else
			{
				return false;
			}
		}
 
		cur = new Node(kv);
		cur->_color = RED;
 
		if (parent->_kv.first < kv.first)
		{
			parent->_right = cur;
		}
		else
		{
			parent->_left = cur;
		}
 
		cur->_parent = parent;
 
		// 对红黑树进行调整
		// 如果父节点为红色，则需要进行调整
		while (parent && parent->_color == RED)
		{
			Node* grandfather = parent->_parent;
 
			if (grandfather->_left == parent)
			{
				Node* uncle = grandfather->_right;
 
				if (uncle && uncle->_color == RED)
				{
					parent->_color = uncle->_color = BLACK;
					grandfather->_color = RED;
 
					// 继续向上调整
					cur = grandfather;
					parent = cur->_parent;
				}
				// uncle不存在或存在且为黑
				else 
				{
					if (parent->_left == cur)
					{
						// 右单旋+变色
						RotateR(grandfather);
 
						parent->_color = BLACK;
						grandfather->_color = RED;
					}
					else
					{
						// 左右双旋+变色
						RotateL(parent);
						RotateR(grandfather);
 
						cur->_color = BLACK;
						grandfather->_color = RED;
					}
 
					break;
				}
			}
			else // grandfather->_right == parent
			{
				Node* uncle = grandfather->_left;
 
				if (uncle && uncle->_color == RED)
				{
					parent->_color = uncle->_color = BLACK;
					grandfather->_color = RED;
 
					// 继续向上调整
					cur = grandfather;
					parent = cur->_parent;
				}
				else // uncle不存在或存在且为黑
				{
					if (parent->_right == cur)
					{
						// 左单旋+变色
						RotateL(grandfather);
 
						parent->_color = BLACK;
						grandfather->_color = RED;
					}
					else
					{
						// 右左双旋+变色
						RotateR(parent);
						RotateL(grandfather);
 
						cur->_color = BLACK;
						grandfather->_color = RED;
					}
 
					break;
				}
			}
		}
 
		_root->_color = BLACK;
 
		return true;
	}
 
	// 右单旋
	void RotateR(Node* parent)
	{
		Node* subL = parent->_left;
		Node* subLR = subL->_right;
		
		// 调整结点的链接关系
		parent->_left = subLR;
		
		// 要考虑subLR为nullptr的情况
		if (subLR)
		{
			subLR->_parent = parent;
		}
		
		Node* pparent = parent->_parent;
		
		parent->_parent = subL;
		subL->_right = parent;
		
		// 考虑是否为根节点的情况
		if (parent == _root)
		{
			_root = subL;
			subL->_parent = nullptr;
		}
		else
		{
			if (pparent->_left == parent)
			{
				pparent->_left = subL;
			}
			else
			{
				pparent->_right = subL;
			}
		
			subL->_parent = pparent;
		}
	}
 
	// 左单旋
	void RotateL(Node* parent)
	{
 
		Node* subR = parent->_right;
		Node* subRL = subR->_left;
	
		parent->_right = subRL;
		if (subRL)
		{
			subRL->_parent = parent;
		}
	
		Node* pparent = parent->_parent;
	
		parent->_parent = subR;
		subR->_left = parent;
	
		if (parent == _root)
		{
			_root = subR;
			subR->_parent = nullptr;
		}
		else
		{
			if (pparent->_left == parent)
			{
				pparent->_left = subR;
			}
			else
			{
				pparent->_right = subR;
			}
	
			subR->_parent = pparent;
		}
	}
 
private:
	Node* _root = nullptr;
};
```


## 插入情况详细分析

红黑树的插入与二叉排序树的插入方式是一致的，只不过是在插入过后，可能会导致树的不平衡，这时就需要对树进行旋转操作和颜色修复（在这里简称插入修复），使得它符合红黑树的定义

**新插入的节点是红色的**，这样不会增加某一路径黑色的高度

- 插入修复操作如果遇到父节点的颜色为黑则修复操作结束
- 只有在父节点为红色节点的时候是需要插入修复操作的
##### 情况一
**节点为根结点**
解决：直接把插入后直接改为黑色即可

##### 情况二
**父节点是黑色**
解决：直接插入即可

##### 情况三
**父节点是红色，叔叔结点也是红色（左右子情况均包含）**
解决：把父辈节点全部变成黑色，祖父结点变成红色

下面又会出现三种情况：
1. 祖父结点(G)是根结点（如图的情况）
    ​ **祖父结点自身改为黑色即可**
    
2. 祖父结点(G)的父结点是红色节点
    ​ **进行情况三到情况五的修复**
    
3. 祖父结点(G)的父结点是黑色节点
    ​ **不需要做修复**
##### 情况四
**父节点是红色，叔叔节点是黑色（NIL也是黑色），和父节点 `在` 同一斜线上**

**父节点是红色，叔叔节点是黑色（NIL也是黑色），和父节点 `不在` 同一斜线上**

## 红黑树除了**规则 + 插入**，还建议掌握这些：
- **为什么红黑树能保证 `O(logN)`**  
    要知道核心原因：红节点不能连续出现、任一路径黑节点数相同，因此最长路径不会超过最短路径约 2 倍。
    
- **左旋 / 右旋**  
    这个你学过 AVL，红黑树里继续复用。要能看懂 LL、LR、RR、RL 对应怎么旋转。
    
- **插入后的调整逻辑**  
    不只是背情况，要理解：
    
    ```
    parent 黑色 → 不处理
    parent 红色 → 发生红红冲突
        ↓
    看 uncle
        ↓
    uncle 红 → 变色，问题向上继续
    uncle 黑/不存在 → 旋转 + 变色
    ```
    
- **为什么新节点默认插红色**  
    因为插黑色会直接改变某条路径的黑节点数量，更难维护；插红色通常只可能产生“连续红节点”问题。
    
- **如何验证一棵树是不是红黑树**  
    至少会检查：
    
    ```
    根节点是否黑色
    是否存在连续红节点
    每条根到叶子的黑节点数量是否相同
    是否仍满足 BST
    ```
    
- **红黑树和 AVL 的区别**  
    AVL 更严格平衡，查找通常更紧；红黑树平衡更宽松，插入删除调整通常更少，所以 `map/set` 常用红黑树。
    
- **红黑树迭代器**  
    这个对你后面模拟 `set/map` 很重要。尤其要懂中序遍历下：
    
    ```
    ++iterator
    --iterator
    ```
    
    怎么找后继和前驱。
    
- **用红黑树封装 `set/map`**  
    这是你后面真正该做的：
    
    ```
    set  → 存 K
    map  → 存 pair<const K,V>
    ```
    
    然后通过 `KeyOfT` 统一复用一棵泛型红黑树。
