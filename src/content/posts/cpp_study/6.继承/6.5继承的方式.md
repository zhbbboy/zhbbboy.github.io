## 继承的方式
1. 单继承：一个子类只有一个直接父类时称这个继承关系为单继承。
![](../../_Pasted_Image/Pasted%20image%2020260729164813.png)
2. 多继承：一个子类有两个或两个以上直接父类时称这个继承关系为多继承。
![](../../_Pasted_Image/Pasted%20image%2020260729164836.png)
  3. 菱形继承：菱形继承是多继承的一种特殊情况。
![](../../_Pasted_Image/Pasted%20image%2020260729164916.png)
从菱形继承的模型构造就可以看出，菱形继承的继承方式存在数据冗余和二义性的问题。

例如，对于以上菱形继承的模型，当我们实例化出一个Assistant对象后，访问成员时就会出现二义性问题。
```cpp
#include <iostream>
#include <string>
using namespace std;
class Person
{
public:
	string _name; //姓名
};
class Student : public Person
{
protected:
	int _num; //学号
};
class Teacher : public Person
{
protected:
	int _id; //职工编号
};
class Assistant : public Student, public Teacher
{
protected:
	string _majorCourse; //主修课程
};
int main()
{
	Assistant a;
	a._name = "peter"; //二义性：无法明确知道要访问哪一个_name
	return 0;
}
```
Assistant对象是多继承的Student和Teacher，而Student和Teacher当中都继承了Person，因此Student和Teacher当中都有_name成员，若是直接访问Assistant对象的_name成员会出现访问不明确的报错。

对于此，我们可以显示指定访问Assistant哪个父类的_name成员。
```cpp
//显示指定访问哪个父类的成员
a.Student::_name = "张同学";
a.Teacher::_name = "张老师";
```
虽然该方法可以解决二义性的问题，但仍然不能解决数据冗余的问题。因为在Assistant的对象在Person成员始终会存在两份。
![](../../_Pasted_Image/Pasted%20image%2020260729165021.png)
## 菱形虚拟继承
为了解决菱形继承的二义性和数据冗余问题，出现了虚拟继承。如前面说到的菱形继承关系，在Student和Teacher继承Person是使用虚拟继承，即可解决问题。
![](../../_Pasted_Image/Pasted%20image%2020260729165212.png)
虚拟继承代码如下：
```cpp
#include <iostream>
#include <string>
using namespace std;
class Person
{
public:
	string _name; //姓名
};
class Student : virtual public Person //虚拟继承
{
protected:
	int _num; //学号
};
class Teacher : virtual public Person //虚拟继承
{
protected:
	int _id; //职工编号
};
class Assistant : public Student, public Teacher
{
protected:
	string _majorCourse; //主修课程
};
int main()
{
	Assistant a;
	a._name = "peter"; //无二义性
	return 0;
}
```
此时就可以直接访问Assistant对象的_name成员了，并且之后就算我们指定访问Assistant的Student父类和Teacher父类的_name成员，访问到的都是同一个结果，解决了二义性的问题。
```cpp
cout << a.Student::_name << endl; //peter
cout << a.Teacher::_name << endl; //peter
```
而我们打印Assistant的Student父类和Teacher父类的_name成员的地址时，显示的也是同一个地址，解决了数据冗余的问题。
```cpp
cout << &a.Student::_name << endl; //0136F74C
cout << &a.Teacher::_name << endl; //0136F74C
```
## 菱形虚拟继承原理
在此之前，我们先看看不使用菱形虚拟继承时，以下菱形继承当中D类对象的各个成员在内存当中的分布情况。
![](../../_Pasted_Image/Pasted%20image%2020260729170829.png)
```cpp
#include <iostream>
using namespace std;
class A
{
public:
	int _a;
};
class B : public A
{
public:
	int _b;
};
class C : public A
{
public:
	int _c;
};
class D : public B, public C
{
public:
	int _d;
};
int main()
{
	D d;
	d.B::_a = 1;
	d.C::_a = 2;
	d._b = 3;
	d._c = 4;
	d._d = 5;
	return 0;
}
```

![](../../_Pasted_Image/Pasted%20image%2020260729170853.png)
也就是说，D类对象当中各个成员在内存当中的分布情况如下：
![](../../_Pasted_Image/Pasted%20image%2020260729170901.png)
这里就可以看出为什么菱形继承导致了数据冗余和二义性，根本原因就是D类对象当中含有两个_a成员。

现在我们再来看看使用菱形虚拟继承时，以下菱形继承当中D类对象的各个成员在内存当中的分布情况。
![](../../_Pasted_Image/Pasted%20image%2020260729170943.png)测试代码如下：
```cpp
#include <iostream>
using namespace std;
class A
{
public:
	int _a;
};
class B : virtual public A
{
public:
	int _b;
};
class C : virtual public A
{
public:
	int _c;
};
class D : public B, public C
{
public:
	int _d;
};
int main()
{
	D d;
	d.B::_a = 1;
	d.C::_a = 2;
	d._b = 3;
	d._c = 4;
	d._d = 5;
	return 0;
}
```
通过内存窗口，我们可以看到D类对象当中各个成员在内存当中的分布情况如下：
![](../../_Pasted_Image/Pasted%20image%2020260729171053.png)
其中D类对象当中的_a成员被放到了最后，而在原来存放两个_a成员的位置变成了两个指针，这两个指针叫虚基表指针，它们分别指向一个虚基表。
虚基表中包含两个数据，第一个数据是为多态的虚表预留的存偏移量的位置（这里我们不必关心），第二个数据就是当前类对象位置距离公共虚基类的偏移量。
也就是说，这两个指针经过一系列的计算，最终都可以找到成员_a。
![](../../_Pasted_Image/Pasted%20image%2020260729171145.png)
我们若是将D类对象赋值给B类对象，在这个切片过程中，就需要通过虚基表中的第二个数据找到公共虚基类A的成员，得到切片后该B类对象在内存中仍然保持这种分布情况。
```cpp
D d;
B b = d; //切片行为
```
得到切片后该B类对象当中各个成员在内存当中的分布情况如下：
![](../../_Pasted_Image/Pasted%20image%2020260729171220.png)

## AI讲解C++ 常见的继承结构包括：

---
### 一、单继承
一个派生类只直接继承一个基类。
```cpp
class Animal
{
};

class Dog : public Animal
{
};
```
结构：
```text
Animal
   ↓
  Dog
```
这里：
- `Animal` 是基类；
- `Dog` 是派生类；
- `Dog` 只有一个直接基类。

这是最简单、最常见的继承结构。
#### 对象结构
一个 `Dog` 对象概念上包含：
```text
Dog 对象
├── Animal 基类子对象
└── Dog 自己的成员
```
示例：
```cpp
#include <iostream>

class Animal
{
public:
    void Eat()
    {
        std::cout << "Animal eats\n";
    }
};

class Dog : public Animal
{
public:
    void Bark()
    {
        std::cout << "Dog barks\n";
    }
};

int main()
{
    Dog dog;

    dog.Eat();
    dog.Bark();
}
```

---
### 二、多层继承
一个类继承某个基类后，又被其他类继续继承。
```cpp
class Animal
{
};

class Mammal : public Animal
{
};

class Dog : public Mammal
{
};
```
结构：
```text
Animal
   ↓
Mammal
   ↓
  Dog
```
其中：
- `Animal` 是 `Mammal` 的直接基类；
- `Mammal` 是 `Dog` 的直接基类；
- `Animal` 是 `Dog` 的间接基类。
#### 对象结构
`Dog` 对象概念上包含：
```text
Dog 对象
├── Animal 部分
├── Mammal 部分
└── Dog 自己的部分
```
示例：
```cpp
#include <iostream>

class Animal
{
public:
    void Eat()
    {
        std::cout << "Eat\n";
    }
};

class Mammal : public Animal
{
public:
    void Run()
    {
        std::cout << "Run\n";
    }
};

class Dog : public Mammal
{
public:
    void Bark()
    {
        std::cout << "Bark\n";
    }
};

int main()
{
    Dog dog;

    dog.Eat();
    dog.Run();
    dog.Bark();
}
```
#### 构造和析构顺序
构造 `Dog`：
```text
Animal
  ↓
Mammal
  ↓
Dog
```
析构顺序相反：
```text
Dog
  ↓
Mammal
  ↓
Animal
```

---
### 三、层次继承

多个派生类继承同一个基类。
```cpp
class Animal
{
};

class Dog : public Animal
{
};

class Cat : public Animal
{
};

class Bird : public Animal
{
};
```
结构：
```text
        Animal
       /   |   \
     Dog  Cat  Bird
```
这表示：
```text
Dog 是一种 Animal
Cat 是一种 Animal
Bird 是一种 Animal
```
示例：
```cpp
#include <iostream>

class Character
{
public:
    void Move()
    {
        std::cout << "Character moves\n";
    }
};

class Player : public Character
{
public:
    void UseSkill()
    {
        std::cout << "Player uses skill\n";
    }
};

class Enemy : public Character
{
public:
    void Attack()
    {
        std::cout << "Enemy attacks\n";
    }
};

class NPC : public Character
{
public:
    void Talk()
    {
        std::cout << "NPC talks\n";
    }
};
```
这里：
```text
        Character
       /    |     \
  Player  Enemy   NPC
```
层次继承非常适合建立统一接口，并配合虚函数实现多态。

---
### 四、多继承

一个派生类同时直接继承多个基类。
语法：
```cpp
class Derived : public Base1, public Base2
{
};
```
例如：
```cpp
class Flyable
{
};

class Swimmable
{
};

class Duck : public Flyable, public Swimmable
{
};
```
结构：
```text
Flyable   Swimmable
    \       /
       Duck
```
`Duck` 对象中同时包含：
```text
Duck 对象
├── Flyable 基类子对象
├── Swimmable 基类子对象
└── Duck 自己的部分
```
完整示例：
```cpp
#include <iostream>

class Flyable
{
public:
    void Fly()
    {
        std::cout << "Flying\n";
    }
};

class Swimmable
{
public:
    void Swim()
    {
        std::cout << "Swimming\n";
    }
};

class Duck : public Flyable, public Swimmable
{
public:
    void Quack()
    {
        std::cout << "Quack\n";
    }
};

int main()
{
    Duck duck;

    duck.Fly();
    duck.Swim();
    duck.Quack();
}
```

---
#### 多继承的同名成员歧义

假设两个基类都有同名函数：
```cpp
class Base1
{
public:
    void Print()
    {
        std::cout << "Base1\n";
    }
};

class Base2
{
public:
    void Print()
    {
        std::cout << "Base2\n";
    }
};

class Derived : public Base1, public Base2
{
};
```
调用：
```cpp
Derived object;

// object.Print(); // 错误：编译器不知道调用哪一个
```
需要明确指定：
```cpp
object.Base1::Print();
object.Base2::Print();
```
因此多继承的常见问题之一是：
> 多个基类出现同名成员时，会产生名字查找歧义。

---
### 五、菱形继承
菱形继承是多继承中的一种特殊结构。
例如：
```cpp
class Animal
{
};

class FlyingAnimal : public Animal
{
};

class SwimmingAnimal : public Animal
{
};

class Duck : public FlyingAnimal, public SwimmingAnimal
{
};
```
结构：
```text
          Animal
          /    \
 FlyingAnimal  SwimmingAnimal
          \    /
           Duck
```
因为形状像菱形，所以称为菱形继承，也叫钻石继承。

---
#### 1. 菱形继承的问题
普通继承情况下：
```cpp
class Animal
{
public:
    int age = 1;
};
```
`FlyingAnimal` 包含一份 `Animal`：
```text
FlyingAnimal
└── Animal
```
`SwimmingAnimal` 也包含一份 `Animal`：
```text
SwimmingAnimal
└── Animal
```
所以最终 `Duck` 中会有两份 `Animal` 子对象：
```text
Duck 对象
├── FlyingAnimal
│   └── Animal
│       └── age
│
└── SwimmingAnimal
    └── Animal
        └── age
```
这会造成两个问题：
```text
1. 数据重复
2. 成员访问歧义
```

---
#### 2. 成员访问歧义
```cpp
#include <iostream>

class Animal
{
public:
    int age = 1;
};

class FlyingAnimal : public Animal
{
};

class SwimmingAnimal : public Animal
{
};

class Duck : public FlyingAnimal, public SwimmingAnimal
{
};

int main()
{
    Duck duck;

    // std::cout << duck.age; // 错误：不知道是哪一份 age
}
```
编译器不知道你要访问：
```cpp
duck.FlyingAnimal::age
```
还是：
```cpp
duck.SwimmingAnimal::age
```
只能手动指定：
```cpp
std::cout << duck.FlyingAnimal::age << '\n';
std::cout << duck.SwimmingAnimal::age << '\n';
```
而且这两个 `age` 是两份独立数据：
```cpp
duck.FlyingAnimal::age = 10;
duck.SwimmingAnimal::age = 20;
```

---
### 六、虚继承解决菱形继承问题
为了让最底层的 `Duck` 只包含一份公共基类 `Animal`，可以使用虚继承：
```cpp
class FlyingAnimal : virtual public Animal
{
};

class SwimmingAnimal : virtual public Animal
{
};
```
完整代码：
```cpp
#include <iostream>

class Animal
{
public:
    int age = 1;
};

class FlyingAnimal : virtual public Animal
{
};

class SwimmingAnimal : virtual public Animal
{
};

class Duck : public FlyingAnimal, public SwimmingAnimal
{
};

int main()
{
    Duck duck;

    duck.age = 10;
    std::cout << duck.age << '\n';
}
```
结构变成：
```text
          Animal
          ↑    ↑
 FlyingAnimal  SwimmingAnimal
          \    /
           Duck
```
逻辑上，`Duck` 中只有一份共享的 `Animal` 虚基类子对象：
```text
Duck 对象
├── 共享的 Animal 子对象
├── FlyingAnimal 部分
├── SwimmingAnimal 部分
└── Duck 自己的部分
```
于是：
```cpp
duck.age
```
不再产生歧义。

---
#### 虚继承中的 `virtual`
这里的：
```cpp
virtual public Animal
```
和虚函数中的：
```cpp
virtual void Func();
```
虽然都使用 `virtual`，但解决的问题不同。
```text
虚函数：
解决运行时多态和动态绑定

虚继承：
解决菱形继承中公共基类子对象重复的问题
```

---
### 七、虚基类由谁负责构造？

这是虚继承中非常重要的规则：
> **虚基类由最终派生类，也就是最底层派生类负责直接构造。**

例如：
```cpp
#include <iostream>

class Animal
{
public:
    Animal(int age)
    {
        std::cout << "Animal: " << age << '\n';
    }
};

class FlyingAnimal : virtual public Animal
{
public:
    FlyingAnimal()
        : Animal(10)
    {
    }
};

class SwimmingAnimal : virtual public Animal
{
public:
    SwimmingAnimal()
        : Animal(20)
    {
    }
};

class Duck : public FlyingAnimal, public SwimmingAnimal
{
public:
    Duck()
        : Animal(30),
          FlyingAnimal(),
          SwimmingAnimal()
    {
    }
};
```
创建：
```cpp
Duck duck;
```
真正用于构造共享 `Animal` 子对象的是：
```cpp
Animal(30)
```
也就是最终派生类 `Duck` 指定的构造参数。
当构造完整的 `Duck` 对象时，`FlyingAnimal` 和 `SwimmingAnimal` 对虚基类构造函数的指定会被忽略。

原因是：
> 共享的 `Animal` 只有一份，必须由最完整对象的类型统一决定如何构造。

---
### 八、混合继承
混合继承就是多种继承结构组合在一起。
例如：
```cpp
class Object
{
};

class Character : public Object
{
};

class Damageable
{
};

class Player : public Character, public Damageable
{
};
```
结构：
```text
Object
   ↓
Character     Damageable
      \         /
          Player
```

这里同时包含：
- 多层继承：`Object → Character → Player`
- 多继承：`Player` 同时继承 `Character` 和 `Damageable`
这种组合称为混合继承。

混合继承不是一种新的语法，只是已有继承结构组合形成的复杂层次。

---
### 九、这些继承结构之间的区别

| 类型   | 特点               |
| ---- | ---------------- |
| 单继承  | 一个派生类只有一个直接基类    |
| 多层继承 | 继承关系形成连续多层链条     |
| 层次继承 | 多个派生类共享同一个基类     |
| 多继承  | 一个派生类拥有多个直接基类    |
| 菱形继承 | 两条继承路径最终汇聚到同一派生类 |
| 混合继承 | 多种继承结构组合使用       |

---
### 十、容易混淆：多层继承和多继承

## 多层继承
```text
A
↓
B
↓
C
```
代码：
```cpp
class B : public A {};
class C : public B {};
```
特点：
> 一层接一层，每个类可以只直接继承一个类。

---

## 多继承
```text
A   B
 \ /
  C
```
代码：
```cpp
class C : public A, public B {};
```
特点：
> 一个派生类同时直接继承多个基类。

所以：
```text
多层继承：继承链很深
多继承：直接基类很多
```

---
### 十一、层次继承和菱形继承的关系

层次继承：
```text
     A
    / \
   B   C
```
只到这里不会产生重复基类问题。

如果再增加：
```text
     A
    / \
   B   C
    \ /
     D
```
这时才形成菱形继承。
所以菱形继承通常可以理解为：
> 层次继承与多继承结合形成的结构。

---
### 十二、实际开发中如何选择

## 单继承
最简单，也最容易维护。
例如：
```cpp
class Enemy : public Character
{
};
```
适合稳定的 `is-a` 关系。

---

## 多层继承
可以使用，但层次不宜太深。

例如：
```text
Object
  ↓
Actor
  ↓
Character
  ↓
PlayerCharacter
```

继承太深时：
- 代码来源难以追踪；
- 基类修改影响范围大；
- 依赖关系复杂。

---
#### 多继承
应谨慎使用。
多继承比较适合多个较纯粹的接口：
```cpp
class IDamageable
{
public:
    virtual void TakeDamage(float damage) = 0;
    virtual ~IDamageable() = default;
};

class ISavable
{
public:
    virtual void Save() = 0;
    virtual ~ISavable() = default;
};

class Player : public IDamageable, public ISavable
{
public:
    void TakeDamage(float damage) override
    {
    }

    void Save() override
    {
    }
};
```
这种“多接口继承”通常比同时继承多个包含大量数据和复杂逻辑的实体基类更安全。

---
#### 菱形继承

没有必要时尽量避免。
必须使用时：
```cpp
virtual public Base
```
让公共基类只保留一份。

但虚继承会使：
- 对象布局更复杂；
- 构造规则更复杂；
- 指针调整更复杂；
- 理解和维护成本上升。

---
### 十三、游戏开发中的理解

游戏中不建议设计过深的结构：
```text
Object
↓
Actor
↓
Character
↓
Enemy
↓
EliteEnemy
↓
Boss
↓
FireBoss
```
继承层级越深，耦合通常越严重。

许多能力更适合使用组合：
```cpp
class Character
{
private:
    HealthComponent health;
    CombatComponent combat;
    InventoryComponent inventory;
};
```
也就是：
```text
Character has-a HealthComponent
Character has-a CombatComponent
```
实际游戏引擎通常是：
```text
少量合理继承
+
大量组件组合
```

### 十四、面试回答

面试官问：

> C++ 中有哪些常见的继承结构？

可以这样回答：

C++ 按继承结构可以分为单继承、多层继承、层次继承、多继承、菱形继承和混合继承。

单继承表示一个派生类只有一个直接基类；多层继承表示继承关系形成连续链条；层次继承表示多个派生类继承同一个基类；多继承表示一个派生类同时继承多个直接基类。

菱形继承是多继承中的特殊情况，公共基类通过两条路径被最终派生类继承，普通继承会导致最终派生对象中存在两份公共基类子对象，从而产生数据冗余和访问歧义。可以通过虚继承使公共基类在最终派生对象中只保留一份，并且虚基类由最终派生类负责构造。

混合继承则是多种继承结构的组合。

### 十五、最终总结
```text
单继承：
A → B

多层继承：
A → B → C

层次继承：
    A
   / \
  B   C

多继承：
A   B
 \ /
  C

菱形继承：
    A
   / \
  B   C
   \ /
    D
```

最重要的两个结论：
> **多继承表示一个类同时继承多个直接基类；多层继承表示继承关系一层一层向下延伸。**

> **菱形继承会造成公共基类子对象重复，虚继承可以让最终派生类只保留一份公共基类子对象。**
