## 基类和派生类对象赋值转换
派生类对象可以赋值给基类的对象、基类的指针以及基类的引用，因为在这个过程中，会发生基类和派生类对象之间的赋值转换。

例如，对于以下基类及其派生类。
```cpp
//基类
class Person
{
protected:
	string _name; //姓名
	string _sex;  //性别
	int _age;     //年龄
};
//派生类
class Student : public Person
{
protected:
	int _stuid;   //学号
};
```
代码当中可以出现以下逻辑：
```cpp
Student s;
Person p = s;     //派生类对象赋值给基类对象
Person* ptr = &s; //派生类对象赋值给基类指针
Person& ref = s;  //派生类对象赋值给基类引用
```
对于这种做法，有个形象的说法叫做切片/切割，寓意把派生类中基类那部分切来赋值过去。

## 继承中的作用域
在继承体系中的基类和派生类都有独立的作用域。若子类和父类中有同名成员，子类成员将屏蔽父类对同名成员的直接访问，这种情况叫隐藏，也叫重定义。

例如，对于以下代码，访问成员_num时将访问到子类当中的_num。
```cpp
#include <iostream>
#include <string>
using namespace std;
//父类
class Person
{
protected:
	int _num = 111;
};
//子类
class Student : public Person
{
public:
	void fun()
	{
		cout << _num << endl;
	}
protected:
	int _num = 999;
};
int main()
{
	Student s;
	s.fun(); //999
	return 0;
}
```
若此时我们就是要访问父类当中的_num成员，我们可以使用作用域限定符进行指定访问。
```cpp
void fun()
{
	cout << Person::_num << endl; //指定访问父类当中的_num成员
}
```

```
需要注意的是，如果是成员函数的隐藏，只需要函数名相同就构成隐藏。
```
例如，对于以下代码，调用成员函数fun时将直接调用子类当中的fun，若想调用父类当中的fun，则需使用作用域限定符指定类域。
```cpp
#include <iostream>
#include <string>
using namespace std;
//父类
class Person
{
public:
	void fun(int x)
	{
		cout << x << endl;
	}
};
//子类
class Student : public Person
{
public:
	void fun(double x)
	{
		cout << x << endl;
	}
};
int main()
{
	Student s;
	s.fun(3.14);       //直接调用子类当中的成员函数fun
	s.Person::fun(20); //指定调用父类当中的成员函数fun
	return 0;
}
```
**特别注意：** 代码当中，父类中的fun和子类中的fun不是构成函数重载，因为函数重载要求两个函数在同一作用域，而此时这两个fun函数并不在同一作用域。为了避免类似问题，实际在继承体系当中最好不要定义同名的成员。

## AI讲解
### 一、基类和派生类对象的赋值转换
假设有下面两个类：
```cpp
#include <iostream>

class Base
{
public:
    int baseValue = 10;

    void BaseFunc()
    {
        std::cout << "Base::BaseFunc\n";
    }
};

class Derived : public Base
{
public:
    int derivedValue = 20;

    void DerivedFunc()
    {
        std::cout << "Derived::DerivedFunc\n";
    }
};
```
一个 `Derived` 对象在概念上包含两部分：
```text
Derived 对象
├── Base 基类子对象
│   └── baseValue
└── Derived 自己的部分
    └── derivedValue
```
因此，派生类对象天然包含一个基类部分。

---
#### 1. 派生类对象赋值给基类对象
```cpp
Derived d;

Base b = d;
```
这是允许的。

因为 `d` 中包含一个 `Base` 子对象，编译器可以把其中的基类部分复制给 `b`。
转换过程可以理解为：
```text
Derived d
├── Base 部分          ──复制──> Base b
└── Derived 特有部分              被丢弃
```
因此：
```cpp
std::cout << b.baseValue;  // 可以

// b.derivedValue;         // 不可以
// b.DerivedFunc();        // 不可以
```
因为 `b` 的静态类型和真实类型都是 `Base`，它只保存复制出来的基类部分。

这种现象称为：
> **对象切片，Object Slicing。**

---
#### 2. 对象切片到底切掉了什么？
例如：
```cpp
class Base
{
public:
    int a = 10;
};

class Derived : public Base
{
public:
    int b = 20;
};

int main()
{
    Derived d;

    Base base = d;
}
```
转换后可以概念化为：
```text
原来的 d：
┌──────────────┐
│ Base 部分     │ a = 10
├──────────────┤
│ Derived 部分  │ b = 20
└──────────────┘

新的 base：
┌──────────────┐
│ Base 部分     │ a = 10
└──────────────┘
```
`b` 没有复制进 `base`。
并不是 `b` 被藏起来了，而是新创建的 `Base` 对象根本没有派生类部分。

---
#### 3. 已有基类对象接收派生类对象

```cpp
Derived d;
Base b;

b = d;
```
也允许。

这里调用的是 `Base` 的赋值运算符，概念上相当于：
```cpp
b.operator=(static_cast<const Base&>(d));
```
只会把 `d` 中的 `Base` 子对象部分赋值给 `b`。
派生类新增成员仍然不会复制。

因此下面两种情况都会发生对象切片：
```cpp
Base b1 = d;  // 初始化
Base b2;
b2 = d;       // 赋值
```

---
#### 4. 基类引用绑定派生类对象
```cpp
Derived d;

Base& ref = d;
```
这是允许的，并且**不会发生对象切片**。
因为引用没有创建新对象，它只是引用 `d` 内部的基类子对象：
```text
Base& ref
     │
     ▼
Derived d
├── Base 部分  ← ref 指向这里
└── Derived 部分仍然存在
```

但通过 `ref` 能直接访问哪些成员，由引用的静态类型 `Base&` 决定：
```cpp
ref.BaseFunc();       // 可以
ref.baseValue = 100;  // 可以

// ref.DerivedFunc(); // 不可以
// ref.derivedValue;  // 不可以
```

注意：
> 派生类部分仍然存在，只是通过 `Base&` 这个接口看不到派生类特有成员。

---
#### 5. 基类指针指向派生类对象
```cpp
Derived d;

Base* ptr = &d;
```
同样允许，也不会发生对象切片。
```text
Base* ptr
     │
     ▼
Derived 对象中的 Base 子对象
```
可以访问基类接口：
```cpp
ptr->BaseFunc();
ptr->baseValue = 100;
```
不能直接访问派生类特有接口：
```cpp
// ptr->DerivedFunc();
// ptr->derivedValue;
```
这叫作：
> **向上转换，Upcasting。**

也就是把派生类指针或引用转换为基类指针或引用。
在公有继承中，向上转换通常可以隐式完成：
```cpp
Derived* → Base*
Derived& → Base&
```
因为：
```text
Derived 是一种 Base
```

---
#### 6. 对象赋值与指针、引用转换的区别
##### 对象赋值
```cpp
Base b = d;
```
创建新的 `Base` 对象，只复制基类部分：
```text
发生对象切片
```
##### 引用转换
```cpp
Base& ref = d;
```
没有创建新对象：
```text
不发生对象切片
```
##### 指针转换
```cpp
Base* ptr = &d;
```
没有创建新对象：
```text
不发生对象切片
```
所以涉及多态时，通常使用：
```cpp
Base*
Base&
```
而不是按值传递：
```cpp
Base
```

---
#### 7. 函数参数中的对象切片
错误的多态写法：
```cpp
void Print(Base object)
{
}
```
调用：
```cpp
Derived d;
Print(d);
```
参数 `object` 是一个新创建的 `Base` 对象，因此会切掉派生类部分。

更合理的是引用：
```cpp
void Print(const Base& object)
{
}
```
调用：
```cpp
Print(d);
```
不会复制对象，也不会切片。

所以多态接口通常写成：
```cpp
void Process(Base& object);
void Process(const Base& object);
void Process(Base* object);
```
而不是：
```cpp
void Process(Base object);
```

---
#### 8. 基类能不能转换成派生类？
下面通常不允许：
```cpp
Base b;

// Derived d = b;  // 错误
```
原因是一个 `Base` 对象只包含基类部分：
```text
Base 对象
└── Base 部分
```
但 `Derived` 还需要自己的派生类部分：
```text
Derived 对象
├── Base 部分
└── Derived 部分
```
编译器不知道怎样凭空生成派生类特有成员。
所以：
```text
Derived → Base
通常安全

Base → Derived
不一定安全
```

---
#### 9. 指针向下转换
假设：
```cpp
Base* basePtr;
```
想转成：
```cpp
Derived* derivedPtr;
```
这叫：
> **向下转换，Downcasting。**

不能直接隐式转换：
```cpp
// Derived* derivedPtr = basePtr; // 错误
```
因为 `basePtr` 可能指向一个真正的 `Base` 对象，也可能指向一个 `Derived` 对象。

---

##### 使用 `static_cast`
```cpp
Derived d;
Base* basePtr = &d;

Derived* derivedPtr = static_cast<Derived*>(basePtr);
```
这里实际对象确实是 `Derived`，所以转换结果可以正常使用。

但是如果实际对象不是 `Derived`：
```cpp
Base b;
Base* basePtr = &b;

Derived* derivedPtr = static_cast<Derived*>(basePtr);
```
转换本身可能通过编译，但把结果当作 `Derived` 使用会产生未定义行为。
`static_cast` 不进行运行时类型检查。

---
##### 使用 `dynamic_cast`
基类必须是多态类型，通常至少有一个虚函数：
```cpp
class Base
{
public:
    virtual ~Base() = default;
};

class Derived : public Base
{
};
```
然后：
```cpp
Base* basePtr = new Derived;

Derived* derivedPtr = dynamic_cast<Derived*>(basePtr);

if (derivedPtr != nullptr)
{
    // 转换成功
}
```
如果实际对象不是 `Derived`，指针转换返回：
```cpp
nullptr
```
引用转换失败则会抛出：
```cpp
std::bad_cast
```
因此：
```text
static_cast：不检查实际动态类型
dynamic_cast：运行时检查实际动态类型
```

---
#### 10. 赋值转换总结

```text
Derived 对象 → Base 对象
允许，但发生对象切片

Derived 对象 → Base&
允许，不切片

Derived 对象地址 → Base*
允许，不切片

Base 对象 → Derived 对象
通常不允许

Base* → Derived*
属于向下转换，需要确认真实对象类型
```

最核心的区别是：
> **对象转换会创建新的基类对象，因此可能切片；指针和引用转换只是换一个观察对象的接口，不会删除原对象的派生类部分。**

## 二、继承中的作用域

每个类都有自己的类作用域：
```cpp
class Base
{
    // Base 类作用域
};

class Derived : public Base
{
    // Derived 类作用域
};
```
派生类不会和基类共享同一个作用域。

更准确地说：
> 编译器在派生类中查找一个名字时，会先查找派生类自己的作用域；如果没有找到，再到基类作用域中查找。

---
#### 1. 派生类可以查找到基类成员
```cpp
class Base
{
public:
    int value = 10;

    void Print()
    {
        std::cout << "Base::Print\n";
    }
};

class Derived : public Base
{
public:
    void Test()
    {
        std::cout << value << '\n';
        Print();
    }
};
```
`Derived` 自己没有定义：
```cpp
value
Print
```
编译器查找过程：
```text
先查找 Derived 作用域
    ↓ 没找到
再查找 Base 作用域
    ↓ 找到
使用 Base::value / Base::Print
```
因此可以省略：
```cpp
Base::value
Base::Print()
```
直接写：
```cpp
value
Print()
```

---
#### 2. 派生类同名成员会隐藏基类成员
```cpp
class Base
{
public:
    int value = 10;
};

class Derived : public Base
{
public:
    int value = 20;

    void Print()
    {
        std::cout << value << '\n';
    }
};
```
在 `Derived::Print()` 中：
```cpp
value
```
先在 `Derived` 作用域中找到，所以输出：
```text
20
```
基类的 `Base::value` 并没有消失，只是被派生类同名成员隐藏。

可以显式访问：
```cpp
void Print()
{
    std::cout << value << '\n';       // Derived::value
    std::cout << Base::value << '\n'; // Base::value
}
```
输出：
```text
20
10
```

---
#### 3. 对象外部如何访问被隐藏成员？
```cpp
Derived object;

std::cout << object.value << '\n';
```
访问的是：
```cpp
Derived::value
```

想访问基类版本：
```cpp
std::cout << object.Base::value << '\n';
```

也可以通过基类引用：
```cpp
Base& baseRef = object;

std::cout << baseRef.value << '\n';
```
因为 `baseRef` 的静态类型是 `Base&`。

## 4. 同名函数也会发生隐藏
```cpp
class Base
{
public:
    void Func()
    {
        std::cout << "Base::Func()\n";
    }
};

class Derived : public Base
{
public:
    void Func(int value)
    {
        std::cout << "Derived::Func(int)\n";
    }
};
```
使用：
```cpp
Derived object;

object.Func(10); // 可以
// object.Func(); // 错误
```
很多初学者会认为：
```cpp
Base::Func()
Derived::Func(int)
```
参数不同，应该形成重载。

但是：
> 基类和派生类位于不同类作用域，派生类只要声明了同名函数，就会隐藏基类中所有同名函数。

因此 `Derived::Func(int)` 隐藏了：
```cpp
Base::Func()
```
不管参数列表是否相同。

---
#### 5. 如何调用被隐藏的基类函数？

使用作用域限定符：
```cpp
Derived object;

object.Base::Func();
object.Func(10);
```
在派生类内部也可以写：
```cpp
class Derived : public Base
{
public:
    void Func(int value)
    {
        Base::Func();
    }
};
```

---
#### 6. 使用 `using` 把基类重载引入派生类作用域

```cpp
class Base
{
public:
    void Func()
    {
        std::cout << "Base::Func()\n";
    }

    void Func(double value)
    {
        std::cout << "Base::Func(double)\n";
    }
};

class Derived : public Base
{
public:
    using Base::Func;

    void Func(int value)
    {
        std::cout << "Derived::Func(int)\n";
    }
};
```
现在：
```cpp
Derived object;

object.Func();      // Base::Func()
object.Func(3.14);  // Base::Func(double)
object.Func(10);    // Derived::Func(int)
```

这一句：
```cpp
using Base::Func;
```
表示：

> 把基类中的 `Func` 名字引入派生类作用域，让它们与派生类版本一起参与重载决议。

---
#### 7. 名字隐藏和函数重写不是一回事
##### 名字隐藏

只要派生类存在同名成员，就可能隐藏基类成员：
```cpp
class Base
{
public:
    void Func();
};

class Derived : public Base
{
public:
    void Func(int);
};
```
名字相同即可发生隐藏。

---
##### 虚函数重写
需要基类函数是虚函数，并且派生类函数满足重写条件：
```cpp
class Base
{
public:
    virtual void Func();
};

class Derived : public Base
{
public:
    void Func() override;
};
```
所以：
```text
隐藏：名字查找规则
重写：虚函数和动态多态规则
```
二者不是同一个概念。

---
#### 8. 基类私有成员也处于基类作用域
```cpp
class Base
{
private:
    int value = 10;
};

class Derived : public Base
{
public:
    void Func()
    {
        // std::cout << value; // 错误
    }
};
```
`value` 存在于 `Base` 作用域和基类子对象中，但派生类没有访问权限。

这里要区分：
```text
名字是否存在
和
当前代码是否有权访问
```
基类 `private` 成员：
```text
存在
但派生类不能直接访问
```

可以通过基类公共或保护接口访问：
```cpp
class Base
{
private:
    int value = 10;

protected:
    int GetValue() const
    {
        return value;
    }
};

class Derived : public Base
{
public:
    void Print()
    {
        std::cout << GetValue() << '\n';
    }
};
```

---
#### 9. 多继承中的作用域歧义
```cpp
class Base1
{
public:
    void Print()
    {
        std::cout << "Base1\n";
    }
};

class Base2
{
public:
    void Print()
    {
        std::cout << "Base2\n";
    }
};

class Derived : public Base1, public Base2
{
};
```
调用：
```cpp
Derived object;

// object.Print(); // 错误：不知道调用哪个
```

因为两个基类作用域中都有：
```cpp
Print
```
需要明确指定：
```cpp
object.Base1::Print();
object.Base2::Print();
```
也可以在派生类中定义自己的版本：
```cpp
class Derived : public Base1, public Base2
{
public:
    void Print()
    {
        Base1::Print();
    }
};
```
此时：
```cpp
object.Print();
```
调用 `Derived::Print()`。

### 最后总结
#### 基类和派生类赋值转换
```text
Derived → Base 对象
允许，但只复制基类部分，发生对象切片

Derived → Base& / Base*
允许，不发生对象切片，称为向上转换

Base → Derived
通常不能隐式转换，因为基类对象不一定包含派生类部分
```
#### 继承中的作用域
```text
1. 基类和派生类分别拥有自己的类作用域。
2. 名字查找先查派生类，再查基类。
3. 派生类同名成员会隐藏基类同名成员。
4. 函数参数不同也可能被整体隐藏。
5. 使用 Base::member 访问被隐藏的基类成员。
6. 使用 using Base::Func 引入基类函数，形成重载集合。
7. 名字隐藏和虚函数重写不是一回事。
8. 多继承出现同名成员时，需要使用作用域限定符消除歧义。
```

两个最核心结论：

> **按值把派生类赋给基类会发生对象切片，使用基类指针或引用则不会。**

> **继承中的名字查找先看派生类作用域；一旦找到同名成员，通常不会继续自动查找基类的同名成员。**
