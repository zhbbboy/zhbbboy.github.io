## 继承与友元
友元关系不能继承，也就是说基类的友元可以访问基类的私有和保护成员，但是不能访问派生类的私有和保护成员。

例如，以下代码中Display函数是基类Person的友元，当时Display函数不是派生类Student的友元，即Display函数无法访问派生类Student当中的私有和保护成员。
```cpp
#include <iostream>
#include <string>
using namespace std;
class Student;
class Person
{
public:
	//声明Display是Person的友元
	friend void Display(const Person& p, const Student& s);
protected:
	string _name; //姓名
};
class Student : public Person
{
protected:
	int _id; //学号
};
void Display(const Person& p, const Student& s)
{
	cout << p._name << endl; //可以访问
	cout << s._id << endl; //无法访问
}
int main()
{
	Person p;
	Student s;
	Display(p, s);
	return 0;
}
```
若想让Display函数也能够访问派生类Student的私有和保护成员，只能在派生类Student当中进行友元声明。
```cpp
class Student : public Person
{
public:
	//声明Display是Student的友元
	friend void Display(const Person& p, const Student& s);
protected:
	int _id; //学号
};
```

## 继承与静态成员
若基类当中定义了一个static 静态成员变量，则在整个继承体系里面只有一个该静态成员。无论派生出多少个子类，都只有一个static成员实例。

例如，在基类Person当中定义了静态成员变量_count，尽管Person又继承了派生类Student和Graduate，但在整个继承体系里面只有一个该静态成员。
我们若是在基类Person的构造函数和拷贝构造函数当中设置_count进行自增，那么我们就可以随时通过_count来获取该时刻已经实例化的Person、Student以及Graduate对象的总个数。
```cpp
#include <iostream>
#include <string>
using namespace std;
//基类
class Person
{
public:
	Person() 
	{ 
		_count++; 
	}
	Person(const Person& p) 
	{
		_count++;
	}
protected:
	string _name; //姓名
public:
	static int _count; //统计人的个数。
};
int Person::_count = 0; //静态成员变量在类外进行初始化
//派生类
class Student : public Person
{
protected:
	int _stuNum; //学号
};
//派生类
class Graduate : public Person
{
protected:
	string _seminarCourse; //研究科目
};
int main()
{
	Student s1;
	Student s2(s1);
	Student s3;
	Graduate s4;
	cout << Person::_count << endl; //4
	cout << Student::_count << endl; //4
	return 0;
}
```
此时我们也可以通过打印Person类和Student类当中静态成员_count的地址来证明它们就是同一个变量。
```cpp
cout << &Person::_count << endl; //00F1F320
cout << &Student::_count << endl; //00F1F320
```


## AI讲解
### 一、继承与友元

友元的作用是：
> 允许某个函数或类，访问另一个类的 `private` 和 `protected` 成员。

例如：
```cpp
class Base
{
private:
    int value = 10;

    friend void PrintBase(const Base& obj);
};

void PrintBase(const Base& obj)
{
    std::cout << obj.value << '\n';
}
```
`PrintBase` 不是 `Base` 的成员函数，但因为被声明为友元，所以可以访问：
```cpp
obj.value
```

---
#### 1. 友元关系不能被继承
这是最重要的结论：
> **基类的友元，不会自动成为派生类的友元。**

例如：
```cpp
#include <iostream>

class Base
{
private:
    int baseValue = 10;

    friend void Print(const Base& obj);
};

class Derived : public Base
{
private:
    int derivedValue = 20;
};

void Print(const Base& obj)
{
    std::cout << obj.baseValue << '\n';

    // 无法访问 Derived::derivedValue
}
```
`Print` 是 `Base` 的友元，所以它只能获得 `Base` 授予的访问权限。
它不会因为 `Derived` 继承了 `Base`，就自动获得对 `Derived` 私有成员的访问权限。
如果希望它访问 `Derived` 的私有成员，必须在 `Derived` 中再次声明：
```cpp
class Derived : public Base
{
private:
    int derivedValue = 20;

    friend void PrintDerived(const Derived& obj);
};
```

---
#### 2. 派生类的友元也不是基类的友元
反过来也一样。
```cpp
class Base
{
private:
    int baseValue = 10;
};

class Derived : public Base
{
private:
    int derivedValue = 20;

    friend void PrintDerived(const Derived& obj);
};
```
友元函数：
```cpp
void PrintDerived(const Derived& obj)
{
    std::cout << obj.derivedValue << '\n'; // 可以

    // std::cout << obj.baseValue; // 错误
}
```
虽然 `Derived` 对象中包含 `Base` 子对象，但 `baseValue` 是 `Base` 的私有成员。
只有 `Base` 自己能够授予访问权限。
`Derived` 不能替 `Base` 决定谁可以访问 `Base::baseValue`。
因此：
> 派生类的友元只能获得派生类授予的权限，不能自动访问基类的私有成员。

---
#### 3. 友元关系没有传递性
假设：
```cpp
class A
{
    friend class B;
};

class B
{
    friend class C;
};
```
这里：
```text
B 是 A 的友元
C 是 B 的友元
```
并不能推出：
```text
C 是 A 的友元
```
所以：
> 友元关系不具有传递性。

完整例子：
```cpp
class A
{
private:
    int value = 10;

    friend class B;
};

class B
{
public:
    void AccessA(A& obj)
    {
        obj.value = 20; // 可以
    }

    friend class C;
};

class C
{
public:
    void AccessA(A& obj)
    {
        // obj.value = 30; // 错误
    }
};
```

---
#### 4. 友元关系没有对称性

假设：
```cpp
class A
{
    friend class B;
};
```
表示：
```text
B 可以访问 A 的私有成员
```
但不表示：
```text
A 可以访问 B 的私有成员
```

例如：
```cpp
class B;

class A
{
private:
    int aValue = 10;

    friend class B;
};

class B
{
private:
    int bValue = 20;

public:
    void AccessA(A& obj)
    {
        obj.aValue = 100; // 可以
    }
};
```
但是 `A` 并不是 `B` 的友元。

所以：
> 友元关系是单向授权，不是相互授权。

---
#### 5. 基类的友元能否访问派生对象中的基类部分？
可以访问派生对象中继承来的那个基类子对象部分。

例如：
```cpp
#include <iostream>

class Base
{
private:
    int value = 10;

    friend void PrintBase(const Base& obj);
};

class Derived : public Base
{
private:
    int otherValue = 20;
};

void PrintBase(const Base& obj)
{
    std::cout << obj.value << '\n';
}
```

调用：
```cpp
Derived d;

PrintBase(d);
```
这是允许的，因为 `Derived` 可以向上转换为 `const Base&`。
`PrintBase` 访问的是：
```text
Derived 对象中的 Base 子对象
```
但是它仍然不能访问：
```cpp
Derived::otherValue
```
可以画成：
```text
Derived 对象
├── Base 子对象
│   └── value       ← Base 的友元可以访问
└── Derived 部分
    └── otherValue  ← Base 的友元不能访问
```

---
#### 6. 友元类与继承
例如：
```cpp
class Helper;

class Base
{
private:
    int value = 10;

    friend class Helper;
};
```
`Helper` 的所有成员函数都可以访问 `Base` 的私有成员：
```cpp
class Helper
{
public:
    void Modify(Base& obj)
    {
        obj.value = 100;
    }
};
```
但是如果还有：
```cpp
class Derived : public Base
{
private:
    int derivedValue = 20;
};
```
`Helper` 仍然不是 `Derived` 的友元。
除非：
```cpp
class Derived : public Base
{
private:
    int derivedValue = 20;

    friend class Helper;
};
```

---
#### 7. 继承与友元总结
必须记住：
```text
1. 友元不是类成员。
2. 友元关系不能被继承。
3. 友元关系没有传递性。
4. 友元关系没有对称性。
5. 基类的友元只能访问基类授予的成员。
6. 派生类的友元不能自动访问基类私有成员。
7. 要访问派生类私有成员，派生类必须单独声明友元。
```
最核心的一句话：
> **友元权限是谁声明、谁授予；继承不会自动传播友元权限。**

---
### 二、继承与静态成员
静态成员属于：
> **整个类，而不是某一个具体对象。**

例如：
```cpp
class Base
{
public:
    static int count;
};

int Base::count = 0;
```
无论创建多少个对象：
```cpp
Base b1;
Base b2;
```
它们共享同一个：
```cpp
Base::count
```

---
#### 1. 派生类会访问基类的静态成员
```cpp
#include <iostream>

class Base
{
public:
    static int count;
};

int Base::count = 0;

class Derived : public Base
{
};
```
可以通过基类访问：
```cpp
Base::count = 10;
```
也可以通过派生类名访问：
```cpp
Derived::count = 20;
```
但这里不是两份变量。
它们指向同一个静态成员：
```cpp
std::cout << Base::count << '\n';
std::cout << Derived::count << '\n';
```
都输出：
```text
20
```
所以：
> 派生类不会因为继承而获得一份新的基类静态成员，整个继承体系访问的是基类定义的同一份静态数据。

---
#### 2. 静态成员不属于对象内部
假设：
```cpp
class Base
{
public:
    int normalValue;
    static int staticValue;
};
```
对象内部概念上只有：
```text
Base 对象
└── normalValue
```
而：
```cpp
staticValue
```
单独属于类：
```text
Base 类
└── staticValue
```
因此：
```cpp
sizeof(Base)
```
通常不会因为加入一个静态数据成员而增加对应大小。
静态成员通常存储在静态存储区域，而不是每个对象内部。

---
#### 3. 基类和派生类对象共享同一个静态成员
```cpp
class Base
{
public:
    static int count;

    Base()
    {
        ++count;
    }
};

int Base::count = 0;

class Derived : public Base
{
};
```
使用：
```cpp
Base b1;
Derived d1;
Derived d2;

std::cout << Base::count << '\n';
```
输出：
```text
3
```
原因是每创建一个 `Derived` 对象，都会先构造它的 `Base` 子对象，因此也会执行：
```cpp
Base()
{
    ++count;
}
```
共享关系：
```text
Base b1       ─┐
Derived d1    ├── 共用 Base::count
Derived d2    ─┘
```

---
#### 4. 派生类可以定义自己的同名静态成员
```cpp
class Base
{
public:
    static int count;
};

int Base::count = 10;

class Derived : public Base
{
public:
    static int count;
};

int Derived::count = 20;
```
此时确实有两份变量：
```cpp
Base::count
Derived::count
```
访问：
```cpp
std::cout << Base::count << '\n';     // 10
std::cout << Derived::count << '\n';  // 20
```
`Derived::count` 会隐藏基类中的同名静态成员。

在派生类内部：
```cpp
class Derived : public Base
{
public:
    static int count;

    void Print()
    {
        std::cout << count << '\n';       // Derived::count
        std::cout << Base::count << '\n'; // Base::count
    }
};
```

所以分两种情况：
##### 派生类没有重新定义
```cpp
class Derived : public Base
{
};
```
那么：
```cpp
Derived::count
```
访问的是：
```cpp
Base::count
```

##### 派生类重新定义同名成员
```cpp
class Derived : public Base
{
    static int count;
};
```
那么基类和派生类各有一份。

---
#### 5. 静态成员的访问权限仍然有效
```cpp
class Base
{
protected:
    static int count;
};

int Base::count = 0;

class Derived : public Base
{
public:
    void Increase()
    {
        ++count; // 可以
    }
};
```
因为 `count` 是 `protected`，派生类可以访问。
但是类外不能直接写：
```cpp
// Base::count = 10;    // 错误
// Derived::count = 10; // 错误
```
如果是 `private`：
```cpp
class Base
{
private:
    static int count;
};
```
派生类同样不能直接访问：
```cpp
class Derived : public Base
{
public:
    void Increase()
    {
        // ++count; // 错误
    }
};
```
因此：
> `static` 只改变成员属于类还是对象，不会取消 `public/protected/private` 访问控制。

---
#### 6. 静态成员函数也可以被继承使用
```cpp
class Base
{
public:
    static void Print()
    {
        std::cout << "Base::Print\n";
    }
};

class Derived : public Base
{
};
```
可以这样调用：
```cpp
Base::Print();
Derived::Print();
```
两者调用的是同一个：
```cpp
Base::Print()
```
也可以通过对象调用：
```cpp
Derived d;
d.Print();
```
但更推荐使用类名：
```cpp
Derived::Print();
```
因为静态成员函数不依赖某个具体对象。

---
#### 7. 静态成员函数没有 `this` 指针
普通成员函数：
```cpp
class Base
{
    int value;

public:
    void Func()
    {
        value = 10;
    }
};
```
调用：
```cpp
obj.Func();
```
编译器内部会传入当前对象地址，也就是 `this` 指针。

但是静态成员函数：
```cpp
class Base
{
public:
    static void Func()
    {
    }
};
```
不属于某个具体对象，所以没有 `this` 指针。
	因此静态成员函数不能直接访问非静态成员：
```cpp
class Base
{
private:
    int normalValue;
    static int staticValue;

public:
    static void Func()
    {
        staticValue = 10;  // 可以

        // normalValue = 20; // 错误
    }
};
```
原因是：
```text
staticValue：属于类，只有一份
normalValue：属于某个具体对象
```
静态函数不知道应该操作哪个对象的 `normalValue`。

---
#### 8. 静态成员函数与虚函数

静态成员函数不能声明为虚函数：
```cpp
class Base
{
public:
    // virtual static void Func(); // 错误
};
```
原因是动态多态需要：
```text
具体对象
this 指针
虚函数表
```
而静态成员函数：
```text
不属于对象
没有 this 指针
```
因此无法进行基于对象动态类型的虚函数分派。
派生类可以定义同名静态函数：
```cpp
class Base
{
public:
    static void Print()
    {
        std::cout << "Base\n";
    }
};

class Derived : public Base
{
public:
    static void Print()
    {
        std::cout << "Derived\n";
    }
};
```
调用：
```cpp
Base::Print();     // Base
Derived::Print();  // Derived
```
这是名字隐藏，不是虚函数重写，也不是运行时多态。

---
#### 9. 静态成员变量的定义
传统写法中，类内只是声明：
```cpp
class Base
{
public:
    static int count;
};
```
类外还需要提供定义：
```cpp
int Base::count = 0;
```
因为静态数据成员需要独立存储空间。

C++17 以后可以使用内联静态成员：
```cpp
class Base
{
public:
    inline static int count = 0;
};
```
这样可以直接在类内初始化，不需要再在 `.cpp` 中单独定义。

对于编译期常量也常见：
```cpp
class Base
{
public:
    static constexpr int maxCount = 100;
};
```

---
#### 10. 类模板中的静态成员要特别注意
虽然你这里学习的是继承，但和前面的模板知识可以连接起来。
```cpp
template <typename T>
class Base
{
public:
    static int count;
};

template <typename T>
int Base<T>::count = 0;
```
不同模板实例有不同静态成员：
```cpp
Base<int>::count = 10;
Base<double>::count = 20;
```
它们不是同一份：
```text
Base<int>::count
Base<double>::count
```
但对于普通继承：
```cpp
class Derived : public Base<int>
{
};
```
`Derived` 访问的是：
```cpp
Base<int>::count
```
不会自动生成一份 `Derived::count`。

---
### 继承与静态成员总结
```text
1. 静态成员属于类，不属于某个对象。
2. 基类和派生类默认共享基类的同一个静态成员。
3. Derived::count 可以访问继承来的 Base::count。
4. 派生类不会自动获得一份新的静态成员。
5. 派生类若重新定义同名静态成员，会隐藏基类版本。
6. 静态成员仍然受 public、protected、private 控制。
7. 静态成员函数没有 this 指针。
8. 静态成员函数不能直接访问非静态成员。
9. 静态成员函数不能是虚函数。
10. 派生类同名静态函数属于隐藏，不属于虚函数重写。
```

两个最核心结论：
> **友元关系不会随着继承传播，谁需要访问权限，谁就必须被相应的类单独声明为友元。**

> **基类静态成员在整个继承体系中通常只有一份，基类对象和派生类对象共享它。**
