## 抽象类
### 概念
在虚函数的后面写上=0，则这个函数为纯虚函数。包含纯虚函数的类叫做抽象类（也叫接口类），抽象类不能实例化出对象。
```cpp
#include <iostream>
using namespace std;
//抽象类（接口类）
class Car
{
public:
	//纯虚函数
	virtual void Drive() = 0;
};
int main()
{
	Car c; //抽象类不能实例化出对象，error
	return 0;
}

```
派生类继承抽象类后也不能实例化出对象，只有重写纯虚函数，派生类才能实例化出对象。
```cpp
#include <iostream>
using namespace std;
//抽象类（接口类）
class Car
{
public:
	//纯虚函数
	virtual void Drive() = 0;
};
//派生类
class Benz : public Car
{
public:
	//重写纯虚函数
	virtual void Drive()
	{
		cout << "Benz-舒适" << endl;
	}
};
//派生类
class BMV : public Car
{
public:
	//重写纯虚函数
	virtual void Drive()
	{
		cout << "BMV-操控" << endl;
	}
};
int main()
{
	//派生类重写了纯虚函数，可以实例化出对象
	Benz b1;
	BMV b2;
	//不同对象用基类指针调用Drive函数，完成不同的行为
	Car* p1 = &b1;
	Car* p2 = &b2;
	p1->Drive();  //Benz-舒适
	p2->Drive();  //BMV-操控
	return 0;
}
```

**抽象类既然不能实例化出对象，那抽象类存在的意义是什么？**
1. 抽象类可以更好的去表示现实世界中，没有实例对象对应的抽象类型，比如：植物、人、动物等。
2. 抽象类很好的体现了虚函数的继承是一种接口继承，强制子类去重写纯虚函数，因为子类若是不重写从父类继承下来的纯虚函数，那么子类也是抽象类也不能实例化出对象。

### 接口继承和实现继承

**实现继承：** 普通函数的继承是一种实现继承，派生类继承了基类函数的实现，可以使用该函数。
**接口继承：** 虚函数的继承是一种接口继承，派生类继承的是基类虚函数的接口，目的是为了重写，达成多态。

**建议：** 所以如果不实现多态，就不要把函数定义成虚函数。

## AI讲解C++ 抽象类

先记住最核心的定义：
> **只要一个类中存在至少一个纯虚函数，这个类就是抽象类。**

抽象类主要用于：
- 描述一类对象的共同特征；
- 规定派生类必须实现的接口；
- 作为运行时多态的基类；
- 不允许直接创建这种“概念不完整”的对象。

---
### 一、什么是纯虚函数？

纯虚函数的语法是：
```cpp
virtual 返回类型 函数名(参数列表) = 0;
```

例如：
```cpp
class Character
{
public:
    virtual void Attack() = 0;
};
```
其中：
```cpp
virtual void Attack() = 0;
```
就是纯虚函数。
`= 0` 并不是把函数赋值为数字零，而是告诉编译器：
> 这个函数在当前类中只规定接口，具体行为主要交给派生类实现。

因为 `Character` 中存在纯虚函数，所以 `Character` 是抽象类。

---
### 二、抽象类不能直接创建对象
```cpp
class Character
{
public:
    virtual void Attack() = 0;
};
```
下面是错误的：
```cpp
Character character; // 错误
```
因为 `Character` 没有完整的 `Attack()` 行为。
编译器会认为：
> 你想创建一个 Character 对象，但这个对象调用 Attack 时应该做什么并不完整。

因此抽象类不能直接实例化。

---
### 三、为什么需要抽象类？
假设游戏中有：
```text
玩家
普通敌人
Boss
```
它们都应该具有攻击能力，但攻击方式不同。
玩家：
```text
挥剑
```
敌人：
```text
爪击
```
Boss：
```text
释放火焰技能
```
我们可以用抽象类规定统一接口：
```cpp
class Character
{
public:
    virtual void Attack() = 0;
};
```
然后让不同派生类提供自己的实现：
```cpp
class Player : public Character
{
public:
    void Attack() override
    {
        std::cout << "Player uses sword\n";
    }
};

class Enemy : public Character
{
public:
    void Attack() override
    {
        std::cout << "Enemy uses claw\n";
    }
};

class Boss : public Character
{
public:
    void Attack() override
    {
        std::cout << "Boss casts fire skill\n";
    }
};
```
现在所有角色都遵守同一个接口：
```cpp
Attack()
```

但具体行为不同。

---
### 四、抽象类可以创建指针和引用
虽然不能创建抽象类对象：
```cpp
// Character character; // 错误
```
但是可以创建抽象类的指针和引用：
```cpp
Player player;

Character* pointer = &player;
Character& reference = player;
```
这是因为：
```text
pointer 和 reference 本身不是 Character 对象
它们只是指向或引用一个具体的派生类对象
```
调用：
```cpp
pointer->Attack();
reference.Attack();
```
都会执行：
```cpp
Player::Attack()
```
这就是抽象类配合虚函数实现运行时多态。

---
### 五、完整示例
```cpp
#include <iostream>

class Character
{
public:
    virtual void Attack() const = 0;

    virtual ~Character() = default;
};

class Player : public Character
{
public:
    void Attack() const override
    {
        std::cout << "Player uses sword\n";
    }
};

class Boss : public Character
{
public:
    void Attack() const override
    {
        std::cout << "Boss casts fireball\n";
    }
};

void ExecuteAttack(const Character& character)
{
    character.Attack();
}

int main()
{
    Player player;
    Boss boss;

    ExecuteAttack(player);
    ExecuteAttack(boss);
}
```
输出：
```text
Player uses sword
Boss casts fireball
```
`ExecuteAttack` 只依赖抽象类接口：
```cpp
const Character&
```
不需要关心具体传入的是：
```text
Player
Boss
```

---
### 六、派生类必须实现所有纯虚函数

假设抽象类有两个纯虚函数：
```cpp
class Character
{
public:
    virtual void Attack() = 0;
    virtual void Move() = 0;
};
```
派生类只实现一个：
```cpp
class Player : public Character
{
public:
    void Attack() override
    {
    }
};
```
由于 `Move()` 仍然没有实现，所以 `Player` 仍然是抽象类。
下面仍然不能创建对象：
```cpp
// Player player; // 错误
```
只有实现所有继承而来的纯虚函数后，派生类才能变成具体类：
```cpp
class Player : public Character
{
public:
    void Attack() override
    {
        std::cout << "Attack\n";
    }

    void Move() override
    {
        std::cout << "Move\n";
    }
};
```
现在可以：
```cpp
Player player;
```
因此：
> 派生类没有实现全部纯虚函数，它自己也仍然是抽象类。

---
### 七、抽象类不等于只有纯虚函数

抽象类除了纯虚函数，还可以拥有：
- 普通成员变量；
- 普通成员函数；
- 构造函数；
- 析构函数；
- 静态成员；
- 受保护成员；
- 已有实现的虚函数。

例如：
```cpp
#include <iostream>
#include <string>

class Character
{
protected:
    std::string name;
    int health;

public:
    Character(const std::string& name, int health)
        : name(name), health(health)
    {
    }

    void TakeDamage(int damage)
    {
        health -= damage;
    }

    int GetHealth() const
    {
        return health;
    }

    virtual void Attack() = 0;

    virtual ~Character() = default;
};
```
这里：
```cpp
Attack()
```
是纯虚函数。
但是：
```cpp
TakeDamage()
GetHealth()
```
是已经实现好的普通函数。
抽象类可以把共同功能写好，只把不同的行为留给派生类。

---
### 八、抽象类为什么可以有构造函数？
虽然不能直接创建抽象类对象，但派生类对象内部包含一个基类子对象。

例如：
```cpp
class Character
{
public:
    Character()
    {
        std::cout << "Character constructor\n";
    }

    virtual void Attack() = 0;
};

class Player : public Character
{
public:
    Player()
    {
        std::cout << "Player constructor\n";
    }

    void Attack() override
    {
    }
};
```
创建：
```cpp
Player player;
```
输出：
```text
Character constructor
Player constructor
```
因为 `Player` 对象内部需要先构造它的 `Character` 基类部分。
所以：
> 抽象类不能独立实例化，但它的基类子对象仍然需要构造。

---
### 九、抽象类应该有虚析构函数
抽象类通常作为多态基类使用，所以析构函数一般应该声明为虚函数：
```cpp
class Character
{
public:
    virtual void Attack() = 0;

    virtual ~Character() = default;
};
```
这样才能安全地通过基类指针删除派生类对象：
```cpp
Character* character = new Player;

delete character;
```
销毁顺序是：
```text
先执行 Player 析构函数
再执行 Character 析构函数
```
如果基类析构函数不是虚函数，通过基类指针删除派生类对象会产生未定义行为。

因此重要规则是：
> **作为多态基类使用的抽象类，应当提供虚析构函数。**

---
### 十、纯虚析构函数
析构函数本身也可以是纯虚函数：
```cpp
class Character
{
public:
    virtual ~Character() = 0;
};
```
这样也会让 `Character` 成为抽象类。

但是纯虚析构函数必须提供函数定义：
```cpp
Character::~Character()
{
}
```
完整写法：
```cpp
class Character
{
public:
    virtual ~Character() = 0;
};

Character::~Character()
{
}
```
为什么纯虚析构函数还需要定义？

因为销毁派生类对象时，最终一定需要调用基类析构函数：
```text
派生类析构
    ↓
基类析构
```
所以即使基类析构函数是纯虚函数，也必须存在实际函数体。

不过普通场景更简单的写法是：
```cpp
virtual ~Character() = default;
```

---
### 十一、纯虚函数可以有实现吗？

可以。

例如：
```cpp
class Character
{
public:
    virtual void Attack() = 0;
};
```
可以在类外提供定义：
```cpp
void Character::Attack()
{
    std::cout << "Default attack logic\n";
}
```
即使纯虚函数有定义，`Character` 仍然是抽象类，依然不能直接创建对象。

派生类仍然需要重写它，才能变成具体类：
```cpp
class Player : public Character
{
public:
    void Attack() override
    {
        Character::Attack();
        std::cout << "Player uses sword\n";
    }
};
```
这里显式调用：
```cpp
Character::Attack();
```
使用了纯虚函数在基类中提供的公共实现。

所以：
> 纯虚函数表示类仍然是抽象的，并不绝对代表函数不能拥有定义。

但这种写法使用较少，初学阶段主要掌握纯虚函数作为接口即可。

---
### 十二、抽象类和接口类

C++ 没有像 Java、C# 那样单独的 `interface` 关键字。
通常使用只包含纯虚函数的抽象类模拟接口：
```cpp
class IDamageable
{
public:
    virtual void TakeDamage(float damage) = 0;

    virtual ~IDamageable() = default;
};
```
派生类：
```cpp
class Player : public IDamageable
{
public:
    void TakeDamage(float damage) override
    {
        std::cout << "Player takes "
                  << damage
                  << " damage\n";
    }
};
```
这种类通常称为：
```text
接口类
Interface Class
```
常见特征：
- 几乎只有纯虚函数；
- 没有复杂成员数据；
- 析构函数是虚函数；
- 用于规定能力或协议。

游戏中常见：
```cpp
class IDamageable;
class ISavable;
class IInteractable;
class IRenderable;
```
例如：
```cpp
class IInteractable
{
public:
    virtual void Interact() = 0;
    virtual ~IInteractable() = default;
};
```
表示：
> 任何可交互对象都必须实现 `Interact()`。

---
### 十三、抽象类与普通基类的区别
#### 普通基类
```cpp
class Character
{
public:
    virtual void Attack()
    {
        std::cout << "Character attack\n";
    }
};
```
可以直接创建：
```cpp
Character character;
```
因为所有函数都有完整实现。

---
#### 抽象类
```cpp
class Character
{
public:
    virtual void Attack() = 0;
};
```
不能直接创建：
```cpp
// Character character; // 错误
```
因为存在纯虚函数。
对比：

|对比项|普通类|抽象类|
|---|---|---|
|是否有纯虚函数|不一定|至少一个|
|能否直接实例化|可以|不可以|
|能否作为基类|可以|可以|
|能否有成员变量|可以|可以|
|能否有构造函数|可以|可以|
|能否有普通成员函数|可以|可以|
|主要用途|表示具体对象|表示抽象概念和统一接口|

---
### 十四、抽象类与纯虚函数的关系

关系可以概括为：
```text
类中存在至少一个纯虚函数
              ↓
           抽象类
```
但是要注意：
```text
抽象类不一定所有函数都是纯虚函数
```
例如：
```cpp
class Character
{
public:
    void Move()
    {
    }

    virtual void Attack() = 0;
};
```
只要一个 `Attack()` 是纯虚函数，整个类就是抽象类。

---
### 十五、抽象类在多继承中的使用

C++ 可以同时继承多个接口类：
```cpp
class IDamageable
{
public:
    virtual void TakeDamage(float damage) = 0;
    virtual ~IDamageable() = default;
};

class ISavable
{
public:
    virtual void Save() = 0;
    virtual ~ISavable() = default;
};

class Player : public IDamageable, public ISavable
{
public:
    void TakeDamage(float damage) override
    {
    }

    void Save() override
    {
    }
};
```
`Player` 同时具有：
```text
可受伤害能力
可保存能力
```
这种接口式多继承通常比继承多个复杂实体类更安全。

---
### 十六、抽象类的实际设计意义
假设有函数：
```cpp
void ExecuteAttack(Character& character)
{
    character.Attack();
}
```
它只依赖抽象接口：
```cpp
Character
```
新增一个角色：
```cpp
class IceBoss : public Character
{
public:
    void Attack() override
    {
        std::cout << "IceBoss casts ice storm\n";
    }
};
```
原来的：
```cpp
ExecuteAttack()
```
不需要修改。

这符合开闭原则：
```text
对扩展开放
对修改关闭
```

也就是说：
- 可以新增派生类；
- 不需要频繁修改调用者；
- 调用者不依赖具体类型。

---
### 十七、抽象类的常见错误
#### 1. 尝试创建抽象类对象

```cpp
class Base
{
public:
    virtual void Func() = 0;
};

// Base object; // 错误
```

---
#### 2. 派生类没有实现全部纯虚函数

```cpp
class Base
{
public:
    virtual void Func1() = 0;
    virtual void Func2() = 0;
};

class Derived : public Base
{
public:
    void Func1() override
    {
    }
};
```
`Derived` 仍然是抽象类，因为没有实现 `Func2()`。

---
#### 3. 基类析构函数不是虚函数
```cpp
class Base
{
public:
    virtual void Func() = 0;

    ~Base() = default;
};
```
如果将来通过 `Base*` 删除派生类对象，会产生风险。

推荐：
```cpp
virtual ~Base() = default;
```

---
#### 4. 重写函数签名不一致

基类：
```cpp
virtual void Func() const = 0;
```
派生类错误地写成：

```cpp
void Func()
{
}
```
缺少 `const`，没有真正重写。
使用：
```cpp
void Func() const override
{
}
```
让编译器帮助检查。

---
#### 5. 按值传递抽象类
下面本身就不允许，因为抽象类不能作为按值参数创建对象：
```cpp
void Process(Character character); // 不合理
```
应该使用：
```cpp
void Process(Character& character);
void Process(const Character& character);
void Process(Character* character);
```

---
### 十八、面试回答

面试官问：
> 什么是抽象类？

可以这样回答：

抽象类是至少包含一个纯虚函数的类。纯虚函数使用 `virtual` 和 `= 0` 声明，例如：

```cpp
virtual void Func() = 0;
```

抽象类不能直接实例化，但可以定义指针和引用，并通过它们绑定具体派生类对象。它主要用于规定统一接口、建立类型体系以及实现运行时多态。

派生类必须实现所有继承而来的纯虚函数，否则派生类本身仍然是抽象类。

抽象类可以拥有成员变量、普通成员函数、构造函数和析构函数。由于抽象类通常作为多态基类使用，其析构函数通常应声明为虚函数，从而保证通过基类指针删除派生类对象时能够正确析构。

---
### 十九、最终总结

核心语法：
```cpp
class Base
{
public:
    virtual void Func() = 0;
    virtual ~Base() = default;
};
```

必须记住：
```text
1. 至少有一个纯虚函数的类就是抽象类。
2. 纯虚函数使用 = 0 声明。
3. 抽象类不能直接创建对象。
4. 抽象类可以定义指针和引用。
5. 抽象类可以有构造函数和普通成员函数。
6. 派生类必须实现全部纯虚函数。
7. 未实现全部纯虚函数的派生类仍是抽象类。
8. 抽象类通常作为多态基类。
9. 多态基类应该有虚析构函数。
10. C++ 常用抽象类模拟接口。
```

最核心的一句话：
> **抽象类负责规定“必须具备什么能力”，具体派生类负责决定“这种能力如何实现”。**
